# 자동화 공장

같은 와이파이에서 친구와 같이 짓는 2D 공장 자동화 게임 (Windows).

## 받기

1. 오른쪽 **Releases**에서 가장 최근 `AutomationFactory-Setup-(버전).exe` 를 받아 더블클릭하면 설치돼요.
2. "Windows의 PC 보호" 창이 뜨면 → **추가 정보** → **실행**
   (개인이 만든 게임이라 서명이 없어서 떠요)
3. 처음 켤 때 방화벽 창이 뜨면 **개인**·**공용** 둘 다 체크 → **액세스 허용**
4. 새 버전이 나오면 게임 오른쪽 위에 **[업데이트]** 버튼이 떠요.
