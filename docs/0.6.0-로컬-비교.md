# 0.6.0과 이전 로컬 작업 비교

2026-10-28. 기준은 `v0.6.0` (`27d14d7`). 이전 미커밋 작업은
`codex/compare-local-with-0.6.0`의 `50db9ad`에 보존했다.

- 기존 도전 10개와 지역·날씨 비교 창은 새 목표·지역 과제·정보 보기로 대체되어 옮기지 않았다.
- 업적의 시뮬레이션 판정·기록은 새 업적 시스템에 구현되어 있어 옮기지 않았다.
- 기획서 버전 3과 업적 확장 기획서는 줄바꿈을 제외하면 배포본과 동일하다.
- 과거 리뷰 문서는 백업 브랜치에 보존한다. 현행 구현 설명으로 가져오지 않는다.
- 모달을 열었을 때 게임 이동·건설 단축키를 막고, 버튼의 Space/Enter 기본 동작과 편집 입력을 보호하는 수정은 가져왔다.
- 모달의 Tab 이동이 건설 탭을 바꾸지 않고 대화상자 안에서 순환하도록 했다.
- 예전 UI 스모크 테스트는 0.6.0 화면에 맞게 고쳤다. `npm run test:ui`는 사용자 저장과 분리된 숨김 Electron 창을 사용한다.

검증: 프로덕션 빌드 통과, 테스트 305개 통과·1개 생략, Electron UI 검사 통과.
UI 검사는 주요 창 5개, 모달 단축키 차단, Tab 순환을 확인한다.
