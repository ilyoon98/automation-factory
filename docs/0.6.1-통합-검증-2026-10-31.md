# 0.6.1 통합·검증 기록

2026-10-31. 원격 `836025f` (v0.6.1)을 `codex/integrate-0.6.0`에 병합했다.
이전 개발판은 `codex/compare-local-with-0.6.0`의 `50db9ad`에 보존되어 있다.

## 반영과 개선

- 원격의 도로 자동 연결·운송 UI·공장 연출 개선과 문서를 반영했다.
- 입력 코드 두 곳의 충돌을 해결해 창 안 단축키 차단·Tab 순환·편집 입력 보호를 유지했다.
- 새 포인터 테스트의 브라우저 대역에 document·HTMLElement를 추가했다.
- 이동 키를 누른 상태에서 모달을 열면 카메라 이동이 멈추고, 닫은 뒤 눌림 상태가 남지 않는 회귀 테스트를 추가했다.
- 연출 검사는 PC의 동작 줄이기 설정을 따르던 탓에 화물 장식 검사에서 실패했다. 시험에서 효과를 명시적으로 켠 뒤, 효과 줄이기 전환은 별도 항목으로 확인한다. 게임의 사용자 설정은 바꾸지 않는다.

## 확인한 결과

- 프로덕션 빌드 통과.
- 단위·시뮬레이션 테스트 389개 통과, 성능 관련 1개 생략.
- 배포 산출물 UI 스모크 검사 8개 통과.
- 개발 화면 운송 검사 10개 통과.
- 개발 화면 연출 검사 27개 통과 (효과 줄이기·1000대 설비 검사 포함).
- 화면 검사는 개인 저장과 다른 임시 프로필의 Electron 창으로 실행했다.
- 컴퓨터 유즈 시험 창은 열었지만 앱 접근 승인 시간 초과로 실제 마우스·키보드 조작은 확인하지 못했다. 자동 화면 검사와 구분한다.

## 남은 범위

이전 중간 개발판 저장의 지형·금속·업적 이관은 이번 작업에서 수정하거나 검증하지 않았다.
새 기능은 추가하지 않았다. main 병합·원격 푸시·설치 파일 배포는 하지 않았다.
