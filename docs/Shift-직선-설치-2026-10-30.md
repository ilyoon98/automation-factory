# Shift 직선 설치

2026-10-30 · regional-d09 작업본 · 배포 전

건설 도구를 든 상태에서 Shift+좌클릭 드래그하면 처음 이동량이 큰 축으로 가로/세로를 고정한다. 같은 이동량은 가로를 선택하며 이후 마우스가 대각선으로 흔들려도 축을 바꾸지 않는다. 도로·컨베이어와 기존 드래그 건설이 가능한 설비에 적용한다. 빈손 Shift는 기존 단체 선택이다.

Shift를 놓으면 자유 배치로 돌아간다. 드래그 중 다시 누르면 마지막 배치 칸부터 새 직선을 시작한다. 실제 설치·고스트·커서·툴팁이 투영된 좌표를 공유하고 지도에 가로/세로 점선을 표시한다. 마우스를 떼거나 Esc·포커스 상실·다른 도구/청사진 선택으로 끝내면 축을 지운다.

기존 배치 명령을 사용해 비용·공개 범위·장애물·컨베이어 방향·되돌리기와 함께 하기 동기화를 유지한다. 장애물은 우회하지 않으며 놓을 수 없는 칸은 기존 규칙에 따라 건너뛴다. 지하 컨베이어는 첫 클릭 한 칸만 놓는 규칙을 유지한다.

변경: `src/input/input.ts`, `src/input/pointer.ts`, `src/render/renderer.ts`, `index.html`. 루트 운영 UI §2.8과 계획서에도 반영했다.

검증: `npm run build` 성공, 전체 366개 테스트 통과·기존 성능 테스트 1개 제외, `git diff --check` 통과. 실제 입력/명령 경로에 11개 검증을 추가해 네 방향 축·컨베이어 방향·미리보기 일치, Shift 해제/재진입, 빈손 단체 선택, 장애물과 한 번의 되돌리기/재료 보존, 2칸 설비, 지하 클릭 제한, Esc/포커스/도구 교체 후 재진입을 확인했다. 테스트 하네스가 콜백 없는 명령도 실제로 실행하도록 보완했다. 컴퓨터 유즈·화면 재생 검증은 하지 않았다.
