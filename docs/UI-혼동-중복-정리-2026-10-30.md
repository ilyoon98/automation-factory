# 기존 UI의 혼동·중복 설명 정리

2026-10-30 · regional-d09 작업본 · 배포 전

사용자의 요청에 따라 선택 설비, 전력, 통계, 정류장/차량, 툴팁, 관련 도움말을 코드 기준으로 검토했다. 도감·도움말은 상세 정보를 찾는 화면이므로 조건 자체를 일괄 삭제하지 않았다.

| 대상 | 문제와 변경 |
| --- | --- |
| 선택 설비 | 상단 설명과 아래 상태·수치를 반복하던 사용법은 아래 `설비 사용법`으로 접었다. 전력 연결과 충전 예산도 필요할 때 펼친다. 기존 details 상태 보존 경로를 사용한다. |
| 모듈 | 초기부터 미해금 설명을 반복하던 패널은 통합 자동화 연구 이후 표시한다. 설치·분리 조건, 현지 반환·되돌리기 제한은 유지한다. |
| 생산 통계 | 현재/최대 생산·사용을 명시하고 `지금 남음`을 `현재 증감`, `100%일 때 남음`을 `최대 증감`으로 변경했다. 재고와 분당 생산−사용을 구분한다. 설비 대수는 수치의 툴팁으로 옮기고 자동 증설 대수 추천을 제거했다. |
| 전력 막대 | 숫자는 충족률인데 막대는 수요/용량이던 불일치를 없앴다. 막대·숫자 모두 충족률이다. 수요/용량과 충전 수요는 별도 표시한다. |
| 발전기 | 전력망 영역과 설비 영역에서 중복하던 출력을 한 번만 표시한다. 연료·지열도 0kW를 포함해 표시한다. 태양광·풍력의 기본 정격을 현지 최대값처럼 쓰지 않는다. |
| 기계 전력 | 고정 기본값을 현재 소비처럼 보이게 하던 `전력`을 `기본 작업 전력`으로 바꿨다. 모듈 전력 배율은 모듈 설정에서 유지한다. |
| 충전기 | 전체 전력 충족률×정격으로 추정하던 표시를 실제 충전원의 차량 수·받은 전기/DT로 바꿨다. 한 도로에 충전기가 여럿이어도 중복 집계하지 않는다. 충전 대기는 따로 센다. |
| 정류장·노선 | 정류장은 벨트 입고/출고, 차량 작업은 트럭에 싣기/트럭에서 내리기로 구분한다. 실제 설정값과 동작은 보존한다. |
| 목표 재고 | 현재/목표 숫자를 함께 두고 입고 예정은 다음 줄로 분리한다. 예약량 0은 생략하며 현재 재고에 더하지 않는다. |
| 차량 | 상태와 짧은 이유를 한 상태 줄로 합쳤다. 정류장 간 거리가 완충 주행거리보다 긴 경우 중간 충전기 확인으로 안내하고 실제 충전 실패처럼 단정하지 않는다. |
| 하역기 | 뒤 칸이 벨트 등 다른 설비인 경우 함께 놓인 회수 더미를 무시해 출처 없음·허브/창고 필요로 표시하던 문제를 고쳤다. 실제 엔진과 같은 허브/창고 우선 규칙을 사용한다. 속도는 최대 하역량으로 명시한다. |
| 컨베이어 | 품목 종류가 그대로이면 멈춰 있던 목록 개수를 숫자만 갱신하도록 했다. 빼기 버튼을 다시 만들지 않으며 줄 전체 회수 범위는 짧게 유지한다. |
| 창고 | 확장 세계 내용물이 허브로 간다는 잘못된 안내를 고쳤다. 확장 세계는 건설비 허브·내용물 현지 더미, 기존 세계는 허브 반환이다. |
| 툴팁·기타 | 긴 최대 필요 재료 목록·반복 클릭/회전 안내와 평시 증설 권유 문장을 줄였다. 실제 장애 경고·연구 선행·비용·철거 위험·설정 계약은 유지한다. 지하 컨베이어 도움말 번호도 물류 2로 맞췄다. |

새 `equipment-info.ts`는 충전과 하역에 대한 읽기 전용 표시 자료와 접힌 사용법을 제공한다. World의 기존 `chargeSpot`을 공개해 실제 충전원 선택을 재사용했으며 충전·하역·운송 알고리즘, 세계 경제, 저장 포맷은 변경하지 않았다. 주요 수정은 `src/ui/ui.ts`, `src/ui/equipment-info.ts`, `src/sim/world.ts`의 접근 지정, `src/style.css`, `index.html`이다. 루트 운영 UI §2.7과 계획서에 반영했다.

검증: 최종 `npm run build` 성공, 전체 테스트 355개 통과·기존 성능 테스트 1개 제외. 새 5개 검증은 실제 수신량과 대기 구분, 겹친 충전기 집계, 지도 경계의 도로 오인, 실제 하역기의 더미/창고 우선 처리와 읽기 시 게임 상태 보존을 확인한다. 마크업·입력 경로는 코드로 검토했다. 컴퓨터 유즈·숨김 브라우저·실제 화면 재생은 실행하지 않았으므로 시각적 밀도와 좁은 창의 최종 줄바꿈은 미확인이다.
