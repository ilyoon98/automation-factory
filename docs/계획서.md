## 1. 바로 확인할 것 (새 기능 전에)

만든 다음 직접 보지 못한 것들. 문제가 있으면 0.2.1로 고쳐 올린다.

| 할 일 | 왜 | 어떻게 |
| --- | --- | --- |
| 0.4.0 exe에서 숲 해 보기 | 숲은 브라우저(개발 서버)에서만 확인했다 | 게임 안 업데이트 → 새 게임 → 산림 연구 → 벌목기·식목기 |
| 0.2.0 exe 설치해서 켜 보기 | 설치 파일이 만들어지고 올라간 것까지만 확인했다 | 릴리스에서 받아 설치 → 새 게임 → 트럭 노선·소리 |
| 0.1.0 → 0.2.0 게임 안 업데이트 | 업데이트 알림·조각 받기가 되는지 | 0.1.0이 깔린 PC에서 켜기 |
| exe끼리 같이 하기 | 0.2.0에서 노선 명령·체크섬이 바뀌었다 (테스트는 통과) | 두 PC에서 방 만들고 들어가 트럭 노선 고치기 |
| 효과음·배경음 들어 보기 | 소리 높이·길이·크기를 감으로 정했다 | 거슬리는 것만 `src/ui/sound.ts` 숫자 조정 |
| 글자 또렷하게 | 화면 배율을 흉내 내서만 확인했다 | 125%·150% 모니터에서 켜 보기 |
| 다른 PC 맞추기 | 다른 PC는 0.2.0 이전 상태 | `git checkout main` → `git pull` |
| 깃허브의 빈 숨김 릴리스 0.2.0 | 0.2.0 올릴 때 생긴 것. 안 보이고 해가 없다 | 원하면 릴리스 페이지에서 직접 지우기 ("Draft" 표시가 붙은 것만) |

## 3. 운영

- **새 버전 올리기**: 버전 올리기 → `docs/바뀐점.md`에 `## <버전>` 적기 → `npm run release` (README "새 버전 올리기").
  - 0.2.0 뒤에 배포 스크립트를 고쳤다 (올리기를 electron-builder 대신 스크립트가 직접). 가짜 깃허브 서버로는 시험했지만 진짜 깃허브에서는 다음 배포가 처음이다. 끝나고 릴리스 페이지에서 파일 세 개와 설명을 확인한다.
- **깃허브 토큰**: 이 PC에 있다. **2027-01-20에 만료** → 같은 방법으로 새로 만들어 `setx GH_TOKEN`.
- **같이 하기는 버전이 같아야**: 새 버전을 올리면 모두 업데이트하라고 알린다. 개발 서버(브라우저)와 exe는 빌드가 달라 같이 못 한다.
