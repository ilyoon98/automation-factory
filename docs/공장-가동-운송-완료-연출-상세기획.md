# 공장 가동과 운송 및 완료 연출

2026-10-30 · 기존 기능의 표현 개선 · [운영 UI](지역-운영-UI-상세기획.md) · [AI 구현 명세](AI-구현-변경명세.md)

**공장이 일하고, 화물이 이동하고, 연구와 최종 납품이 끝났다는 사실을 움직임으로 전달한다.** 새 생산 시스템·아이템·비용·조작 과제를 추가하지 않는다. 크림색 종이 UI·갈색 잉크·금빛 강조와 기존 픽셀 설비를 유지한다. 아래 시간·입자 수는 첫 적용값이며 실제 화면에서 밀도를 조정한다.

## 1. 이번 개선 범위

건설·철거, 설비 가동·정지, 차량 이동·상하차·충전, 기존 날씨·낮밤, 연구·목표·허브 완료를 다듬는다. 전봇대의 실제 연결 거리·공급 반경·전력 계산은 [전력망 개정](전력망-연결-독립시작-개정.md)을 유지한다. 앞서 비교한 허브 12·발전기 4·변전소 12칸은 배치 테스트 후보이며 이번 연출 채택으로 적용하지 않는다.

추가 환경 후보인 오로라·반딧불이·새로운 기상 이벤트는 첫 범위에 넣지 않는다. 현재 날씨 7종과 낮밤을 먼저 다듬는다. 기능이 없는 온도·오염·세균·충돌·고장 등을 연출 때문에 새로 계산하지 않는다.

확장 작업본 `.claude/worktrees/regional-d09`에서 확인한 기존 표현은 다음과 같다. 착수 시 실제 브랜치의 최신 코드를 다시 확인하고 기존 효과를 보완한다.

| 기존 표현 | 이번 보완 |
| --- | --- |
| 설치 시 내려앉기·작은 반동·먼지·테두리, 철거 시 파편 | 기존 효과 재사용, 연속 편집의 소리·입자 밀도 제한 |
| 기계 작업 프레임, 전력 부족 시 일괄 반 속도 | 실제 작업 진행에 맞는 속도·정지, 설비별 작업 동작 구분 |
| 트럭 빈 차/부분/가득 그림과 일부 경고 | 실제 차량별 용량으로 적재 표현, 상하차·충전·대기 구분 |
| 연구 토스트·효과음·허브 별 반짝임 | 기존 연구 완료 카드와 하나의 성공 사건으로 연결 |
| 처진 전선·배치 중 공급 면 | 선택·전력 보기에서 읽기 쉽게 표시하고 전류 방향 효과는 만들지 않음 |

## 2. 움직임의 공통 기준

- 작업부·실물 벨트 아이템·차량은 게임 시간과 실제 작업 상태를 따른다. 일시정지하면 멈추고 배속에 맞춰 진행한다. 성공한 정류장 화물 이동의 짧은 잔상은 가독성을 위해 실제 시간 0.55초로 마무리한다. 건설·알림의 짧은 장식도 개인 화면의 실제 시간으로 끝난다. 장식이 실제 작업/운송의 속도나 완료 시점을 바꾸지 않는다.
- 작업 속도가 바뀌어도 프레임이 거꾸로 튀지 않게 위상을 누적한다. `현재 시각 × 현재 속도`만으로 프레임을 정하지 않는다. 전력 부족에 일괄 0.5배를 적용하지 않고 실제 배치 진행량·적용 속도 배율을 읽는다.
- 작업부는 움직여도 몸체·입출구·선택 판정은 고정한다. 장식으로 벨트나 접점을 가리지 않는다. 픽셀 그림은 정수 좌표·기존 확대 방식으로 또렷하게 그린다.
- 모든 공장이 동시에 깜빡이지 않도록 설비 ID로 작은 위상 차이를 준다. 진행·실적·재고에 장식용 난수를 사용하지 않는다.
- 전력 부족·미연결·재료 부족·출력 막힘은 작은 고정 아이콘과 상세 문구로 구분한다. 반복 섬광·화면 흔들림·기계별 경고음을 사용하지 않는다.

빠른 연속 편집에서는 효과음을 0.12초보다 자주 재생하지 않고 입자 상한을 공유한다. 화면 밖의 설치 효과는 생성하지 않는다. 불러오기·중간 참가로 나타난 기존 설비에는 설치 효과를 재생하지 않는다.

## 4. 설비별 가동 표현

| 조립기·대형 조립소 | 작업 팔·프레스 왕복, 큰 조립소는 여섯 입력과 작업부가 구별되게 표현 | 작업부 정지, 출력 막힘은 출구 쪽 표시 |

| 풍력·수력·지열 | 풍력은 현재 바람에 따른 회전, 수력은 실제 발전에 따른 물레, 지열은 작은 증기 | 풍력은 수요 0이어도 바람이 있으면 회전 가능. 회전과 실제 kW 표시는 구분 |
| 태양광·축전기·변전소 | 태양광은 일조가 있을 때 드문 반사광, 축전기는 잔량 눈금과 충방전 표시, 변전소는 작은 상태등 | 밤 태양광 반사광 없음. 망 연결/공급원 유무/부족은 실제 상태 표시 |

완제품 한 배치가 실제로 완료되면 출구 부근을 약 0.15초 밝게 표시할 수 있다. 설비당 초당 1회를 넘기지 않고, 아이템 수만큼 폭죽이나 떠오르는 숫자를 만들지 않는다. 실제 산출품의 이동은 기존 벨트·재고가 담당한다.

기계 한 대마다 상시 소리를 재생하지 않는다. 기존 음량·음소거 설정을 유지하고 우선 건설·운송 도착·완료 효과음을 다듬는다. 설비별 공간 음향은 후속으로 둔다.

## 5. 차량과 화물

| 차량 상태 | 지도 위 표현 | 실제 상태와의 관계 |
| --- | --- | --- |
| 주행 | 차체 고정, 바퀴의 2~4프레임 회전. 가까이에서만 아주 작은 노면 먼지 | 실제 이동 거리에 맞춰 바퀴 위상 진행. 악천후에도 실제 주행보다 빠르게 돌지 않음 |
| 상차·하차 | 정류장 적재 구역 ↔ 차량 방향으로 품목 아이콘이 실제 시간 약 0.55초 이동. 밝은 받침·짧은 궤적·도착 적재 구역 테두리 | 실제 성공한 화물 이동 뒤에만 재생. 같은 정류장/종류/방향의 진행 중 효과는 묶고 전체 4개 상한 유지. 수량은 실제 재고/상세에서 표시 |
| 정류장 벨트 입출고 | 실제 출입 방향으로 같은 아이콘 이동, 표지에 잠깐 입고/출고 표시 | 성공한 전송만 표시. 지하 벨트는 실제 출구를 사용하며 공간/재고 부족에는 이동하지 않음 |
| 충전 | 작은 배터리 눈금과 천천히 움직이는 충전 표시 | 실제 받은 충전량이 있을 때만 움직임. 전력 0이면 정적인 충전 대기 표시 |
| 정상 대기 | 시계/대기 표식, 차체와 바퀴 정지 | 정기 출발·충전 순서 대기를 오류로 표시하지 않음 |
| 재고 없음·하차 공간 없음·경로 없음·배터리 부족 | 품목/상자/끊긴 길/빈 배터리의 서로 다른 표식 | 선택 상세에 실제 이유. 첫 진입만 짧게 강조하고 계속 점멸하지 않음 |

적재 그림과 막대의 분모는 해당 차량의 실제 현재 용량을 사용한다. 기본 트럭 용량 상수를 고급 트럭에도 적용해 반만 실었는데 가득 찬 그림이 되지 않게 한다. 동시에 여러 품목을 옮겨도 아이콘을 모두 날리지 않고 실제 이동한 품목을 제한해서 보여 준다. 예약만 됐거나 하역 실패한 물품에는 이동 연출이 없다.

선택한 차량은 실제 경로와 다음 정류장만 강조한다. 경로선을 움직이는 경우 점선 장식으로 제한하며 차가 도착한 것처럼 보이는 가짜 차량·화물은 만들지 않는다. 차량 도착음은 선택한 차량에 한해 최대 1초에 1회, 나머지는 시각 표시만 사용한다. 교통 충돌·주차 공간·추가 하역 대기 시간을 도입하지 않는다.

정류장 일반 배치 중 실제 접도 칸을 초록 테두리·연결선·가까운 화면의 `P`로 표시한다. 도로가 없으면 미연결 안내를 하되 먼저 건설할 수 있는 동작은 유지한다. 정차 칸은 실제 `stationStops`와 같고 새 주차 예약/점유가 아니다. 이후 regional-d09에 적용한 [정류장 구현 기록](../.claude/worktrees/regional-d09/docs/정류장-배치-입출고-연출-구현-2026-10-30.md)을 따른다.

## 6. 전력과 지도 표현

공급 면은 같은 망끼리 합쳐 같은 투명도로 칠한다. 노드가 겹쳤다고 더 진해지지 않는다. 선택한 노드의 개별 범위를 테두리로 구분하고 배치 중 새롭게 공급되는 면을 강조한다. 전봇대 설치 성공 시 새 연결선은 약 0.15초에 걸쳐 나타나며 계속 반짝이지 않는다.

기본 보기의 전선은 기존 실제 연결 그래프에서 연결성을 보존하는 대표 간선만 그려 밀도를 줄인다. 발전기끼리만 있는 망도 실제와 같은 연결 성분으로 보이게 한다. 기존 간선을 가능한 한 유지해 배치 한 번에 온 공장의 선이 바뀌는 것을 줄이고, 선택한 노드의 모든 실제 연결과 철거 영향을 별도로 표시한다. 전력 보기에서는 대표선을 선명하게, 나머지 실제 간선을 옅게 표시한다. 표시 생략은 실제 간선 삭제나 철거 후 분리 판정을 바꾸지 않는다. 전선 교차점은 연결점처럼 빛내지 않는다.

전류 방향·선별 전달량을 계산하지 않으므로 방향 화살표나 전선 위를 달리는 전기 입자를 사용하지 않는다. 망 상태 변화는 실제로 영향을 받는 노드/설비에 약 0.25초 한 번 강조하고, 정전 중에는 고정 아이콘으로 남긴다. 전선이 있다는 사실을 전력 충족으로 표현하지 않는다.

레이어 변경은 정보 면·테두리만 약 0.15초 교차 전환한다. 카메라·선택·건설 도구는 유지한다. 접근 마스크는 전환 효과보다 먼저 적용하고 공개 전 정보를 희미하게도 노출하지 않는다.

## 7. 낮밤과 기존 날씨

기존 하루 12분·낮밤 위상·날씨 확률·지형별 표현과 20초 전환을 유지한다. 현재 현지 날씨에 맞춰 비·눈·모래 바람을 그리며 새 강수 확률이나 별도 환경 이벤트를 만들지 않는다.

- 낮밤은 기존 위상에 따라 배경 색조를 부드럽게 바꾼다. 밤에도 자원·입출구·도로·상태 아이콘을 읽을 수 있게 유지한다. 가동 설비의 작은 상태등은 분위기 표현이며 조명 건물·연료 소모를 추가하지 않는다.
- 비는 가는 픽셀 선, 눈은 느린 작은 점, 모래 바람은 낮은 대비의 짧은 가로 입자, 안개는 지면의 옅은 면으로 구분한다. 맑음·흐림은 색조 중심으로 표현한다.
- 폭풍은 기존 비/바람의 밀도와 배경음으로 구분하고 전체 화면 섬광·카메라 흔들림은 넣지 않는다. 화산재는 기존 화산 지형의 작은 환경 입자로 유지한다.
- 화면에 보이는 공개 지형에서만 효과를 생성한다. 미공개 지형을 지나는 입자나 경계 밖 구름으로 숨은 지역 종류·날씨를 미리 드러내지 않는다.
- 전력·운송·자원 보기에서는 장식 입자를 기본 보기 대비 절반 이하로 줄이고 범례·경고·선택 표시를 우선한다. 효과를 꺼도 현재 날씨와 실제 배율을 확인할 수 있다.

## 8. 연구와 목표 완료

연구는 [운영 UI §9.1](지역-운영-UI-상세기획.md)의 상단 중앙 카드·4초 자동 닫기·0.8초 픽셀 폭죽·1.5초 빛 한 바퀴를 유지한다. 카드 등장/퇴장은 약 0.15초, 폭죽은 카드 주변에만 약 16~24개로 제한한다. 허브가 화면 안에 있을 때만 기존 0.6초 별 효과를 함께 사용하고, 성공음은 한 번만 재생한다. 카드를 보려고 허브로 카메라를 옮기지 않는다.

일반 목표 완료는 약 2.5초의 작은 알림과 도장 하나를 사용한다. 목표와 업적이 동시에 달성되면 한 알림에 묶고 폭죽을 중첩하지 않는다. 반복 연구·연속 메달은 작은 묶음 알림으로 보여 준다. 새 지역 공개는 약 0.6초 동안 새 공개 영역의 경계 음영을 걷고 지역 이름을 약 2.5초 표시한다. 공개 셀의 접근 가능 시점은 판정 틱이며 연출이 끝날 때까지 건설을 막지 않는다. 숨은 자원을 보여 주는 카메라 이동은 없다.

서로 다른 완료 카드가 동시에 오면 최종 완료 → 연구 → 일반 목표/업적 순으로 큰 카드 한 장만 사용한다. 대기한 연구는 기존 묶음 규칙으로 보여 주며 상세 정보는 해당 연구 화면에서 다시 확인할 수 있다. 실제 연구 적용·목표 판정·지도 공개는 카드 대기와 무관하게 즉시 반영한다.

연구·최종 완료 카드는 [상단 앵커](상단-UI-배치-앵커-상세기획.md)의 전체 상단 아래 8px·화면 중앙·완료 카드 겹침 순서를 공유한다. 논리 좌표와 UI 배율을 한 번만 변환하고 작은 화면에서도 카드가 도구 버튼·닫기를 덮지 않게 한다.

## 9. 허브 최종 납품 완료

연출 조건은 기존대로 프로젝트 50개 실물 소비와 MG36의 모든 선행 충족이다. 50개만 먼저 모였으면 납품 완료로 표시하고 MG36 완료 축하는 선행까지 충족했을 때 한 번 실행한다. 마지막 모듈 소비나 완료를 연출 종료 시점으로 미루지 않는다.

1. 완료 직후 허브가 화면에 보이면 테두리와 작은 상태등이 약 0.3초 금빛으로 강조된다.
2. 약 0.8초 동안 허브 위 또는 완료 카드 주변에서 작은 픽셀 폭죽 두 번과 기존 완료음 한 번을 재생한다. 화면 밖 허브로 카메라를 강제로 옮기지 않는다.
3. 상단 아래 중앙에 `공장망 완성`·`설비 모듈 50/50 납품`과 요약 카드를 표시한다. 요약은 완료 시점의 게임 경과 시간·실적이 있는 생산 거점 수·프로젝트 납품 수량 3개로 고정한다. 효율 점수·등급·예상치·새 보너스는 추가하지 않는다.
4. 카드는 약 8초 후 닫힌다. `계속 건설`·X·Esc는 즉시 닫고 장식을 끝낸다. `완료 기록 보기`는 기존 목표 상세로 이동한다. 완료 시점의 요약은 기록에 보존한다.

자동 일시정지·카메라 이동·전체 화면 가림·입력 잠금은 없다. 완성 순간에도 공장은 계속 돌아간다. 현재 함께 하는 참여자에게 동일한 새 완료를 한 번 표시하되 각자 닫을 수 있다. 완료 기록을 불러오거나 나중에 참가한 사람에게 폭죽을 재생하지 않는다. 기존 저장에 완료 시점 통계가 없으면 현재 수치를 과거 통계처럼 채우지 않고 확인 가능한 완료/납품 기록만 표시한다.

## 10. 효과 줄이기와 성능

기존 감소된 동작 기획을 공통 적용한다. 효과 줄이기에서는 설치 반동·파편·폭죽·빛 회전·상하차 아이콘 비행·화면 전환을 생략하고 정적인 상태와 완료 카드로 같은 정보를 전달한다. 운영체제 감소된 동작 설정을 기본값으로 존중하고, 사용자가 게임에서 바꾸면 개인 설정으로 유지한다. 날씨 강도·음소거는 기존 설정을 유지한다.

가까이에서는 작업부·화물·작은 입자를 표시한다. 기존 축소 표시 단계에서는 작업부를 정적 그림으로 대체하고 장식 입자·상시 진행 막대를 숨기되 선택 테두리와 미연결/중단 표식은 작은 고정 형태로 남긴다. 더 먼 화면의 문제 밀도는 기존 운영 표와 함께 확인한다.

첫 상한은 화면 내 순간 장식 입자 128개, 별도 날씨 입자 256개다. 상한 초과 시 오래된 저우선 장식부터 생략하고 경고·선택·실제 벨트 아이템·실물 회수 더미는 생략하지 않는다. 숨긴 탭은 장식 생성을 멈추고 돌아왔을 때 밀린 효과를 재생하지 않는다. 게임 배속이 높아도 장식 수·효과음 빈도의 상한은 개인 화면 실제 시간으로 유지한다.

장식은 클라이언트에만 두며 공유 명령·생산 난수·게임 저장 해시·재고에 영향을 주지 않는다. 연구/목표 등 새 완료 사건은 ID로 중복 재생을 막고 초기 동기화에서는 기존 상태만 수신한다. 일시 효과 큐를 저장하지 않는다. 완료 사실과 요약 수치만 기존 실적 저장에 포함한다.

## 11. 구현 순서와 확인

1. 기존 설치·철거·연구 효과를 공통 사건에 연결하고 중복 소리·불러오기 재생을 막는다.
2. 기계 속도·정지와 트럭 적재율의 실제 값 연결, 상하차·충전 표현을 먼저 개선한다.
3. 전선·공급 면·축소 표시를 정리한 뒤 기존 날씨와 낮밤의 밀도를 조정한다.
4. 연구 카드·목표 묶음·허브 완료를 연결하고 효과 줄이기·큰 공장 부하를 확인한다.

검증할 장면은 다음과 같다. 연출 도입만으로 레시피·전력 반경·시간·운송 처리량을 바꾸지 않는다.
