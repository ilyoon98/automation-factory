# 자동화 공장 기획 통합 정리와 검토

2026-10-27 · 완제품 사용 계약까지 반영한 전체 검토 · 합의한 기준, 수정한 충돌, 남은 출시 범위

**여러 지역에서 자원과 중간재를 생산하고, 운송·전력망으로 연결해 최고 단계 부품을 허브에 납품하는 게임이다.** 생산 경로·비용·설비 연결과 완제품의 현지 사용 계약을 구체화했다. 하루 12분·날씨 확률·경제 비용안·모듈의 인접 창고 설치는 사용자 채택 기준이다. 설치·분리·고급 트럭 생성의 재료 소비와 실패 처리도 첫 구현 기준으로 정리했다. 출시 범위 선택과 실제 플레이 검증은 별도다. 아래 내용은 기획이며 게임 기능의 구현 완료를 뜻하지 않는다.

## 0. 전체 기획 기준

| 분야 | 현재 기획 기준 |
| --- | --- |
| 플레이의 중심 | 필요한 제품 선택 → 산지·공정 확인 → 현지 생산 → 운송·전력 연결 → 부족한 공정 개선 |
| 지도·산업 | 새 지도 256×256·지형 7종·RV00~07 목표별 공개, 신규 원자원 6종·총 신규 아이템 28종·신규 레시피 23개 |
| 설비 | 기존 29종 크기·연결 유지, 새 생산 6종·전력 5종. 대형 조립소 3×3·입력 6곳 |
| 진행 | 메인 36개·9장, 선택 도전 6개 후보. 메인 실적은 누적 보존하며 유지율·마감 조건 없음 |
| 최종 목표 | 자동화 설비 모듈 50개를 실제 허브 프로젝트에 납품. 선행에서 고급 트럭 사용·모듈 장착을 경험 |
| 비용과 목표 시간 | regional-v1 채택. 첫 자동화 5~8분·첫 배송 25~35분·첫 지역 조합 40~55분·최종 납품 4~5시간 |
| 물류 | 현지 실물 이동·인접 창고 도킹·품목별 예약·부분 적재·반송·현지 회수 |
| 전력 | 전봇대 연결 성분별 공유 망·현지 독립 시동. 부족은 같은 망에 적용, 터미널·망/선로 한도 삭제 |
| 운영 UI | 기본/전력/운송/자원/날씨 레이어와 생산·재고·운송 원인 추적. 예보 없음 |
| 기록 업적 | [record-v1 30종](업적-기록30종-구현기준.md)의 누적 17·속도 6·공장 7, 각 4단계 수치·고정 ID·판정·지원별 활성 목록 작성. 과거 구현 복원과 구분 |
| 기존 저장 | 기존 지도·가격·공통 전력·날씨·완료 실적 보존. 확장 규칙 자동 전환 없음 |

목표 시간은 설계 참고치이고 실제 플레이 검증 결과는 아니다. 업적 전체 116종·290기록은 후보 수이며, 미지원 도전·업적을 미완료 목록이나 완료율에 넣지 않는다.

운영 UI는 정확한 정보 표시를 우선하고 공장 계획은 플레이어가 직접 세운다. 생산량에서 기계/차량 수를 계산해 주는 도구, 재고 자동 추천·연구용 물량 자동 확보는 첫 범위에 넣지 않는다. 차량은 화물·배터리·실제 노선·대기 사유 표시와 기존 차량 추가 조작을 개선한다. 연구 완료는 기존 토스트·소리·허브 반짝임을 바탕으로 해금 정보를 보여 주는 축하 카드·짧은 픽셀 폭죽·빛 회전으로 보강한다. 세부 첫 연출안은 [운영 UI](지역-운영-UI-상세기획.md) §6.1·9.1을 따른다.

2026-10-30 연출 개선은 [공장·운송·완료 상세](공장-가동-운송-완료-연출-상세기획.md)를 따른다. 기계 실제 속도/정지·차량 상하차/충전·전선/공급 면·기존 날씨/낮밤·연구/허브 완료를 구체화했다. 허브 완료는 8초 카드와 완료 시점 경과 시간/생산 거점 수/납품량을 보여 주고 즉시 닫아 계속 건설할 수 있다. 비용·전력 반경·생산 규칙은 유지하며 반경 축소는 테스트 후보로 남긴다.

하단 건설 도구는 비용 상시 표시형을 사용한다. 자원 아이콘+개수와 건설 가능/연구 잠김/재료 부족을 구분하고, 조작 안내 대신 필요한 상태를 표시한다. 잠금·부족 항목의 정보 확인과 실제 건설 선택은 분리한다. 상단 되돌리기·다시 실행 버튼도 기능을 발견할 수 있도록 유지한다.

상단은 [줄 배치·앵커 상세](상단-UI-배치-앵커-상세기획.md)에 따라 일반 폭 2줄, 중간 폭 3줄로 나누고 작은 폭에서는 묶음을 세로로 옮긴다. 실제 상단 높이 아래 8px을 팝업·좌우 판의 시작점으로 사용하며 메뉴는 버튼 오른쪽, 연구 완료 카드는 화면 중앙에 맞춘다. 현재 구현은 별도이며 시안의 안내선은 배포 UI에 포함하지 않는다.

### 진행 시간과 경제의 기준안

[경제 상세](진행시간-경제-상세기획.md)의 1인·1배속 첫 플레이 기준안은 기어 자동화 5~8분, 첫 실제 배송 25~35분, 첫 지역 조합 40~55분, 최종 모듈 50개 납품 240~300분이다. 이 목표 시간은 실제 플레이 검증 전의 설계값이며 필수 마감이 아니다.

regional-v1 비용안은 사용자 채택 기준이다. 기존 연구 20종·산업 연구 8종의 비용과 새 설비 11종의 비용을 조정하고 기본 설비 단가는 유지한다. 첫 트럭 세트의 신규 철광석 예산은 1,144개다. 4.5시간 전체 사례는 연구·설비·51개 모듈·5개 트럭 조립품·완충 재고·운영 연료를 합쳐 철광석 13,884개·구리광석 6,519개·석탄 9,643개다. 선택 연구·발전·공유 창고·추가 생산에 따라 달라지는 기준 사례로 최소 필요량이나 모든 플레이의 지출 상한은 아니다.

초반 시작 자원을 넘는 철·석탄은 가까운 추가 광맥을 연결해 확보한다. 기준 생산만의 전력 예산과 달리 전체 건설 사례의 A 보조 공정은 1,275kW가 추가되므로 석탄 발전기 한 대를 추가한다. 가격·수량·범위의 상세는 경제 문서를 우선한다.

### 설비 연결과 표준 조립 셀

[설비 배치 상세](설비-입출구-배치-상세기획.md)에 기존 29종의 면적·연결 유지와 새 생산/전력 설비 11종의 면적·포트를 구체화했다. 대형 조립소는 3×3, 입력 6곳·앞 중앙 출력 1곳이며 권장 배선 셀은 11×11·일반 벨트 28칸이다. 설비 단가는 유지하고 터미널 삭제·전봇대 추가 수량은 경제 개정에 맞춘다. 포트는 재료 전용이 아니며 최종 창고에서 7종을 분리해 모듈용·트럭용 두 조립소에 공급한다. 이는 배치 설계이며 게임 구현 완료는 아니다.

### 완제품 현지 사용과 AI 작업 전달

[사용 계약](모듈-장착-트럭생성-상세기획.md)에 모듈 인접 창고 설치·현재 제작의 효과/잠금·완료 후 분리·작업 취소 현지 회수·고급 트럭 현지 조립을 정리했다. 고급 트럭은 현지 조립품 1개로 생성하며 0kJ에서 실제 충전한다. 차감과 결과 생성을 함께 확정하고 실패·중복 명령·저장 복구에서 재료를 중복 적용하지 않는다. 이 추가 기획으로 비용표·완제품 레시피는 바꾸지 않았다.

기존 코드 대비 추가·수정 내용만 AI에 전달할 때는 [AI 구현 변경 명세](AI-구현-변경명세.md)를 사용한다. 전체 확장 D01~D12, 이번 사용 계약만의 변경 요약, 현재 코드 연결 지점·단계별 확인·붙여 넣을 요청문을 분리했다.

## 1. 가장 먼저 지킬 방향

- 한 지역의 제품이 다른 지역의 재료가 되고, 기존 공장은 후반에도 공급자로 남는다.
- 현지 가공과 원료 운송 후 중앙 가공을 모두 허용한다. 각 지역에서 같은 공장 구성을 강제하지 않는다.
- 기계 레시피 재료·연구비의 허브 입고·최종 납품은 실제 운송이 필요하다. 건설·연구 비용 지불은 공용 허브 재고의 편의를 유지한다.
- 메인 목표는 생산·배송·사용·납품 누적 기록이다. 비율을 몇 분 유지하다 실패해 진행이 초기화되는 조건을 넣지 않는다.
- 전력은 지도 오버레이로 확인한다. 목표판의 전력 확인 버튼이나 필수 유지 과제로 만들지 않는다.
- 날씨는 현재 지역의 분위기와 가벼운 운영 변화를 만든다. 미래 기상 예보·기상 관측 연구는 제외한다. 적·제한 시간·건물 파괴·아이템 소실은 없다.
- 광맥 독립은 기존 저장과 선택 경로에 남기며 최종 목표로 강제하지 않는다.

## 2. 시작부터 최종 납품까지

| 구간 | 만드는 것과 행동 | 연결되는 다음 경험 |
| --- | --- | --- |
| 첫 자동화 | 철광석 → 철판 → 기어, 벨트로 허브 입고 | 방향·입출구·기본 발전 학습 |
| 기본 산업 | 구리선·강철·회로, 산림, 기본 차량 | 첫 외곽 자원지와 노선 연결 |
| 첫 지역 조합 | 주석 + 구리 → 청동, 청동 + 기어 → 구동부 | 서로 다른 산지의 재료 결합 |
| 숲 전기부품 | 수액 → 고무, 구리선과 절연 전선, 구동부와 모터 | 신자원 채취·가공 설비의 기반 |
| 제어·금속의 병행 확장 | 흙 정제로 양수기·벽돌 확보 후 석유·전해 금속 진입, 제어기·프레임 | 화산·염호·대형 설비 진입 |
| 강화 소재·축전 | 황 → 강화 고무·타이어·케이블, 염수 → 리튬·배터리·윤활제 | 송전·축전 선택과 고급 차량 |
| 복합 조립 | 여러 지역의 중간재로 고급 트럭·자동화 설비 모듈 제작 | 차량 사용·설비 개선·완제품 귀환 |
| 허브 프로젝트 | 최고 단계 설비 모듈 50개 실제 허브 납품 | 완성 연출 후 계속 건설·선택 도전·반복 연구 |

9장·메인 36개는 이 흐름을 안내한다. 연구 가지는 일부 병행 가능하며 장 번호 순서로 모든 기능을 잠그지 않는다. 최종 목표는 속도·동시 가동 거점 수 대신 허브 납품 완료량으로 판정한다. 앞선 학습 목표에서 생산 연결·차량 사용·설비 개선을 경험한다.

| 모래사막 | 원유·천연 모래, 유리한 태양광 | 플라스틱·제어기·윤활유·발전 연료 |
| 바위사막 | 보크사이트·석탄·돌 | 알루미늄·경량 프레임 |
| 화산 | 황·지열 분출구 | 강화 소재·케이블·전력 |
| 염호 | 리튬 함유 염수 | 리튬·배터리·고급 윤활제 |

지역별 가공품은 권장 배치다. 기본 광물은 여러 지형에서도 나오며, 조립 공장은 원하는 위치에 둘 수 있다. 새 지도는 256×256, 시작 자원·특화 자원·담수·공장 부지·첫 운송 경로를 보장한다. 기존 128×128 저장은 기존 지형·공통 전력·날씨 규칙을 보존한다. 기존 공장의 확장 전환은 첫 구현 필수 범위와 분리한다.

추가 설계는 원자원 6종·가공품 등 22종, 총 28아이템·23레시피·생산 설비 6종이다. 기존 27아이템을 포함하면 55종의 설계 범위다. 새 전력 설비는 생산 설비 6종과 별도로 센다. 산업 연구 T01~T08과 후반 생산망 확장 반복 연구를 구분한다. 기상 관측 연구는 제외한다.

## 4. 운송과 전력의 운영 원칙

공장 내부·근거리는 벨트, 거점 간 기본 안내는 트럭이다. 긴 벨트를 금지하거나 물리적으로 떨어진 창고를 자동 공유하지 않는다. 물·원유·염수는 첫 범위에서 아이템으로 운송하며 파이프는 후속이다.

기본 트럭은 적재 50·속도 4칸/초·배터리 1,800kJ, 고급은 100·5칸/초·3,600kJ다. 양 끝 충전 시 계획 편도 거리는 기본 96칸·고급 192칸으로 여유를 둔다. 배터리 소진 시 기존 25% 비상 주행을 유지한다. 노선 단절은 화물을 보존한 대기 상태다.

혼합 품목별 적재 상한·목적지 요청량·정기 출발·분산 출발·소수 잔여 이월이 필요하다. 기준 출발 주기는 120초이며 플레이어가 바꿀 수 있다. 도착 재고는 4분 소비량 또는 한 레시피분 중 큰 값, 출발 재고는 최소 2분 물량이다. 공급 부족·충전 대기·정류장 포화를 구분한다.

[전력망 연결·독립 시동 개정](전력망-연결-독립시작-개정.md)을 따른다. 전봇대·발전기·허브·변전소를 12칸 이하 전선으로 연결하면 하나의 망이다. 터미널·확장 한계·망/선로 처리 한도·선로 손실·방향 설정은 없다. 변전소는 반경 18칸에 넓게 공급한다. 발전량·축전 성능·거점별 충전 예산은 유지하며 연료 발전/잉여 축전도 같은 망에서 공유한다. 전력망과 운영 거점은 별개다.

지열은 분출구당 1,800kW, 축전기는 10MJ·충방전 200kW·충전 효율 95%다. 이 수치는 첫 밸런스안이다. 전력 부족은 해당 구역과 연결된 생산망에 영향을 주며, 지도 전체의 기계를 일괄 감속시키지 않는다.

## 5. 날씨와 UI

현지 날씨는 맑음·흐림·안개·비·눈·모래 바람·폭풍 7종이다. 하나의 기상 흐름을 지형에 따라 다르게 적용하며, 독립 지역 기상은 후속이다. 경과 시간에 따라 시작·종료 확률을 높이고, 시작 당첨 뒤 종류를 한 번 고르는 방식과 하루 12분을 채택했다. 주요 날씨 시작은 평균 약 4.3일, 일반 강수는 평균 약 1일이다. 흐림·안개·폭풍은 더 짧게 두며 같은 종류의 반복 가중치를 낮춘다. 예보·미래 날씨 카운트다운은 제공하지 않는다.

최저 트럭 속도는 짧은 폭풍의 ×0.8이며, 눈·모래 바람은 ×0.9다. 날씨와 무관하게 칸당 전기는 15kJ를 유지한다. 비에는 나무 성장과 풍력의 이점이 있고, 양수 처리량·가동 전력은 함께 ×1.2가 된다. 화산 태양광은 0, 지열은 날씨와 무관하다. 기계 레시피·벨트 속도를 날씨가 직접 바꾸지 않는다.

지도에서 `기본 / 전력 / 운송 / 자원 / 날씨`만 전환하고 카메라·선택·건설 도구는 유지한다. 전력 보기는 범위·연결·상태, 날씨 보기는 현재 날씨·발전 영향·도로 영향을 보여 준다. 현재 게임에 없는 온도·세균 레이어는 만들지 않는다.

P는 여러 거점의 생산·물류·전력을 비교하는 운영 개요, O는 메인 목표와 선택 도전, J는 업적이다. 메인 카드에는 현재 행동과 누적 수량을 표시한다. 최종 목표는 ‘허브 납품 12/50개’처럼 현지 재고·운송 중·완료를 분리한다. 픽셀 공장 스타일·갈무리 글꼴을 유지한다.

업적 116종·290기록은 후보 전체의 수다. 탐사 등 아직 지원하지 않는 기능의 업적은 비활성화하고 실제 완료율에서 제외한다. 숨은 업적 정답은 플레이어 UI에 노출하지 않는다. 시간형 심화는 선택 사항이며 미달 시 누적만 멈추고 이전 실적은 남긴다. 업적 보상으로 필수 생산 효율을 잠그지 않는다.

## 7. 정적으로 확인한 수량과 연결

메인 36개의 식별자·선행 중복·누락·순환을 검사했다. 수정 후에도 최종 MG36의 선행 그래프에 나머지 35개가 연결된다. 메인 표에는 시간·비율 유지 조건이 없다. 신규 23레시피와 기본 6경로의 투입·산출을 확인하고 대표 생산망 원료량을 다시 계산했다.

현재 코드의 일반 연구 20개·초기 해금·레시피·건설 비용을 읽고, 시작 재고 종류(철판·기어·돌)에서 각 산업 연구까지 가능한지를 별도로 계산했다. 수정한 T01~T08의 선행과 첫 생산품, 새 생산 설비 6종의 비용은 모두 도달 가능했다. 이 검사는 종류별 생산 가능성의 검사이며 유한 수량·발전·벨트 배치·연구에 걸리는 시간을 시뮬레이션한 것은 아니다. 지도 설계에는 실제 시작 수량인 철판 120·기어 40·돌 40도 명시했다.

후반 기준 15개 제품 노선은 기본 24대 또는 고급 17대다. 정상 연료 보급 2대·최종 허브 귀환 1대를 포함하면 기본 27대, 연결 전 시동 예비 1대까지 경제 최대 예는 28대다. 차량 대수는 최소 정답이 아니라 전용 노선·충전·적재 여유를 둔 사례다. 최장 편도 88칸은 기본 배터리 계획 96칸 안이고, 최신 날씨에서 보수적 왕복 86.2초로 정기 주기 120초 안이다. 실제 교차로·대기열 검증은 남아 있다.

8거점의 기본 작업 부하는 정수 설비 대수에서 계산했다. 양수기의 날씨 부하와 구역별 차량 충전은 별도 포함하며, 태양광·풍력·지열의 설치 용량과 실제 공급을 구분한다. 개정된 무손실 연결 망의 공급/소비와 거점별 충전 예산을 적용한다.

이 검토는 문서 수치·선행 관계의 검사다. 실제 게임 생성·운행·멀티플레이·프레임 성능·플레이 난이도를 통과한 결과는 아니다.

설비 배치 이후 전체 재검토에서도 메인 36개 모두가 MG36의 선행 그래프에 연결되고, 신규 23개·기존 기본 6개 레시피의 첫 생산 경로와 산업 연구 8단계에 순환이 없음을 확인했다. 재료 종류 수는 각 기계의 입력 접점 수 안에 있었다. 현재 코드의 아이템 27종과 새 레시피의 추가 28종을 대조해 합계 55종, 기존 건물 29종·새 생산 6종·전력 5종의 현재 범위를 확인했다.

기준 노선 15개의 품목 합계·도로 거리·2분 운반량과 기본 24대/고급 17대 사례를 다시 확인했다. 이전 검토의 비용 60행·수량 36행은 당시 터미널 포함안이었다. 전력 개정 뒤 비용 58행·수량 35행과 원료 예산을 재검산했다. 날씨의 반복 완화를 포함한 평균 시작 간격은 4.28857일·51.4629분, 일반 강수 평균은 12.1729분으로 현재 요약과 맞는다. 이는 수학적 평균과 문서 검산이며 실제 경로 지연·제작 대기·체감 난이도의 실측은 아니다.

## 8. 남은 기획 결정과 구현 검증

### 8.1 아직 정해야 할 사항과 권장 순서

| 결정 시점 | 결정할 항목 | 정해진 부분과 남은 부분 |
| --- | --- | --- |
| 첫 출시 범위 선정 | 활성 도전·업적과 보상 | 후보 116종·290기록 중 기록 30종은 record-v1의 수치·ID·지원별 활성 26/29/30종·기록/도장 보상까지 구체화. 나머지 86종의 출시 활성 목록·추가 외형은 선정 필요. CG06은 양방향 실제 배송 지원 조건 적용 |
| 후속 환경 확장 전 | 추가 환경 이벤트 | 첫 범위는 기존 날씨 7종·낮밤으로 선정. 오로라·반딧불이·별도 물안개 이벤트와 평온 중 빈도는 후속 |
| 엔딩 이후 확장 구현 전 | 특화 자원 소진·반복 연구 상한 | 첫 매장량·추가 자원지는 정해짐. 지도 전체 고갈 뒤 보충 수단과 반복 연구 단계 상한·효과 상한은 미정. 현재 납품 엔딩의 선행은 아님 |

모듈의 인접 창고 설치는 사용자 채택으로 결정 항목에서 제외했다. 설치·분리·현재 배치의 잠금·작업 취소·창고 선택·실적 판정은 [사용 계약](모듈-장착-트럭생성-상세기획.md)을 구현해 검증한다. 일반 입력구의 용도나 장착 방식을 다시 미정으로 돌리지 않는다.

고급 트럭도 실제 공급 위치·출고 예약·접도·생성 실패·중복 수신·초기 충전과 현지 철거를 같은 계약으로 구체화했다. 추가 금속 비용·자동 기본 차량 교체는 없으며, 새 고급 차량은 화물 0·노선 미지정·0kJ로 생성한다. 기존 기본 차량의 생성·원가·초기 충전·되돌리기는 보존한다.

일반 강수의 세기 연출 분포 등 이미 적은 밸런스 초안은 첫 적용값으로 두고 검증한다. 하루 길이와 날씨 발생 방식을 다시 결정해야 하는 상태는 아니다. 기존 저장의 지도·전력 전환, 계절·독립 기상·온도·세균·파이프·탐사는 첫 구현과 분리한 후속 범위다.

회수·운송은 [물류 운영 규칙](물류-회수-운영규칙.md), 진행 시간·총비용·매장량 검산은 [경제 상세](진행시간-경제-상세기획.md), 입출구와 조립 셀은 [설비 배치 상세](설비-입출구-배치-상세기획.md), 완제품의 실제 사용은 [설치·생성 계약](모듈-장착-트럭생성-상세기획.md)을 구현해 검증한다. 완료 화면과 기존 기능의 표현은 [연출 상세](공장-가동-운송-완료-연출-상세기획.md)에 첫 값을 정했고 가독성·밀도·성능을 구현 후 확인한다. 남은 기획은 활성 도전·업적과 장기 자원/반복 연구를 우선한다. 목표 시간·가격·매장량·발전량을 플레이 없이 다시 미정으로 돌릴 필요는 없으며 시제품 결과를 근거로 함께 조정한다.

### 8.3 구현을 시작할 수 있는 범위

1. 기존 저장을 열어도 바뀌지 않는 규칙 프로필과 실물 수량·소비 사건의 저장 틀을 잡는다. 신규 아이템·레시피·설비 데이터와 접점 표시도 이 틀에서 확장한다.
2. 새 지도에서 철판·기어 → 첫 트럭 → 주석·청동 구동부까지 한 번 실제로 연결한다. 생산 재료의 현지 공급, 충전·예약·반송·현지 회수와 필요한 UI를 함께 검증한다.
3. 숲 모터 → 석유/전해 금속 → 황/리튬으로 확장하며 전력 구역·날씨·송전·출처 실적을 실제 공장에 연결한다. 모든 운영 UI를 마지막 작업으로 미루지 않는다.
4. 대형 조립소 두 제품, 고급 트럭 실제 사용, 확정한 방식의 모듈 장착, 허브 50개 납품을 연결한다. 이때 4~5시간 목표와 전체 비용 사례를 실제 플레이에서 검증한다.
5. 활성 업적·완료 연출·접근성·큰 지도 성능을 마무리한다. 독립 지역 날씨·계절·온도/세균·파이프·탐사·교역·기존 공장 확장 전환은 별도 후속으로 둔다.

새 확장 세계의 [목표별 지도 공개](지도-목표별-공개-상세기획.md)는 MG03 외곽·MG07 눈밭·MG08 숲·MG14 두 사막·MG19 화산·MG20 염호·MG28 전체 공개를 사용한다. 첫 트럭은 초원 안에서 배송하고 첫 목재는 시작 나무를 사용한다. 이전 전체 공개 시제품안은 이 안으로 대체하며 탐사 보고서/드론과 구분한다. 지도 생성·실제 경로·플레이 시간 검증은 남아 있다.

지도 공개 이후 전체 의존 관계를 다시 본 결과는 [지도·연구·생산 통합 검토](지도-연구-생산-진행-통합검토.md)에 있다. 7가지 분기 진행에서 MG36까지의 경로와 RV07 이전 첫 자원지 수지를 확인했다. MG28 수신 준비·MG29 첫 조립·T08과 MG32 선행 구분을 보완했다. 별도 확장 구현의 이전 공개 규칙은 구현 동기화 항목이며 실제 플레이 통과로 간주하지 않는다.
