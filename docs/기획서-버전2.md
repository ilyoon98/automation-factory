## 1. 게임 개요

**탑다운 2D 그리드에서 광물을 캐고, 레시피 체인을 따라 가공하고, 생산 비율이 안 맞아 생기는 잉여를 돌려 쓰며 공장을 키우는 힐링형 자동화 게임.** 친구와 같은 공장을 같이 지을 수도 있다. 최종 목표는 유한한 광맥과 석탄에서 벗어나 흙·물·햇빛만으로 공장을 돌리는 "광맥 독립"이다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 생산 체인 자동화 (Factorio 계열을 작게) |
| 테마 · 시점 | 따뜻한 공방 (나무·놓쇠·벽돌 기계) · 탑다운 그리드, 기계는 3/4 시점 |
| 플랫폼 | 웹 브라우저, Windows exe (Electron) |
| 인원 | 혼자 또는 같은 와이파이·랜선의 여러 명 |
| 기술 | Vite + TypeScript + Canvas 2D, 게임 엔진 없음 |
| 맵 | 128×128 칸, 시드 고정 생성, 허브가 가운데 |
| 규모 | 아이템 21종, 건물 24종, 레시피 16개, 연구 15개 + 끝없는 연구 4줄, 목표 가이드 24단계 |
| 상태 | 0.2.0 배포 (깃허브 릴리스, exe는 게임 안에서 업데이트). 처음부터 최종 목표와 끝없는 연구까지 플레이 가능, 같이 하기 동작 |

## 2. 기획 의도

노린 경험은 "**제한 시간도 적도 없이, 내가 만든 물건으로 공장이 스스로 커지는 걸 보는 재미**"다. 압박은 적이 아니라 자원에서 오고, 버전 2에서는 여기에 "친구와 같이 짓는 재미"를 더했다.

### 핵심 재미 5가지

1. **레시피 트리**: A로 B를, B로 C를, A와 B로 D를 만든다. 철판은 기어·강철·회로에 다 들어가서 한 자원을 여러 라인이 나눠 쓴다.
2. **비율 퍼즐**: 기계마다 제작 시간이 달라(채굴 1초, 제련 2초, 기어 3초, 강철 5초) 개수가 딱 맞지 않는다. 남는 잉여를 다른 라인으로 돌리고 모자란 곳을 채우는 설계가 핵심이다. 공장 통계가 "제련로 약 2대 더"처럼 답을 도와준다.
3. **공장이 공장을 짓는다**: 돈이 없다. 건물과 트럭은 생산품으로만 짓는다.
4. **힐링형 압박**: 기한·주문·적이 없다. 광맥이 유한해서 가까운 광맥이 줄면 트럭으로 먼 곳을 잇고, 결국 흙 정제와 재생 에너지로 넘어간다. 바닥나기 전에 미리 알려 주어 당황하지 않게 했다.
5. **같이 짓기**: 같은 와이파이의 친구가 주소 하나로 들어와 허브 재고와 연구를 함께 쓴다. 한 사람은 흙 공장을, 다른 사람은 트럭 노선을 맡는 식으로 일을 나눌 수 있다.

### 분위기

금속과 연기의 차가운 공장 대신, 크림색 땅에 나무·놓쇠·벽돌 기계가 돌아가는 **따뜻한 공방**을 노렸다. 힐링형이라는 설계를 그림과 소리에서도 느끼게 하려는 것이다 (6장). 소리도 나무 블록이 "톡" 놓이는 짧고 부드러운 효과음과 조용한 칼림바 배경음이다.

### 목표 플레이어

- 자동화 게임을 좋아하지만 Factorio의 적 방어나 제한 시간이 부담스러운 사람
- 같은 공간에 있는 친구와 가볍게 같이 할 게임을 찾는 사람 (서버·계정 없이)

## 3. 핵심 게임 루프

루프의 끝이 다시 시작으로 이어진다. 허브에 모인 생산품이 곧 건설 재료이자 연구 비용이라, 만든 만큼 공장이 커진다.

```
채굴 ───▶ 운반 ───▶ 가공 ───▶ 허브에 모으기 (창고 = 건설 재료)
 ▲      광맥→흙·물·햇빛   컨베이어·트럭   제련로·조립기 등        │
 │              ▲                 │                              ├──▶ 연구 (재료 내고 해금)
 │              └─ 잉여는 분배기로 다른 라인에 ─┘                └──▶ 건설 (허브 재고로 짓기)
 │                                                                     │
 └──────────────────── 공장이 공장을 짓는다 ◀──────────────────────────┘
```

루프 안에 작은 루프가 하나 더 있다. 기계마다 속도가 달라 생기는 잉여를 분배기·분류기로 다른 라인에 돌리는 것이 매 단계의 퍼즐이다.

게임 전체로 보면 네 단계로 흐르고, 최종 목표 뒤에는 끝없는 연구가 이어진다. 단계마다 운송 방식이나 자원이 바뀌어 기존 설계를 다시 고민하게 만든다.

| 단계 | 하는 일 | 느낌 |
| --- | --- | --- |
| 초반 | 시작 광맥 → 철판·구리판·기어 | 빠르게 첫 자동화 라인 세우기 |
| 중반 | 석탄 발전, 강철·회로, 공장 키우기 | 연구마다 기계를 몇 대씩 늘려야 한다 |
| 중후반 | 가까운 광맥 고갈 → 트럭으로 먼 광맥 잇기 | 경고를 보고 미리 노선 준비 |
| 후반 | 흙 → 광물 가루 → 정광 → 철판, 태양광·수력·전기로 | 광맥·석탄 없이 도는 "광맥 독립" |
| 그 뒤 | 끝없는 연구로 채굴·기계·컨베이어·트럭을 단계마다 10% | 다 이룬 뒤에도 공장을 계속 키울 이유 |

흙 라인 하나(채굴기 → 분쇄기 → 세척기 → 분리기)는 철판을 분당 약 7개 만든다. 광맥 채굴기 1대(분당 30)를 대신하려면 이 라인이 4개쯤 필요해서, 후반은 일부러 크고 복잡한 공장을 요구한다.

## 4. 주요 시스템 설계

### 4.1 허브

허브(3×3)는 맵 가운데 하나뿐이고 **창고 + 건설 자재 공급원 + 연구 비용 창구**를 한꺼번에 맡는다. 모든 라인의 끝이 한 곳으로 모여서 "어디로 보내야 하지"를 고민할 필요가 없다.

- 컨베이어나 내리기 정류장으로 넣은 아이템이 허브 재고에 쌓이고, 아이템별 분당 입고량을 보여 준다.
- 건물을 놓으면 재고에서 재료가 빠지고, 철거하면 건설비와 안에 든 아이템이 100% 돌아온다.
- 기본 전력 300kW를 준다. 시작 재고는 철판 120, 기어 40, 돌 40.
- 같이 하기에서는 모두가 한 허브 재고를 같이 쓴다.

### 4.2 자원과 광맥

광맥은 유한하고, 돌·흙·물만 무한이다. 이 차이가 게임 전체의 진행 압박이다.

| 지형 | 매장량 | 캐는 법 |
| --- | --- | --- |
| 철광맥 · 구리광맥 · 석탄 광맥 | 유한. 시작 광맥 칸당 600\~700, 먼 광맥 칸당 300 + 거리×8 | 채굴기 (분당 60), 고급 채굴기 (분당 120) |
| 돌 광맥 | 무한 | 채굴기 |
| 빈 땅 | 무한 (흙) | 흙 정제 연구 후 채굴기 |
| 호수 | 무한 (물) | 양수기 (분당 120). 호수 위엔 양수기만 |

- **광맥 전체에서 캐기**: 이어진 같은 광석 칸들이 한 광맥이다. 채굴기는 어디에 놓든 그 광맥 전체에서 캐고, 가장자리부터 옛어지다 사라진다. 픽셀아트에서는 칸 위 돌 개수(3·2·1개)로 남은 양이 보인다.
- **먼 광맥을 줄인 이유**: 처음엔 먼 광맥이 시작 광맥의 40배가 넘었다. 개수 28 → 20, 칸당 800 + 거리×40 → 300 + 거리×8로 줄여 약 6\~19배로 맞췄다. 그래야 트럭과 흙 정제로 넘어갈 이유가 생긴다.
- **고갈 경고**: 광맥마다 "바닥까지 남은 시간 = 남은 양 ÷ 그 광맥 채굴기들의 실제 생산 합"을 계산한다. 10분 안이면 "곧 바닥"으로 알리고, 왼쪽 "⚠ 광맥 경고" 목록·채굴기 위 노란 !·지도 동그라미로 보여 준다. 힐링형이라 갑자기 멈추는 일을 없애려는 장치다.
- 도감 광맥 페이지에 "이 맵의 철광맥" 목록(허브에서 가까운 순, 남은 양, 📍 가기)이 있어 트럭으로 이을 다음 광맥을 고를 때 쓴다.

### 4.3 아이템과 레시피

초반 레시피는 단순한 사슬이고, 후반 흙 정제는 일부러 다단계·부산물이 많은 공정이다.

| 결과물 | 재료 | 시간 | 기계 |
| --- | --- | --- | --- |
| 철판 / 구리판 | 철광석 1 / 구리광석 1 | 2초 | 제련로 |
| 강철 | 철판 2 + 석탄 1 | 5초 | 제련로 |
| 강철 | 철판 2 (석탄 없이) | 5초 | 전기로 |
| 기어 | 철판 2 | 3초 | 조립기 |
| 구리선 ×2 | 구리판 1 | 1.5초 | 조립기 |
| 회로 | 철판 1 + 구리선 3 | 4초 | 조립기 |
| 자갈 1 + 모래 1 | 흙 2 | 2초 | 분쇄기 |
| 모래 / 자갈 ×2 | 자갈 1 / 돌 1 | 1.5초 / 2초 | 분쇄기 |
| 광물 가루 1 + 진흙 1 | 모래 3 + 물 2 | 3초 | 세척기 |
| 철 정광 / 구리 정광 / 슬래그 (10개마다 7·2·1) | 광물 가루 1 | 4초 | 분리기 |
| 철판 / 구리판 | 철 정광 1 / 구리 정광 1 | 2초 | 제련로 |
| 벽돌 | 진흙 2 | 3초 | 제련로 |
| 콘크리트 | 슬래그 2 + 자갈 1 | 3초 | 조립기 |

- **석탄의 이중 역할**: 강철 재료이면서 발전기 연료다. 한 자원을 두 시스템이 나눠 쓰게 해서 분배 고민을 만든다. 후반에는 전기로와 재생 에너지로 석탄에서도 독립한다.
- **섞여 나오는 결과물**: 분쇄기·세척기·분리기는 여러 결과물이 한 줄로 섞여 나온다. 스마트 분류기로 나누는 것 자체가 후반 퍼즐이다.
- **분리기는 고정 순서**: 확률이 아니라 10개마다 정확히 7·2·1. 비율 계산이 항상 맞아 설계를 믿고 짤 수 있다.
- **부산물을 버리지 않는다**: 진흙은 벽돌로, 슬래그는 콘크리트로 쓴다. 벽돌은 태양광·수력·전기로의 건설 재료다.

| 허브 | 300kW | 없음 | 1 |
| 태양광 패널 | 100kW | 없음 | 1 |
| 수력 발전기 | 600kW | 물 (1개 = 300kJ, 양수기 1대분) | 2 |
| 석탄 발전기 | 900kW | 석탄 (1개 = 4000kJ) | 3 |

- **쓰는 순서**: 공짜인 허브·태양광을 먼저, 그다음 수력, 석탄은 마지막까지 아낀다. 재생 에너지를 놓을수록 석탄이 강철 쪽으로 남는다.
- **석탄 독립**: 철·구리는 흙에서 무한으로 얻지만 석탄은 광맥뿐이라, 석탄이 바닥나면 강철과 발전이 멈춘다. 그래서 태양광·수력·전기로(철판 2 → 강철 1, 450kW)를 넣었다. 세 건물 모두 강철·석탄 없이 지을 수 있어, 석탄이 이미 바닥났어도 다시 시작할 수 있다. 수력 발전기는 나무 물레방아라 목재 20이 들고, 그래서 재생 에너지 연구는 산림 뒤다.
- 기계별 소비: 채굴기 90 · 제련로 90 · 조립기 75 · 분쇄기 120 · 세척기 150 · 분리기 300 · 전기로 450 · 양수기 60 · 고급 채굴기 180 (kW).

### 4.5 물류

컨베이어는 1차선이고, 입출구 방향이 정해져 있다 (노란 화살표 = 출구, 흰 화살표 = 입구). 규칙을 적게, 눈에 보이게 만드는 게 목표다.

| 건물 | 하는 일 | 노린 점 |
| --- | --- | --- |
| 컨베이어 | 초당 1.5칸, 칸당 2개까지 쌓음 | 기본 운송 |
| 고속 컨베이어 | 초당 2.25칸, 칸당 4개까지 | 일반 위로 드래그하면 아이템 그대로 교체 |
| 지하 컨베이어 | 최대 4칸 건너 지나감 | 라인 교차, 호수·도로 건너기 |
| 분배기 | 앞·양옆에 번갈아 | 생산량 나누기 |
| 우선 분배기 | 앞 먼저, 막히면 양옆 | 잉여 넘기기 |
| 스마트 분류기 | 고른 아이템은 앞, 나머지는 양옆 | 섞인 줄 나누기. 고를 목록은 줄을 거꾸로 따라가 찾은 기계가 만드는 것만 |
| 병합기 | 뒤·양옆으로 받아 번갈아 앞으로 | 꽉 찬 두 줄을 반반 섞기 (측정 56 대 53) |
| 창고 | 200개, 붙이면 최대 3×4개(2,400개)가 한 창고 | 중간 저장소 |
| 하역기 | 0.5초마다 앞 칸 하나만큼 꺼냄. 아이템을 안 고르면 전부 번갈아 | 허브·창고에서 다시 꺼내기 |

- **컨베이어 쌓기**: 막혔을 때만 한 칸에 쌓이고 술술 흐를 땐 하나씩 간다. 분배기·병합기·분류기는 한 칸을 통째로 넘기고, 받는 쪽이 덜 받으면 남은 건 그 자리에서 기다린다. 개수는 항상 그대로다.
- **창고 합치기**: 빈틈없는 직사각형으로 붙은 창고는 큰 창고 하나로 보이고 쓰인다. 아무 칸에나 넣고 아무 칸에서나 꺼낸다.

### 4.6 차량 운송

컨베이어 = 가까운 대량 운송, 트럭 = 먼 거리 운송으로 역할을 나눴다. 가까운 광맥이 바닥나면 먼 광맥을 컨베이어로 길게 잇는 대신 트럭 노선을 만든다.

| 것 | 비용 | 하는 일 |
| --- | --- | --- |
| 도로 | 돌 1 | 드래그로 깔고, 트럭만 다닌다. 컨베이어와는 지하 컨베이어로 교차 |
| 정류장 (2×2) | 철판 20 · 기어 10 · 강철 5 | 싣기(컨베이어로 받아 200개까지 쌓음) 또는 내리기(앞으로 내보냄). 허브·창고에 붙이면 저절로 내리기 |
| 트럭 | 강철 10 · 기어 10 · 회로 5 | 50개 실음, 초당 4칸, 싣고 내리기 초당 10개. 노선(정류장 2~8곳)을 차례대로 자동으로 돈다 |

- 트럭은 가득 차거나 5초 동안 새 짐이 없으면 출발한다. 한 정류장에 여럿이 서 있으면 먼저 온 트럭부터 가득 채워 보낸다. 서로 다른 짐만 싣는 트럭끼리는 같이 싣는다.
- **노선**: 트럭마다 정류장 2\~8곳과 곳마다 싣기·내리기, 싣는 곳이면 실을 짐(기본 아무거나)을 정한다. 위에서 아래로 돈 뒤 처음으로 돌아간다. 처음 만들면 싣는 곳 → 가장 가까운 내리는 곳 두 곳 노선이다. 여러 광맥에서 모아 허브에 내리는 일을 트럭 한 대가 한다.
  - 싣는 곳: 빈 채로는 기다리지만, 노선의 다른 싣는 곳에 실을 짐이 있으면 5초 뒤 빈 채로 넘어간다 (빈 바퀴는 돌지 않음). 이미 가득이면 들르기만.
  - 내리는 곳: 다 내리면 다음으로. 꽉 차면 기다리지만, 노선에 다른 내리는 곳이 있으면 남은 짐을 싣고 넘어간다.
  - 트럭 정보창에서 정류장을 더하고 빼고 순서를 바꾼다. 맵에는 정류장마다 "1 싣기 철광석 · 3 내리기"처럼 차례와 할 일이 뜬다.
- **전기 트럭**: 배터리 1,800kJ로 120칸을 가고, 정류장에 서 있는 동안 공장 전력으로 충전한다 (한 대 200kW, 빈 배터리 → 가득 9초). 떠날 때가 돼도 다 찰 때까지 충전하고, 배터리가 떨어지면 멈추지 않고 1/4 속도로 간다. 충전도 전력 수요에 들어가서 모자라면 기계처럼 느려진다.
  - 석탄 연료 대신 전기로 한 것은 최종 목표 "석탄 독립"과 맞추려는 것이다. 태양광·수력으로 가면 트럭도 석탄 없이 돈다.
  - 정보창에 노선 길이와 가장 긴 구간이 배터리로 충분한지 나온다. 더 먼 길은 중간 정류장에서 갈아싣는다.
- 트럭은 칸을 차지하지 않고 서로 겹쳐 지나간다. 교통 체증으로 막히는 일을 없애서 힐링형에 맞춘 것이다.
- 멈춘 이유(길 없음, 내릴 곳이 꽉 참, 배터리 없음 등)는 트럭 위 !와 정보창으로 보여 준다. "같은 노선으로 한 대 더" 버튼으로 운송량을 쉽게 늘린다.

### 4.7 연구와 밸런스

연구 15개는 허브 재고에서 재료를 내고 즉시 해금한다. 기한도 대기 시간도 없다.

| 단계 | 연구 (비용) | 해금 |
| --- | --- | --- |
| 초반 | 조립 자동화 (철판 40) | 조립기, 기어 |

- **비용을 4\~5배로 올린 이유**: 버전 1에서는 연구 전부의 원료가 철광석 1,340개 정도였다. 허브 근처 철광맥(약 25,000)이 끝까지 안 바닥나서, 공장을 거의 키우지 않아도 1시간이면 최종 목표였다. 트럭·흙 정제가 필요할 일도 없었다.
- 지금은 중반 연구 하나가 제련로 8대·조립기 4대로 5\~6분, 최종 목표는 흙 공장을 크게 지어야 15\~25분이다. 가까운 광맥은 차량 운송·흙 정제 무렵에 바닥나기 시작한다.
- 첫 연구는 빠른 시작을 위해 그대로 두었고, 콘크리트는 오히려 줄였다 (개당 흙 122개라 40개는 분리기 한 대로 50분이 넘는 지루한 구간이었다).

## 5. 같이 하기

같은 와이파이·랜선에 있는 친구가 **주소 하나로 들어와 같은 공장을 짓는다.** 계정·외부 서버 없이, 방장 PC가 서버가 된다. 힐링형 게임이라 경쟁이 아니라 협동만 넣었다.

### 들어가는 법

1. 방장이 위쪽 "👥 같이 하기 → 방 만들기". 지금 내 공장으로 방이 열린다.
2. "주소 복사"로 초대 주소(`http://192.168.x.x:5173/?join`)를 보내면, 열기만 해도 참가한다.
3. exe끼리는 주소가 필요 없다. 방이 열리면 1초마다 같은 와이파이에 신호를 뿌려 다른 PC의 방 목록에 저절로 나타난다.

### 함께 쓰는 것과 각자 쓰는 것

| 함께 | 각자 |
| --- | --- |
| 공장(맵), 허브 재고, 연구, 목표 | 되돌리기(자기가 한 것만), 카메라, 들고 있는 도구 |
| 저장·새 게임·게임 속도 (방장 기준) | 나가면 돌아가는 자기 공장(자기 저장) |

### 서로 보이게

같이 짓는 재미는 "저 사람이 지금 뭘 하는지"가 보여야 산다.

- 다른 사람의 커서·이름표, 들고 있는 건물(점선 고스트), 드래그 중인 복사·철거 영역이 보인다. 지도에도 점으로.
- **핑**: F 키 또는 Alt + 클릭. 화면 밖이면 가장자리에 화살표.
- **채팅**: Enter로 입력하면 메시지가 화면을 오른쪽에서 왼쪽으로 흘러가다 사라진다 (한 줄 60자). 채팅창을 따로 두지 않고 공장 위에 흘려서, 화면을 가리지 않고 가볍게 말을 건다. 보낸 사람 이름은 커서와 같은 색. 놓쳤으면 입력창을 열 때 위에 최근 6줄이 보인다.
- 방 창에서 접속자 목록(보기 = 그 사람 커서로 이동)과 내 이름 바꾸기.

### 끊겨도 괜찮게

- 방장이 새로고침하거나 잠깐 끊기면 방이 저절로 다시 열리고 손님도 저절로 다시 들어온다.
- 2초마다 모두의 공장이 같은지 확인하고, 어긋나면 손님이 방장 공장을 다시 받는다 (구현은 8장).

## 6. 아트 방향

그림은 **1칸 = 16픽셀 픽셀아트**, 팔레트는 **따뜻한 공방**이다. 크림색 땅 위에 나무·놓쇠·벽돌로 만든 기계가 돌아간다. 힐링형 설계를 화면에서도 느끼게 하려는 선택이다.

### 원칙

- **그림은 전부 코드로**: 이미지 파일 없이 코드가 그린다. 마음에 안 드는 것만 직접 그린 PNG로 하나씩 바꿔 끼울 수 있다 (같은 이름·크기로 `public/sprites/`에 넣고 목록에 적기).
- **UI도 픽셀**: 갈무리 픽셀 글꼴(무료 글꼴, 인터넷 없이도 됨)과 두꺼운 잉크 테두리, 둥근 모서리 없음. 판은 크림색 종이.
- **모양으로 읽히게**: 모든 테두리와 글씨는 짙은 갈색 잉크(`#3b2716`). 빛은 늘 왼쪽 위.
- **몸체는 돌리지 않는다**: 기계를 돌려도 그림은 그대로고 방향은 입출구 화살표(노랑 = 출구, 흰색 = 입구)로만 보인다. 컨베이어·지하 컨베이어·트럭만 방향대로 그린다.
- **2×2 기계는 3/4 시점**: 윗면과 앞면이 보이고, 앞면 이름표에 만드는 아이템, 오른쪽 아래에 진행 막대가 있다. 맵을 훑어보기만 해도 무엇을 만드는 공장인지 알 수 있다.
- **일하는 게 보이게**: 멈춤 1프레임 + 일할 때 4프레임 (전력 부족이면 반 속도). 드릴 회전, 제련로 불꽃, 물레방아, 컨베이어 흐름, 허브 굴뚝 연기.
- **짓고 허무는 게 보이게**: 건물이 생기면 놋쇠색 테두리가 반짝이고 모래 먼지가 튄다. 철거하면 나무 조각이 흩어진다. 같이 하는 사람이 지은 것도, 되돌리기도 보인다 (화면에만, 0.45초).
- 정보창 제목 옆에는 그 건물·트럭 그림을 작게 둔다.

### 팔레트

| 재료 | 쓰는 곳 |
| --- | --- |
| 나무 | 채굴기, 창고, 세척기 |
| 놓쇠 | 고급 채굴기, 톱니, 리벳 |
| 금속 | 분리기, 전기로, 드릴 날 |
| 벽돌 | 제련로, 허브 지붕·굴뚝 |
| 물 | 호수, 양수기, 세척기 |
| 노란 화살표 `#ffd34d` | 출구 (어느 바탕에서도 눈에 띄게) |

광맥 칸은 광물마다 다른 흙색 위에 돌을 올리고, 남은 양에 따라 돌이 3·2·1개로 줄어든다. 고갈을 숫자보다 땅 모양으로 먼저 느끼게 했다.

### 또렷하게 보이게

- 줌은 단계로만 (그림 1픽셀 = 화면 0.5·1·2·3…픽셀). 어느 줌에서도 픽셀이 뭉개지지 않는다.
- 멀리 볼 때(0.5 단계)는 바닥을 단색으로, 건물은 절반으로 줄인 그림으로 그리고 작은 덧그림은 뺀다. 큰 공장 전체를 봐도 지저분하지 않고 빠르다.
- 확인용 페이지 `/sprites.html`(그림 목록)과 `/scene.html`(모든 건물을 늘어놓은 시험용 맵)으로 그림을 한눈에 점검한다.
- 화면 배율이 125%·150%처럼 정수가 아니면 픽셀 글꼴이 살짝 흐리다. 도움말의 **"글자 또렷하게"**(기본 꺼짐)를 켜면 맵을 뺀 UI를 정수 배율에 맞춰 또렷하게 한다 (125% → 100% 크기, 150% → 넓은 화면은 200%, 좁으면 100%). 크기가 바뀌니 고르게 했다.

### 소리

그림처럼 **소리 파일 없이 코드로** 그 자리에서 만든다 (Web Audio). 나무 공방에 맞게 짧고 부드럽게.

| 소리 | 언제 |
| --- | --- |
| "톡" (셰퍼드 음) | 짓기. 끌어서 연달아 지으면 뒤에서 셰퍼드-리셋 글리산도가 일정한 속도로 끝없이 오르고, 톡은 그 높이를 온음 계단에 맞춰 낸다 |
| "퉁" · "틱" | 철거 · 회전 |
| 낮은 두 음 | 못 지을 때 (처음 클릭만) |
| 도-미-솔 · 종 4음 | 연구 완료 · 목표 달성 |
| "빵빵" | 트럭 만들기 |
| 짧은 음 | 되돌리기 · 다시 하기, 다른 사람 채팅 |
| 배경음 | 70 BPM C장조. 두 마디마다 바뀌는 화음 위에 칼림바 같은 멜로디가 띄엄띄엄. 끝없이 새로 만든다 |

- **내가 한 일에만** 효과음이 난다. 같이 할 때 남이 짓는 소리까지 나면 시끄럽다 (채팅만 남의 것도).
- 위쪽 🔊로 모두 켜고 끄고, 도움말에서 효과음·배경음 음량을 따로 (기본 60% · 35%). 창을 내려 두면 배경음은 쉰다.
- 짓는 소리의 셰퍼드 음: 한 옥타브씩 떨어진 사인파 8개를 가운데(도)가 가장 크게 섞어서, 맨 위로 간 음은 사라지고 맨 아래에서 다시 커진다. 처음엔 짓는 소리마다 한 칸씩 올렸는데 마우스를 들쭉날쭉하게 끌면 오르는 느낌이 깨져서, 짓는 빠르기와 상관없이 일정하게 오르는 글리산도를 깔았다.

## 7. 조작과 UI

조작은 **마우스 중심**이고, 키보드는 빠르게 하고 싶은 사람을 위한 단축키다. 버전 2에서는 실수를 되돌리고 큰 공장을 한눈에 보는 도구를 더했다.

### 조작

| 입력 | 동작 |
| --- | --- |
| 좌클릭 / 드래그 | 건물 배치, 컨베이어·도로 연속 배치 / 빈손이면 정보창 |
| 우클릭 (드래그) | 철거, 재료 100% 환급 |
| Ctrl + 우클릭 드래그 | 사각형 영역 한 번에 철거 (붙여넣기 대기 중에는 우클릭 = 취소) |
| Ctrl + 드래그 → 클릭 | 영역 복사 → 붙여넣기 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 하기 (100단계) |
| R / Shift+R | 회전 |
| Q | 마우스 아래 건물과 같은 도구(설정까지) 집기 |
| Z · X · C · V · B / Tab | 툴바 탭 (물류 · 생산 · 전력 · 보관 · 운송) |
| 1\~9 | 지금 탭의 N번째 건물 |
| 휠 / 가운데 드래그 · Space+드래그 | 단계 줌 / 맵 이동 |
| Space | 일시정지 (속도 1× · 2× · 4× 버튼도 있음) |
| T · G · I · P · M · H | 연구 · 도감 · 생산량 표시 · 공장 통계 · 지도 · 도움말 |
| 🔊 (위쪽 바) | 효과음·배경음 켜기·끄기 |
| Enter · F (Alt+클릭) | 채팅 · 핑 |
| Esc / Del | 선택 해제 / 선택한 것 철거 |

### 배치를 편하게 만드는 장치

- **컨베이어 위에 짓기**: 기계·분배기를 컨베이어 위에 클릭하면 그 칸을 환급하고 흐름 방향에 맞춰 끼워 넣는다. 드래그로는 덮어쓰지 않는다.
- **되돌리기는 마우스 한 번 단위**: 누르고 떼기까지(드래그 한 줄, 영역 철거 한 번)가 한 단계다. 다시 지을 때 재료가 모자라면 건너뛰고 알려 준다. ↶ ↷ 버튼에 마우스를 올리면 무엇이 되돌려지는지 보인다.
- **기계끼리 직접 연결**: 출구가 다른 기계·발전기·허브에 닿으면 컨베이어 없이 바로 넣는다.
- **도구 설정 기억**: 레시피·분류기 아이템·정류장 종류를 한 번 고르면 다음에 놓는 것도 같은 설정이다.
- **조용히 막히지 않게**: 컨베이어를 끌다 도로를 만나면 "지하 컨베이어로 밑을 지나가게"라고 알려 준다. 우클릭으로 3번 연달아 지우면 영역 철거 팁을 한 번 띄운다.

### 화면 구성

| 위치 | 내용 |
| --- | --- |
| 위쪽 바 | 게임 시간, 속도, ↶ ↷, 🔊, 채팅 · 도감 · 생산량 · 통계 · 지도 · 연구 · 같이 하기 · 저장 · 도움말 |
| 왼쪽 | 광맥 경고, 목표 가이드, 전력 (허브·태양광·수력·석탄별 kW), 허브 재고와 분당 입고량 |
| 오른쪽 | 선택한 건물·트럭 정보창 |
| 오른쪽 아래 | 지도 (켜면) |
| 아래 | 큰 툴바: 카테고리 탭 5개 + 그 탭의 건물 |
| 도움말 (H) 맨 아래 | 효과음·배경음 음량, 글자 또렷하게, 공장 파일 내보내기·불러오기, 바로 전 공장으로 |

### 설명 없이도 알 수 있게

- **목표 가이드 24단계**: "채굴기 놓기"부터 트럭·흙 정제·석탄 없는 전기를 거쳐 "광맥 독립", 마지막으로 끝없는 연구 1단계까지. 이룬 목표는 저장돼서 뒤로 돌아가지 않는다.
- **기계 정보창**: 실제 분당 생산·가동률·멈춘 이유와 함께, "철광석 분당 30개를 대 주면 100%로 돌아가요. 지금은 10.7개만 들어와요"처럼 숫자로 안내한다.
- **생산량 표시 (I)**: 모든 기계 위에 "N/분"을 가동률 색(초록 · 노랑 · 빨강)으로, 정류장 위에 트럭 운송량을 띄운다.
- **공장 통계 (P)**: 아이템마다 만들기·쓰기·남음을 "지금"과 "모두 100%일 때"로 보여 주고, 모자라면 "제련로 약 2대 더"처럼 알려 준다. 비율 퍼즐의 답을 도와주는 도구다. 맨 오른쪽에는 최근 10분 허브 재고 흐름을 막대로 (늘면 초록, 줄면 빨강) 보여 줘서 모자라 가는 재료를 일찍 알아챈다.
- **지도 (M)**: 맵 전체를 칸당 1픽셀로. 광맥·호수·건물·도로·트럭·고갈 경고·다른 사람의 위치. 눌러서 이동.
- **도감 (G)**: 아이템마다 얻는 법·쓰는 곳·건설 재료·연구 재료와 "이 공장의 분당 만들기·쓰기"를 표로. 광맥 페이지에는 맵의 광맥 목록과 📍 가기.

## 8. 구현 방식

게임 엔진 없이 **TypeScript + Canvas 2D**로 직접 만들었다. 자동화 게임은 규칙 시뮬레이션이 핵심이라 시뮬레이션을 직접 다루는 쪽이 맞고, 이 선택 덕분에 락스텝 멀티플레이도 쉽게 붙었다.

### 코드 구조

| 폴더 | 맡는 일 |
| --- | --- |
| `src/data` | 아이템·레시피·건물·연구 정의. 밸런스 숫자는 전부 여기 |
| `src/sim` | 시뮬레이션 (맵, 채굴·제작·전력·컨베이어·트럭, 저장). `commands.ts` = 플레이어가 월드를 바꾸는 명령 전부. DOM 없음 |
| `src/render` | 픽셀 그림(`pixel.ts`, `pixel-buildings.ts`), 맵 그리기, 카메라 |
| `src/input` | 마우스·키보드 → 명령 |
| `src/ui` | 툴바, 정보창, 연구, 목표, 도감, 지도, 채팅 |
| `src/net` | 같이 하기 (락스텝 세션) |
| `server/relay.mjs` | 같이 하기 중계 서버 |
| `electron/` | Windows exe (내장 서버 + 방 찾기) |

### 핵심 기술 선택

- **시뮬레이션과 그리기 분리**: 초당 60틱 고정으로 `World`를 갱신하고, 그리기는 `requestAnimationFrame`에 맡긴다. 시뮬레이션이 화면과 상관없이 같은 결과를 내서 테스트와 같이 하기가 가능하다.
- **모든 변경은 명령으로**: 마우스·버튼은 월드를 직접 고치지 않고 짓기·철거·회전·레시피·연구·트럭 만들기 같은 명령(JSON)을 낸다. 되돌리기와 같이 하기가 이 하나의 구조 위에 올라간다.
- **락스텝**: 월드는 주고받지 않고 명령만 주고받는다. 방장이 명령에 틱 번호를 찍어 돌리고, 모두 같은 틱에 같은 순서로 적용한다. 2초마다 체크섬을 비교해 어긋나면 손님이 방장 월드를 다시 받는다. 트럭·컨베이어가 많아져도 통신량이 늘지 않는다. 커서·핑·채팅은 게임 진행과 상관없이 바로 뿌린다.
- **exe**: Electron 창 안에 게임 파일과 중계 서버를 같이 띄운다. 내 방이 열려 있으면 1초마다 UDP 브로드캐스트로 알리고, 다른 PC의 신호를 모아 방 목록을 만든다. 저장이 주소별로 따로라 내장 서버는 늘 같은 포트를 쓴다.
- **픽셀 그림 구워 두기**: 그림은 코드로 한 번 구워 두고 찍는다. 땅·광맥은 16×16칸 묶음으로 구워, 광맥이 줄어 모양이 바뀐 묶음만 다시 굽는다. 이미지 보간을 끄고 원점을 기기 픽셀에 맞춰 번짐이 없다.
- **정확한 생산 속도**: 남은 진행도를 다음 제작으로 이어받는다. 도감·통계의 숫자와 실제 생산이 일치해야 비율 퍼즐이 성립한다. (실제로 트럭 싣기가 초당 10개가 아니라 8.6개였던 소수점 오차를 잡았다.)
- **저장**: 30초마다 자동 저장 (브라우저는 localStorage, exe는 앱 저장 공간). 저장에 버전(rev)을 넣어 규칙이 바뀌어도 예전 저장을 자동으로 고친다 (예: 두 곳 왕복 트럭은 두 곳 노선으로).
  - 저장이 그 PC 안에만 있어서, 공장을 **파일(.json)로 내보내고 불러와** 다른 PC로 옮기거나 친구가 이어서 방장을 하거나 백업한다.
  - 새 게임·파일 불러오기로 공장이 통째로 바뀌기 직전 공장을 한 칸 보관해서 **"바로 전 공장으로"** 되돌린다 (실수로 새 게임을 눌렀을 때).
- **소리**: Web Audio로 효과음과 배경음을 그 자리에서 합성한다. 배경음은 0.2초마다 앞으로 1.2초 안의 음을 미리 예약해서 타이머가 조금 늦어도 박자가 흔들리지 않는다.
- **배포와 업데이트**: `npm run release`가 설치 파일을 만들어 깃허브 릴리스에 올린다. 숨김 릴리스 하나에 설치 파일 → 조각 지도(`.blockmap`) → `latest.yml` 차례로 올리고 다 올라가면 공개한다. 깔린 게임은 켤 때 `latest.yml`을 보고 바뀐 조각만 받는다 (93MB 중 약 2MB). 릴리스 설명은 `docs/바뀐점.md`에서 가져온다.
- **성능**: 건물 3,300개 + 트럭 30대에서 한 틱 0.15ms. 컨베이어는 2만 칸·4만 개에서 틱당 1.72ms라 지금 맵에는 충분하다.
- **테스트**: Vitest 시뮬레이션 테스트 137개 + 락스텝 테스트 6개. 락스텝 테스트는 저장에 없는 새 상태가 생겨도 두 PC가 같은 결과를 내는지 확인한다. 시작 재고로 첫 연구까지 갈 수 있는지도 테스트로 고정했다.

## 9. 설계 결정 정리

만드는 동안 직접 해 보고 바꾼 결정들이다. 대부분 "규칙은 적게, 막히는 사고는 없게" 쪽으로 움직였다. ★는 버전 2에서 새로 정한 것.

| 주제 | 처음 생각 / 선택지 | 최종 결정 | 이유 |
| --- | --- | --- | --- |
| 압박 요소 | 주문 기한, 적 방어 | 없음. 유한 광맥만 | 힐링형. 압박은 확장을 유도하는 정도로 |
| 건설 비용 | 돈과 상점 | 생산품만 | 만든 것이 곧 확장이라 보람이 바로 보인다 |
| 입출구 | 아무 면으로나 출력 | 앞면으로만 출력, 분배기는 뒤가 입구 | 제련로 옆 분배기로 결과물이 새어 라인이 막혔다 |
| 시작 전력 | 발전기만 | 허브 기본 300kW | 석탄 채굴기도 전기가 필요해서 없으면 시작이 막힌다 |
| 전력 부족 | 기계 정지 | 비율만큼 감속 | 갑자기 멈추지 않아 덜 고통스럽다 |
| 속도 업그레이드 | 전역 연구 | 따로 짓는 건물 | 업그레이드가 공장을 고치는 플레이가 된다 |
| 채굴 범위 | 채굴기 아래 칸만 | 이어진 광맥 전체 | 다 캐면 채굴기를 옮겨야 하는 수고를 없앰다 |
| 먼 광맥 양 | 시작 광맥의 40배 이상 | 6\~19배 | 바닥나야 트럭·흙 정제가 의미가 있다 |
| 분리기 결과 | 확률 | 고정 순서 7·2·1 | 비율을 믿고 설계할 수 있다 |
| 줄 합류 | 옆구리 합류만 | 병합기 추가 | 본선이 꽉 차면 옆줄이 거의 못 들어간다 (측정 55 대 5) |

| ★ 허브에 붙인 정류장 | 직접 고름 | 무조건 내리기 | 허브에서 싣기는 쓸모가 없다 |
| ★ 석탄 고갈 | 석탄을 흙에서 만들기 | 전기로 + 태양광·수력 | 새 아이템 없이 끝까지 무한으로. 석탄 없이도 지을 수 있게 |
| ★ 연구 비용 | 버전 1 수준 | 약 4\~5배 | 공장을 안 키워도 1시간에 끝났다 |
| ★ 되돌리기 단위 | 건물 하나 | 마우스 누르고 떼기까지 | 드래그 한 줄을 한 번에 되돌린다 |

| ★ 되돌리기 (같이 할 때) | 모두의 것 | 각자 자기 것만 | 남이 지은 걸 실수로 없애지 않게 |
| ★ 채팅 | 채팅창 + 기록 | 화면을 흘러가는 메시지 | 공장을 가리지 않고 가볍게 |
| ★ 그림 | 직접 그린 이미지 | 코드로 그리고, 필요한 것만 PNG로 교체 | 빠르게 전부 맞추고, 마음에 안 드는 것만 바꾼다 |
| ★ 기계 방향 표시 | 몸체를 돌려 그리기 | 몸체는 고정, 화살표로만 | 빛 방향이 항상 같고 그릴 양이 적다 |
| ★ 트럭 연료 | 석탄 연료 | 전기 충전 (정류장에서 공장 전력) | 트럭이 석탄을 먹으면 "석탄 독립" 목표와 어긋난다 |
| ★ 트럭 노선 | 두 정류장 왕복 | 정류장 2\~8곳, 곳마다 싣기·내리기·실을 짐 | 여러 광맥에서 모으려고 트럭을 따로 만들 필요가 없게 |
| ★ 빈 싣는 곳 | 무조건 다음으로 | 다른 싣는 곳에 짐이 있을 때만 넘어감 | 모두 비면 빈 바퀴를 돌며 충전 전력만 쓴다 |
| ★ 최종 목표 뒤 | 끝 | 끝없는 연구 (단계마다 10%, 비용 1.5배) | 다 이룬 뒤에도 공장을 키울 이유 |
| ★ 소리 | 소리 파일 | 코드로 합성 (Web Audio) | 그림처럼 파일 없이 |
| ★ 효과음 범위 | 모두의 행동 | 내가 한 것만 (채팅은 남의 것도) | 같이 할 때 시끄럽지 않게 |
| ★ 연달아 짓는 소리 | 한 칸씩 오르는 음 | 셰퍼드-리셋 글리산도 + 온음 계단 | 짓는 빠르기와 상관없이 끝없이 오르는 느낌 |
