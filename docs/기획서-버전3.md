# 자동화 공장 확장 기획서 (버전 3)

2026-10-27 · 지형·자원·날씨·지역 전력망·업적 확장안

> 후속 방향: [전체 흐름과 지역 생산망](기획서-버전4.md)은 여러 지역의 자원·중간재를 운송해 복합 제품을 만드는 경험을 중심으로 한다. 아래 ‘광맥 독립 후 선택형 지역 확장’은 이전 방향이며, 진행 구조가 충돌하면 버전 4를 따른다.

> 후속 수치안: [생산 상세](생산체인-상세기획.md)와 [지형·운송·전력 상세](지형-운송-전력-상세기획.md)에 제품·레시피·새 지도·자원 배치·물류·지역 전력망을 구체화했다. 아래 미정 항목과 수치 후보가 충돌하면 후속 상세 기획을 따른다. 구현 완료를 뜻하지 않는다.

> 후속 진행·화면: [메인 목표 36개와 선택 도전](목표-진행-상세기획.md), [지역 운영 UI](지역-운영-UI-상세기획.md), 보강된 [업적 후보 116종·290기록](업적-확장기획서.md)을 따른다. 아래 100종·262기록은 보강 전 설계의 수다.

이 문서는 대화에서 정한 확장 방향을 정리한 **기획서**다. 문서 작성은 게임 기능 구현이나 배포를 뜻하지 않는다. 기본 게임과 이전 구현 기록은 [버전 2](기획서-버전2.md), 실행 순서는 [계획서](계획서.md), 업적의 전체 목록·숨은 조건·판정 규칙은 [업적 확장 기획서](업적-확장기획서.md)에 있다.

## 1. 핵심 경험과 범위

**기본 공장 만들기 → 자원과 좋은 입지 발견 → 지역 거점 건설 → 현지 발전 또는 송전 선택 → 운송망 연결 → 생산 효율 개선.**

초원에서 기본 산업을 시작하고, 필요한 제품과 운영 방식에 따라 다른 지형을 찾아간다. 여러 지형의 자원을 연결할수록 선택할 수 있는 생산·전력·물류 방식이 늘어난다. 기존 최종 목표인 광맥 독립은 유지하고, 지역 산업과 업적은 이후에도 즐길 수 있는 확장 경로로 둔다.

- 최초 달성은 새 기능을 배운 순간을 기록한다.
- 심화 업적은 생산량뿐 아니라 가동 안정성·지역 자립·송전·운송·자원 순환을 평가한다.
- 숨은 업적은 일상적인 플레이에서 발견할 수 있는 조합과 작은 이야기를 보상한다.
- 게임을 놓치거나 실패하도록 요구하지 않는다. 건물 파괴·아이템 손실·특정 날짜 접속을 업적 조건으로 삼지 않는다.
- 생산 속도·비용·설비 범위·레시피 개수는 플레이 테스트로 정한다. 아래 심화 업적 수치는 밸런스 초안이다.

## 2. 구현된 내용과 추가 기획의 구분

7종 지형과 신규 자원이 이미 게임에 들어간 상태로 해석하지 않는다. [이전 구상](업적-날씨-지형-자원-구상.md)은 이전 단계의 설계 기록이며, 확장 방향이 충돌하면 이 문서를 따른다.

현재 main에는 기존 광물·산림·흙 정제, 맑음·흐림·비와 태양광·풍력 영향이 있다. 주석·알루미늄·3종 지형·확장 날씨·업적·도전은 현재 코드에서 확인되지 않는다. 아래 날씨 수치·기존 업적 ID 보존 규칙도 이전 구현본을 찾기 전까지 설계 자료로 취급한다.

### 3.1 배치 원칙

- 허브 주변에는 기본 광물 4종과 초기 진행에 필요한 물·나무 접근을 보장한다.
- 철·구리·석탄·돌은 여러 지형에서도 얻을 수 있다. 특화 지형은 종류·밀도·매장량에서 이점을 갖는다.
- 원유·리튬 함유 염수·황·주석은 특화 지역을 찾는 중요한 동기다. 시작 연구를 이 자원에 의존시키지 않는다.
- 유기 자원은 숲에 집중한다. 별도 열대우림·농업·식물 섬유 산업은 이번 범위에 넣지 않는다.
- 소금은 염호의 분위기와 자원 설명에 사용할 수 있지만, 확실한 소비처를 정하기 전까지 강제로 쌓이는 부산물 아이템으로 만들지 않는다.
- 지열 분출구는 운반하는 아이템이 아닌 발전 입지다. 화산 전체를 발전소로 채울 수 없고, 발견한 분출구에 발전 설비를 설치한다.
- 지형 안에는 희귀한 물 접근 지점·풍부한 광맥·좋은 분출구 등 입지 차이를 둔다. 실제 목록과 빈도는 지도 생성 설계에서 정한다.

### 3.2 기존 공장과 지도 확장

기존 건물·자원·나무·호수를 보존하는 방식이 우선이다. 기존 지형 번호는 재사용하지 않고 새 지형을 뒤에 추가한다. 기존 공장을 무조건 새 지형으로 덮어 발전이나 생산을 끊지 않는다. 빈 지역 세분화와 새 지도 전용 배치 중 어떤 이행 방식을 쓸지는 구현 전에 확정한다.

새 지도는 256×256을 검토 목표로 두되 7종의 유효한 자원지·운송 거리·성능을 먼저 확인한다. 256×256은 아직 구현된 지도 크기가 아니다. 업적 필수 조건에 특정 시드나 운으로만 생기는 입지를 요구하지 않는다.

## 4. 자원과 소비처

### 4.1 기본·금속 자원

| 원자원 | 주요 가공 흐름 | 실제 소비처 또는 추가 계획 |
| --- | --- | --- |
| 철광석 | 철판 → 기어·강철 | 기본 건설·기계·차량 부품 |
| 구리광석 | 구리판 → 구리선 | 회로, 기본 배전, 절연 전선·케이블 |
| 석탄 | 연료, 강철 제련 | 석탄 발전과 초중반 강철. 숯·전기 제강으로 대체 경로 유지 |
| 돌 | 자갈 → 모래 | 건설, 광물 정제 산업의 재료 |
| 흙 | 자갈·모래 → 광물 가루 → 정광 | 광맥 고갈 뒤에도 철·구리와 건설 재료 생산 |
| 천연 모래 | 세척 → 광물 가루 | 모래사막을 활용하는 정제 경로. 기존 흙·자갈 분쇄 경로도 유지 |
| 물 | 세척·제지·전해·화학 공정 | 광물 정제, 종이·알루미늄, 수력 발전, 신규 화학 공정 |
| 나무 | 통나무 → 목재·숯·톱밥 | 건설·전봇대, 연료·강철, 종이·연구 |
| 주석광석 | 주석판 + 구리판 → 청동 | 전해로 등 고급 설비와 차량 기술 |
| 보크사이트 | 물·전력과 함께 전해 → 알루미늄판 | 경량 프레임·고용량 케이블 |

기존 부산물은 톱밥 + 물 → 종이, 진흙 → 벽돌, 슬래그 + 자갈 → 콘크리트로 사용한다. 묘목은 벌목·식목 순환에 사용한다.

### 4.2 신규 자원

| 자원 | 주력 역할 | 보조 역할 |
| --- | --- | --- |
| 원유 | 플라스틱·고급 회로 | 윤활유·연료 |
| 고무 | 구리선과 조합해 절연 전선 | 강화 고무의 원료, 타이어·컨베이어 |
| 황 | 고무와 조합해 강화 고무 | 황산을 통한 고효율 광물 정제 |
| 리튬 | 배터리 팩 → 축전기·상위 차량 배터리 | 석유계 윤활유와 조합해 고급 윤활제 |

고무를 이번 산업 확장에 포함한다. 리튬 경량 합금·특수 유리와 황 비료는 후속 후보이며, 현재 확장에 필수로 넣지 않는다.

### 4.3 게임용 생산 조합

후속 [생산 체인 상세 기획](생산체인-상세기획.md)에 제품명·재료량·시간·설비·연구의 첫 수치안을 정리했다. 아래 표는 이전 후보이며 충돌하면 상세 기획을 따른다.

현실 화학식을 그대로 재현하는 문서가 아니다. 다음은 생산 체인 연결을 위한 단순화된 기획 레시피이며 투입량·시간·전력은 미정이다.

| 결과 | 재료 또는 공정 | 쓰는 곳 |
| --- | --- | --- |
| 플라스틱 | 원유 → 정유·화학 가공 | 고급 회로·고급 부품 |
| 윤활유 | 원유 → 정유 | 고급 윤활제 |
| 연료 | 원유 → 정유·연료 가공 | 연료 발전. 트럭은 전기 운행 유지 |
| 고무 | 고무나무의 원료 → 가공 | 절연 전선·강화 고무 |
| 절연 전선 | 구리선 + 고무 | 중반 배전망·전력 설비 |
| 강화 고무 | 고무 + 황 | 상위 케이블·타이어·컨베이어 |
| 고용량 케이블 | 구리 또는 알루미늄 + 강화 고무 | 설비 모듈·후반 조립 |
| 고급 타이어 | 강화 고무 + 강철 부품 | 차량 성능 개선 |
| 리튬 | 염수 채취 → 농축·정제 | 배터리 팩·고급 윤활제 |
| 배터리 팩 | 리튬 + 구리 + 회로 | 축전기·상위 차량 배터리 |
| 축전기 | 배터리 팩 + 강철 + 전력 제어 부품 | 소속 구역의 전력 저장·방전 |
| 고급 윤활제 | 윤활유 + 리튬계 재료 | 기계 성능 연구·상위 기계 제작 |
| 황산 | 황 → 화학 가공 | 선택형 고효율 정제 레시피 |
| 고효율 정광 | 기존 광물 재료 + 황산 | 기존 방식보다 높은 수율의 철·구리 정제 |

구리·알루미늄 케이블의 최종 레시피는 하나 또는 대체 레시피로 정리한다. 서로 같은 아이템을 반복 변환해 생산량을 무한히 올리는 가역 레시피는 만들지 않는다.

### 4.4 진행이 막히지 않게

- 첫 배전은 목재·철·구리 같은 기본 자원으로 가능해야 한다. 고무·황·리튬을 얻기 위해 먼저 그 자원의 전선·배터리를 요구하지 않는다.
- 염수 정제는 기존 발전원과 기본 배전으로 시작할 수 있다. 배터리를 이미 가지고 있어야 리튬을 생산하는 순환 의존을 만들지 않는다.
- 화산 거점은 반입한 연료·기본 전력 설비 또는 송전으로 시작할 수 있다. 지열 발전소 해금에 현지 대규모 발전이 선행 필수가 되지 않게 한다.
- 고급 윤활제와 황산 정제는 기존 공장을 개선하는 선택지다. 기본 기계가 소모품 부족으로 멈추는 상시 유지보수 시스템은 추가하지 않는다.
- 초기 정유는 플라스틱 등 하나의 소비처로 완결되는 경로부터 만든다. 쓰임이 없는 가스 부산물 때문에 전체 공정이 정지하지 않게 한다.
- 원유·염수 등 액체는 우선 기존 물처럼 아이템 단위로 운송한다. 파이프는 별도 확장으로 남긴다.

## 5. 날씨와 지역 환경

> 아래 표는 이전 설계 기록이다. 최신 운송 속도·초반 보호·예보·지도 표현은 [날씨·지도 오버레이 상세](날씨-지도레이어-상세기획.md)를 따른다.

기존 날씨 체계를 바탕으로 한다. 맑음 50%·흐림 20%·안개 10%·비 15%·폭풍 5%, 게임 시간 3분마다 결정, 첫 구간은 맑음, 전환은 20초다. 같은 씨앗과 게임 시간이면 모든 참여자가 같은 날씨를 본다.

| 현지 날씨 | 태양광 배율 | 풍력 한 대 기준 | 트럭 속도 | 나무 자람 | 양수 |
| --- | --- | --- | --- | --- | --- |
| 맑음 | 1 | 60kW | 1 | 1 | 1 |
| 흐림 | 0.5 | 100kW | 1 | 1 | 1 |
| 안개 | 0.6 | 60kW | 0.8 | 1 | 1 |
| 비 | 0.25 | 150kW | 0.9 | 1.5 | 1.2 |
| 눈 | 0.25 | 150kW | 0.7 | 0 | 1 |
| 모래 바람 | 0.1 | 150kW | 0.8 | 1 | 1 |
| 폭풍 | 0.1 | 250kW | 0.7 | 1.5 | 1.2 |

위 표는 과거 확장 설계의 기준값이며 현재 코드 구현값이 아니다. 실제 태양광은 낮·밤과 지형 배율, 풍력은 지형 배율, 나무는 지형 성장 배율도 함께 적용한다. 새 지형의 수치는 별도로 조정한다. 화산의 태양광은 모든 배율을 적용해도 항상 0이며, 화산재는 확률형 날씨와 별개의 상시 지역 환경이다.

예보는 기본 3분·기상 관측 뒤 9분을 유지한다. 화면 효과를 꺼도 시뮬레이션 영향은 유지한다. 기계와 컨베이어의 레시피 속도는 날씨가 직접 바꾸지 않는다. 날씨가 건물을 파괴하지 않으며, 태양광의 밤·화산 출력 0과 눈의 나무 성장 정지는 의도한 예외다.

## 6. 지역 전력 구역

### 6.1 후속 채택 구조

이 버전의 옛 독립 구역/방향 지정 송전안은 [전력망 연결·독립 시작 개정](전력망-연결-독립시작-개정.md)으로 대체한다. 송전 터미널을 삭제하고 전봇대로 연결된 노드는 한 전력망에서 공유한다. 확장 반경 상한·선로 용량/손실·망 처리 한도를 두지 않는다. 전봇대 연결은 12칸 이하, 공급 반경은 허브 24·발전기 10·전봇대 6·변전소 18칸이다. 거점은 망과 별개로 보존한다. 부족은 같은 망의 작업/배정 충전에 전파되고 분리된 망은 보호된다. 새 거점은 외부 전력 없이 반입 연료·풍력·태양광/지열로 시작할 수 있다. 세부 수치·가격은 최신 개정/경제 문서를 따른다.

### 6.2 발전·축전

태양광·풍력·수력·지열·연료 발전과 축전기를 조합한다. 축전기는 남는 전력만 충전하고 부족할 때 방전하며, 저장 용량과 최대 충전·방전 출력을 따로 가진다. 상위 배터리는 기존 기본 트럭을 만들기 위한 선행 필수품으로 바꾸지 않는다.

트럭은 정류장·충전기가 속한 구역에서 충전한다. 전력이 없는 외곽 정류장은 현지 발전 또는 송전이 필요하다. 배터리가 모자란 트럭의 기존 저속 이동 원칙은 유지한다.

화산에서는 태양광을 설치해도 출력은 0이다. 배치 미리보기와 정보창에서 화산재로 발전 불가임을 먼저 표시한다. 지열 발전소는 분출구에 설치하고 지속적으로 전기를 생산한다. 물 소모·발전량·분출구 수는 밸런스 설계 사항이다.

### 6.3 전력 UI

- 구역별 색·이름·공급/수요·부족량·축전량·송수전량을 표시한다.
- 건물 배치 중 소속될 구역과 예상 전력 여유를 보여 준다.
- 구역 경고를 누르면 해당 거점으로 이동한다. 문제없는 다른 구역의 화면을 덮지 않는다.
- 지열은 발전 입지, 리튬은 저장과 차량, 고무·황은 배전·송전 소재라는 역할을 도감과 연구에서 연결한다.

## 7. 업적 구성

신규 업적은 **최초 30종 + 심화 24종 + 숨은 16종 = 70종**이다. 기존 누적 생산·생산 속도·공장 업적 30종은 ID와 달성 메달을 유지한다. 최종 목록은 기존 30종과 신규 70종을 합쳐 **100종**이다. 심화는 각 4단계로 구성하므로 총 획득 기록은 기존 120개 + 최초 30개 + 심화 96개 + 숨은 16개 = **262개**다.

| 종류 | 역할 | 표시 방식 |
| --- | --- | --- |
| 최초 달성 | 첫 생산·첫 운송·첫 발전 등 새로운 행동의 발견 | 한 번 달성. 미달성도 이름·조건 공개 |
| 기존 기록 | 누적 생산·최근 1분 생산량·공장 규모 | 동·은·금·다이아 유지 |
| 심화 | 복합 생산·효율·지역 자립·송전·순환·물류 숙련 | 24개 계열, 각 4단계. 다음 단계 조건 공개 |
| 숨은 업적 | 특별한 운영 조합과 소소한 발견 | 미달성은 이름·조건·진행도를 숨기고 분위기 힌트만 표시 |

기존 도전(O)은 원하는 목표를 고르고 추적하는 기능, 업적(J)은 이룬 행동을 보존하는 기록이다. 동일한 행동이 둘을 동시에 만족할 수 있지만 통계나 보상을 두 번 더하지 않는다. 같은 이름·조건의 카드가 중복되지 않게 서로 연결한다.

업적의 모든 상세 조건과 숨은 업적의 전체 정답은 [업적 확장 기획서](업적-확장기획서.md)에 있다. 숨은 업적은 플레이어 화면에서 잠금을 숨길 뿐, 설계 문서에서는 구현자가 재현할 수 있게 공개한다.

## 8. 구현 순서와 완료 기준

| 단계 | 범위 | 완료 기준 |
| --- | --- | --- |
| A | 현재 기능을 사용하는 최초·심화·숨은 업적, 업적 UI 개편 | 기존 메달 보존, 저장·중간 참가·알림·숨김 규칙 확인 |
| B | 지형 7종·특화 분포·천연 모래·탐색 기반 | 시작 자원 보장, 필요한 지역·입지 보장, 기존 공장 보존·성능 확인 |
| C | 석유·고무·황·리튬의 작은 완결 생산 경로 | 자원마다 실제 소비처 2개 이상, 초기 전력과 연구 의존 순환 없음 |
| D | 지역 배전·송전·축전·지열 | 독립 구역·과부하·충전·송전·날씨·저장·멀티플레이 검증 |
| E | 조사 보고서·탐사 드론과 후반 업적 | 기록 중복 방지, 시드와 무관한 달성 가능성 확인 |

각 기능을 구현할 때 연결된 업적도 함께 활성화한다. 미구현 기능의 업적은 이번 게임 버전의 완료율에 넣지 않는다. 단계는 작업 순서이며 버전 번호나 출시 일정을 확정한 것은 아니다.

## 9. 구현 전에 정할 수치

- 7종 지형의 면적 비율·최소 자원지 수·특수 입지 빈도, 지도 크기와 성능 기준.
- 새 지형의 태양광·풍력·나무 배율, 바위사막·염호의 강수 표현.
- 전력 연결 규칙은 후속 개정에서 확정. 실제 공급/부족·망 병합/분리·계측을 시제품으로 검증.
- 지열 발전량·물 소모, 배터리 용량·출력·충방전 우선순위.
- 신규 생산 설비와 연구 선행 관계·레시피 시간·투입량·전력.
- 업적의 초중후반 달성 시간과 심화 단계별 난이도. 숫자는 조정해도 업적 ID는 바꾸지 않는다.

자원·지형·날씨·전력의 이번 합의는 새 산업과 지역 선택의 방향을 정한다. 구현하지 않은 기능을 기존 게임 설명이나 배포 내역에 완료로 기록하지 않는다.
