# 자동화 공장 전체 흐름과 지역 생산망

2026-10-27 · 지역 분업을 중심으로 한 진행 기획

**서로 다른 지역에서 자원을 모으고 중간재를 만든 뒤, 운송망으로 연결해 더 복잡한 제품을 자동 생산하는 게임.** A지역의 생산물이 B지역의 재료가 되고, 여러 지역의 결과물이 최종 조립 공장에서 만난다. 공장이 커진다는 것은 건물 수뿐 아니라 연결된 생산 거점과 생산 관계가 늘어난다는 뜻이다.

사용자는 기존의 광맥 독립도 여러 곳의 광맥을 모아 공장을 만드는 경험을 위해 넣었다고 설명했다. 앞으로의 중심 목표는 흙 정제로 모든 광맥을 대체하는 일이 아니라 **여러 지역이 서로 필요한 생산망을 만드는 일**이다. 이 방향은 이전 기획서의 ‘광맥 독립 후 선택형 지역 확장’보다 우선한다.

아래 지역별 제품·시설·진행 조건은 이 의도를 구체화한 설계안이다. 현재 구현은 [구현 코드 추적 기록](구현코드-추적기록.md), 자원별 세부 후보는 [버전 3](기획서-버전3.md), 업적 후보 목록은 [업적 확장 기획서](업적-확장기획서.md)를 참고한다. 게임 코드를 변경한 문서가 아니다.

제품과 수량을 구체화한 후속 설계는 [지역 생산망의 제품과 레시피](생산체인-상세기획.md)에 있다. 청동 구동부·절연 모터·산업 제어기에서 고급 트럭·설비 모듈까지 신규 레시피 23개, 연구·설비 비용안과 기준 공장의 공급량을 정리했다. 아래 예시보다 상세 기획의 이름·레시피를 우선한다.

지도 공개는 [목표별 지도 공개](지도-목표별-공개-상세기획.md)의 RV00~07을 적용한다. 시작 초원만 보이고 목표 달성에 따라 다음 산업 지역과 접근로가 열린다. 기존 전체 공개 공장은 다시 가리지 않는다.

지도·물류·전력 수치는 [지형과 인프라 상세 기획](지형-운송-전력-상세기획.md)을 따른다. 새 지도 256×256을 시제품 기준으로 정하고 자원지·매장량·도로 거리·노선·지역 전력 구역·송전·축전 수치안을 연결했다. 기존 128×128 공장에는 이 규칙을 자동 적용하지 않는다.

목표 시간과 비용은 [진행 시간·경제 기획](진행시간-경제-상세기획.md)의 첫 플레이 1배속 기준안으로 연결한다. 첫 자동화 5~8분·첫 배송 25~35분·첫 지역 조합 40~55분·최종 납품 4~5시간이며 마감 시간이 아니다.

진행과 화면은 [메인 목표·선택 도전](목표-진행-상세기획.md)과 [지역 운영 UI](지역-운영-UI-상세기획.md)를 따른다. 메인 36개를 9장으로 연결하고, 기존 업적 후보에 새 제품·공급망 성취 16종을 보강했다.

## 1. 플레이어가 반복하는 일

**필요한 제품 정하기 → 재료와 산지 확인 → 현지 공장 건설 → 전력과 운송 연결 → 실제 생산 확인 → 부족한 공정 개선.**

예를 들어 회로가 필요하면 구리선을 만들고, 구리선이 부족하면 구리 거점의 채굴·제련·운송을 살핀다. 이후 상위 제품이 고무와 배터리까지 요구하면 기존 금속 거점에 새로운 지역을 연결한다. 매번 처음부터 같은 공장을 짓는 대신, 이전 공장이 다음 산업의 공급자가 된다.

적·제한 시간·건물 파괴는 추가하지 않는다. 생산 비율, 운송량, 발전 입지와 거점 사이의 거리가 설계 과제가 된다. 함께 하는 사람들은 채광·화학·물류·조립을 나누어 맡을 수 있다.

## 2. 처음부터 후반까지의 흐름

| 단계 | 플레이어가 하는 일 | 이 단계에서 생기는 고민 | 다음으로 이어지는 계기 |
| --- | --- | --- | --- |
| 1. 첫 공장 | 시작 지역의 철을 캐서 철판·기어를 자동 생산하고 허브에 보낸다 | 기계 방향과 컨베이어 연결 | 기계를 늘리니 전력과 다른 재료가 필요하다 |
| 2. 기본 산업 | 구리·강철·회로 생산을 연결하고 발전을 늘린다 | 같은 재료를 건설·연구·다른 레시피가 나눠 쓴다 | 새 제품의 재료가 시작 지역에 충분하지 않다 |
| 3. 첫 외곽 거점 | 먼 자원지에 채굴·가공 설비를 짓고 정류장과 트럭으로 연결한다 | 광석을 운반할지 현지에서 가공할지 결정한다 | 두 지역이 연결되어야 돌아가는 첫 제품을 만든다 |
| 4. 지역별 분업 | 금속·산림·화학 등 필요한 산업을 각 입지에 배치한다 | 어디에서 어떤 중간재를 만들지 정한다 | 여러 지역의 중간재를 함께 쓰는 상위 제품이 열린다 |
| 5. 복합 조립 | 금속 부품·고무계 부품·회로·배터리를 한 조립 거점에 공급한다 | 가장 느린 지역이나 노선이 전체 생산을 제한한다 | 공급이 끊기지 않도록 거점을 보강해야 한다 |
| 6. 전력과 물류 개선 | 지역 발전·송전·축전을 선택하고 노선과 재고를 조정한다 | 날씨, 야간 발전, 충전 수요와 운송 주기를 맞춘다 | 공장망 전체가 안정적으로 생산한다 |
| 7. 허브 프로젝트 | 최고 단계 설비 모듈 50개를 실제 허브에 납품한다 | 최종 조립품을 운송하면서 연구·설비 개선용 물량도 배분한다 | 공장망 완성 연출 후 자유 확장·반복 연구·선택 업적을 이어 간다 |

이 표는 학습 순서다. 산림과 운송, 흙 정제와 신금속 같은 가지는 병행할 수 있다. 7개 지형을 정해진 순서로 전부 방문해야만 다음 연구가 열리는 구조로 만들지 않는다. 대신 주요 상위 제품에는 서로 다른 지역을 연결해야 할 이유를 둔다.

현재의 철판 → 기어 → 석탄 발전 → 구리·강철·회로 흐름은 초반 기반으로 활용한다. 첫 외곽 거점 전에는 신자원·송전·대형 배터리를 요구하지 않는다.

## 3. 지역 생산망의 예

다음은 지역 연결의 개념 예시다. 상세 설계에서는 가벼운 차체를 공용 경량 프레임으로 정리하고, 고급 트럭 조립품과 자동화 설비 모듈을 후반 대표 제품으로 잡았다. 정확한 수량과 공정은 [생산 체인 상세](생산체인-상세기획.md)를 따른다.

```text
금속 거점: 철·주석·구리 → 강철·청동 부품 ──────────────┐
금속 거점: 보크사이트 + 물 → 알루미늄·경량 프레임 ────────┤
산림 거점: 고무 원료 → 고무 ─┬→ 구리선과 절연 전선 ────┤
                            └→ 황과 강화 고무·타이어 ──┤
석유 거점: 원유 → 플라스틱 → 회로와 상위 제어 부품 ─────┤→ 조립 거점 → 상위 전기 트럭·설비 모듈 → 허브 프로젝트
염호 거점: 염수 → 리튬 → 구리·회로와 배터리 팩 ─────────┘
화산 거점: 황 → 화학 재료 / 지열 → 현지 발전·송전
```

회로·구리선·타이어·배터리까지 모두 한 지역에서 만들 필요는 없다. 자원 가까이에서 중간재를 만든 뒤 운반하거나, 원료를 조립 거점으로 보낼 수 있다. 운송 단위와 레시피 비율을 정할 때 두 방식 중 하나가 항상 정답이 되지 않게 한다.

새 지역의 생산물은 기존 공장을 개선하는 곳에도 쓰인다. 예를 들어 배터리 팩은 트럭과 축전기에, 강화 고무는 타이어와 케이블에 쓰인다. 새 산업이 연구비 한 번만 내고 끝나는 재료가 되지 않게 한다.

## 4. 지형이 맡는 역할

| 지형 | 현지에서 얻는 이점 | 다른 지역에 공급하는 것 | 외부에서 필요한 것 |
| --- | --- | --- | --- |
| 초원 | 기본 광물과 물을 이용한 시작 공장 | 철판·구리선·기어·회로 등 기본 중간재 | 상위 금속·고무·화학 재료·배터리 |
| 숲 | 풍부한 나무와 고무 원료 | 목재·숯·종이·고무 | 금속 부품과 설비, 강화 고무용 황 |
| 바위사막 | 석탄·돌·보크사이트 중심의 광업 | 연료·건설 재료·알루미늄계 중간재 | 전해 공정용 물과 전력, 기계 부품 |
| 모래사막 | 원유·천연 모래와 유리한 일조 | 플라스틱·윤활유·연료 | 금속 설비, 필요한 물·보조 발전·축전 |
| 눈밭 | 주석과 유리한 풍력 입지 | 주석판·청동계 중간재 | 청동용 구리, 목재·기계 부품 |
| 염호 지대 | 리튬 함유 염수 | 리튬·배터리계 중간재 | 구리·회로·정제 전력 |
| 화산 지대 | 황과 지열 분출구 | 황계 화학 재료와 전력 | 설비 부품, 공정에 필요한 물 |

기본 광물은 여러 지형에서도 얻는다. 주석·원유·고무 원료·리튬·황 같은 특화 자원의 위치가 지역 연결의 동기가 된다. 시작 지역에는 첫 운송과 발전을 준비할 자원을 보장한다. 지도 생성은 산업에 필요한 지역·물·도로를 놓을 공간이 실제로 존재하도록 검증해야 한다.

숲은 현재도 나무 군락으로 존재하지만, 표의 독립 지형·고무 산업은 확장 설계다. 물이 귀한 지역에는 물 운송을 선택지로 두되, 시작 산업이 우연한 지도 배치 때문에 불가능해지지 않게 한다.

## 5. 흙 정제와 광맥 고갈의 역할

현재 게임은 흙 정제로 철·구리를 무한 생산하고 ‘광맥 독립’ 연구를 마치는 후반 구조다. 이를 모든 지역 자원의 대체 경로로 확장하면 먼 지역에서 가져올 이유가 사라진다.

새 방향에서는 흙 정제를 **기본 금속의 보조 공급과 고갈 대응 경로**로 둔다. 주석·알루미늄·원유·고무·황·리튬까지 흙 하나에서 전부 나오게 하지 않는다. 기존 공장과 저장 파일의 흙 라인은 유지하고, 수율·소비 전력 조정은 별도 밸런스 검토를 거친다.

광맥이 바닥나면 새 자원지를 찾아 연결할 수 있어야 하지만, 자주 채굴기를 옮기는 일이 주된 플레이가 되면 안 된다. 주요 지역 거점은 충분히 오래 운용할 수 있는 매장량을 목표로 하고, 고갈 경고와 다음 자원지 안내를 제공한다. 무한 광맥 전환이나 자동 재생은 아직 결정하지 않는다.

기존 ‘광맥 독립’ 연구는 현재 저장에서 보존한다. 새 게임에서의 이름·선행 관계·보상과 전체 목표에서 차지할 위치는 개편 대상으로 둔다. 지역 공장망 완성의 필수 종착점으로 고정하지 않는다.

## 6. 실제로 운반해야 하는 것

레시피 재료는 컨베이어·트럭을 통해 해당 기계에 도착해야 한다. A지역에서 만든 부품을 허브에 넣었다는 이유만으로 B지역의 기계가 자동으로 꺼내 쓰면 지역 간 물류가 사라진다.

| 대상 | 설계 원칙 |
| --- | --- |
| 건설·연구 | 기존 공용 허브 재고를 사용하는 편의를 우선 유지한다 |
| 기계의 생산 재료 | 현지에 실제로 공급해야 한다 |
| 거점의 완제품 | 다른 거점의 투입물 또는 허브 납품으로 보낸다 |
| 액체 | 첫 구현은 물과 같은 아이템 단위 운송을 이용한다. 파이프는 후속 범위다 |
| 정류장·창고 | 거점의 입고·완충·출고를 맡고, 멀리 떨어진 창고가 자동으로 같은 재고가 되지 않게 한다 |
| 트럭 | 전기 운행을 유지하고, 기본 트럭으로 신자원을 처음 운반할 수 있게 한다 |

중간재를 모두 허브로 모았다가 다시 내보내는 우회를 강제하지 않는다. 금속 거점 → 화학 거점, 배터리 거점 → 조립 거점처럼 직접 연결할 수 있어야 한다. 현재 정류장·트럭·컨베이어를 기반으로 설계하되 필요한 기능은 구현 전에 따로 검증한다.

공용 허브 재고는 어디서든 건설·연구에 지불할 수 있지만, 재고를 늘리려면 실제 허브 입고가 필요하다. 신자원 연구비도 해당 부품을 허브로 운반해 준비한다. 레시피·정류장 모드 변경, 철거·되돌리기로 생기는 실물 화물과 설치 모듈은 현지 회수하며 허브 입고·생산·납품 실적을 추가하지 않는다. 현재 코드의 내부 재료 허브 환급과 다른 확장 규칙이므로 구현 시 반드시 분리한다. 구체적인 현지 회수 더미·하역·되돌리기·예약과 반송은 [물류 운영 규칙](물류-회수-운영규칙.md)을 따른다. 기존 저장의 호환 모드에는 원래 동작을 보존한다.

## 7. 연구와 생산 경로

초반의 공통 기반은 조립·기본 물류·구리·강철·회로·발전이다. 그다음 기본 트럭과 정류장이 지역 확장을 가능하게 한다. 산림과 흙 정제는 기본 산업을 보조하는 병행 경로다.

지역 산업은 다음처럼 시작할 수 있게 설계한다. 이 목록은 확정된 연구 ID가 아닌 선행 관계의 기준이다.

| 산업 | 첫 가동에 사용할 기존 기반 | 생산 후 열리는 개선 |
| --- | --- | --- |
| 신금속 | 기본 채굴·제련, 강철·회로, 물·기존 발전 | 전해 설비·경량 프레임·상위 전력 설비 |
| 고무 | 산림 기술과 기본 운송 | 절연 전선, 황을 연결한 강화 고무 |
| 석유 | 강철·회로·기본 운송과 발전 | 플라스틱·상위 회로, 윤활유·연료 |
| 황 화학 | 기본 채굴·화학 설비와 기존 전력 | 강화 고무, 선택형 고효율 정제 |
| 리튬 | 기본 운송·회로·기존 발전 | 배터리 팩·축전·상위 트럭 배터리 |
| 지열 | 기본 전력과 반입 설비로 분출구에 진입 | 안정적인 현지 발전과 송전 |

첫 거점은 현지 발전기로 독립 시동하고 거점 간 전력은 기본 전봇대로 연결한다. 전선 공유를 T05에 잠그지 않는다. [전력망 개정](전력망-연결-독립시작-개정.md)에 따라 터미널·방향 지정·망 처리 한도를 삭제했다. 고무를 얻기 위해 고무 케이블을, 리튬을 얻기 위해 리튬 배터리를 요구하는 순환 의존을 만들지 않는다. 새 산업은 먼저 한 가지 유용한 제품까지 완결하고 다른 지역과 조합한다. 소비처 없는 부산물이 쌓여 첫 생산이 막히지 않게 한다.

## 8. 날씨와 전력

최신 세부 규칙은 [날씨·지도 레이어 기획](날씨-지도레이어-상세기획.md)을 따른다. 지도는 기본·전력·운송·자원·날씨 보기로 전환하며, 전력 확인을 목표판의 행동으로 강제하지 않는다.

날씨는 지역별 발전·나무 성장·운송의 차이를 만드는 변수다. 생산 레시피 자체를 무작위로 바꾸지 않는다. 비·눈·모래바람의 현재 영향만 보여 준다. 예보·기상 관측 연구는 제외하며, 평소 완충 재고·자동 보조 발전·축전으로 변화를 흡수한다. 하루는 12분으로 확정했고, 날씨 시작·종류·종료는 [확률 발생 규칙](날씨-확률-발생규칙.md)을 채택한다. [연출 상세](공장-가동-운송-완료-연출-상세기획.md)에 따라 첫 범위는 기존 날씨 7종과 낮밤을 다듬고 오로라 등 새 환경 이벤트는 후속으로 둔다.

전봇대 연결 전력망은 지역 분업의 기반이다. 첫 외곽 거점은 현지의 기본 발전만으로 시작할 수 있게 하고, 발전이 좋은 입지와 전력이 많이 필요한 공장을 송전으로 연결하는 선택지를 더한다. 화산의 태양광 출력 0과 지열의 지속 발전 방향은 유지한다.

정류장 충전도 현지 수요에 포함한다. 전력 부족은 실제 전선으로 연결된 같은 망 전체에 전파되고 독립 망은 영향을 받지 않는다. 거점 수와 망 수는 별개다. 공급 범위·연결 거리·축전량은 개정 상세를 따르고 실제 부하로 검증한다.

## 9. 목표와 업적

메인 안내는 플레이어가 공장망을 만드는 순서에 맞춘다. ‘첫 운송’에서 끝내지 않고 **외곽 중간재 생산 → 다른 거점으로 배송 → 서로 다른 지역의 재료를 사용한 조립 → 최종 모듈의 허브 납품**까지 안내한다.

| 구분 | 역할 | 예 |
| --- | --- | --- |
| 메인 목표 | 생산망의 새 개념을 순서대로 배운다 | 두 거점의 재료로 첫 복합 제품 생산 |
| 선택형 도전 | 플레이어가 원하는 개선 과제를 고른다 | 원료 현지 가공, 야간에도 조립 공장 가동 |
| 업적 | 실제로 이룬 행동과 숙련을 기록한다 | 지역 간 유효 배송, 복합 조립과 허브 납품, 안정적인 송전 |
| 끝없는 연구 | 완성된 생산망에 더 큰 수요와 개선 동기를 만든다 | 기계·운송 성능 향상 |

완료는 건물을 놓았다는 사실보다 실제 운송·재료 소비·생산으로 판정한다. 빈 트럭 왕복이나 창고 사이 반복 이동으로 납품 실적을 부풀리지 않는다. 메인 목표는 생산·배송·사용 누적량으로 달성하며 중단돼도 실적이 남는다. 시간·비율 조건은 선택 심화에만 두고 충족 시간을 합산한다. 분당 생산량은 운영 진단·설계 참고값이다.

업적은 생산 효율을 위한 필수 보상으로 만들지 않는다. 이전 100종·262기록에서 새 제품·공급망 성취를 보강한 최신 후보는 116종·290기록이며 실제 구현 수가 아니다. 메인 진행·선택 도전·업적을 분리하고 활성화된 공개 기록으로만 완료율을 계산한다.

## 10. UI가 설명해야 하는 흐름

새 기능을 모두 넣은 뒤 UI를 마지막에 붙이면 지역 간 의존을 확인하기 어렵다. 구조를 먼저 기획하고, 각 산업을 만들 때 필요한 화면을 함께 연결한다. 최종 단계에서 밀도·색·배율·조작을 다듬는다.

| 화면 | 플레이어가 알아야 하는 것 |
| --- | --- |
| 메인 목표 | 지금 만들 제품, 필요한 재료, 연결할 지역, 다음 행동 |
| 지도 | 지형·자원지·거점·노선·발전 입지, 경고가 난 위치 |
| 제품 도감 | 만드는 재료와 공정, 생산 중인 지역, 어디에서 쓰는지 |
| 거점 요약 | 실제 입고·생산·출고, 부족 재료와 완충 재고 |
| 운송 | 무엇을 어디로 나르는지, 적재·하역·대기·충전 상태 |
| 조립기 정보 | 어떤 재료가 모자란지, 연결된 공급 거점을 확인할 수 있는 이동 기능 |
| 전력 | 지역별 공급·수요·저장·송수전과 날씨 영향 |
| 업적·도전 | 실제 생산과 연결된 목표, 다음 단계, 추적 상태 |

후반의 핵심 질문은 ‘왜 조립이 느리지?’다. 답을 따라 조립기 → 부족 재료 → 공급 거점 → 생산 또는 운송 문제로 이동할 수 있어야 한다. 모든 아이템의 이동 이력을 무한히 저장하는 방식은 요구하지 않는다.

## 11. 구현 전 기획 완료 기준

전체 흐름은 지역 분업 → 지역 간 운송 → 복합 조립 → 안정화 → 확장으로 잡는다. 구현을 시작하기 전에는 아래 항목을 실제 목록과 수치로 채운다.

1. **첫 복합 제품과 후반 대표 제품**: 청동 구동부·모터·제어기 → 고급 트럭·자동화 설비 모듈로 상세 기획했다. 기존 제품의 수요와 지역 간 연결을 플레이 테스트에서 확인한다.
2. **산업별 최소 생산 경로**: 상세 기획에 레시피·연구·설비·소비처와 비용안을 정리했다. 재료·해금·첫 설비의 순환 의존을 정적으로 확인하고 실제 게임에서도 검증한다.
3. **지도와 매장량**: 256×256을 새 지도 시제품 기준으로 정하고 자원지·매장량·부지·담수·도로 보장 조건을 상세 기획했다. 실제 시드 생성과 성능을 검증한다.
4. **물류와 전력 수치**: 기준 노선·적재·운행 주기·완충 재고와 지역 배전·송전·축전·발전 예산을 계산했다. 실제 운행·충전 대기와 소비량을 검증한다.
5. **후반 달성 조건**: 최고 단계 완제품인 자동화 설비 모듈 50개를 허브 프로젝트에 실제 납품한다. 납품량은 영구 보존하고 원격 공용 재고로 대신하지 않는다. 앞선 목표에서 고급 트럭 조립품을 사용 위치에 배송하고 만든 차량의 실제 배송도 확인한다. 시간·비율 유지 조건은 없다. 목표 시간은 경제 기획의 240~300분 기준안이며 실제 달성 시간과 난이도는 플레이 테스트로 조정한다.
6. **초반과 기존 저장**: 첫 지역 연결의 소요 시간을 검증한다. 기존 지도는 기존 크기·공통 전력망을 유지하는 호환 모드로 보존하고, 지도 확장·지역 전력 전환은 별도 기능으로 설계한다.

전체 요약·문서 우선순위·충돌 수정·미정 사항은 [통합 정리와 검토](기획-통합정리-검토.md)를 따른다. 현재 문서는 전체 경험과 기능의 역할을 연결한 기획안이다. 레시피·연구·지도·전력·운송·설비 입출구의 첫 수치안은 구체화했고 경제 비용안은 사용자 채택 기준이다. 모듈의 인접 창고 설치도 사용자 채택했으며 [완제품 사용 계약](모듈-장착-트럭생성-상세기획.md)에 설치·분리·차량 생성·예약·실패를 정리했다. 기존 코드에서 추가·수정할 내용만 전달하려면 [AI 변경 명세](AI-구현-변경명세.md)를 사용한다. 실제 생성·운행·밸런스·성능과 기존 저장의 선택형 확장 기능 검증은 남아 있다.
