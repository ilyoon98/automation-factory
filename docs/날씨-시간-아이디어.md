# 다양한 날씨와 시간 진행 아이디어

2026-10-27 · [날씨 기준 기획](날씨-지도레이어-상세기획.md)과 함께 검토할 후보

**예보는 넣지 않고, 오래 보고 싶은 공장의 풍경과 자연스러운 시간 변화를 만든다.** 하루 12분과 주요 날씨의 주기·지속·종류 추첨은 [날씨 확률 규칙](날씨-확률-발생규칙.md)의 방식으로 확정했다. 아래 추가 연출·계절은 미정 후보이며 다른 하루 길이는 과거 비교 기록으로 남긴다. 자원·레시피·납품 목표를 특정 날이나 계절에만 가능하게 제한하지 않는다.

## 1. 날씨를 늘리는 방법

계산 규칙과 보이는 모습을 분리하면 비슷한 효과를 공유하면서도 다양한 날씨를 볼 수 있다. 기존 7종 기상 효과에 새로운 생산 규칙을 계속 붙이기보다 지역·시간별 연출을 더하는 안을 우선 검토한다. 새 연출 후보는 활성 날씨 업적의 종류 수에 자동으로 추가하지 않는다.

| 후보 | 어느 장면에서 어울리는가 | 운영 영향 후보 |
| --- | --- | --- |
| 가랑비 | 숲·초원의 잔잔한 물결과 젖은 지면 | 기존 비의 약한 연출, 별도 패널티 없이 가능 |
| 짧은 소나기 | 햇빛 사이로 지나가는 비, 지나간 뒤 물방울 | 일반 비 효과 공유, 추가 기계 감속 없음 |
| 옅은 지면 안개 | 아침 강가·숲, 건물 아래만 얇게 흐름 | 시각 연출 중심. 건물·벨트·자원 정보는 가리지 않음 |
| 눈발 | 눈밭의 일상 풍경 | 기존 눈 효과 공유 |
| 눈보라 | 바람 방향으로 흐르는 굵은 눈 | 눈 효과의 강한 연출. 추가로 멈춤·동결을 넣지 않음 |
| 모래 먼지 | 사막의 먼 배경·도로 가장자리 | 기존 모래 바람과 공유하거나 시각 효과만 사용 |
| 건조한 돌풍 | 바위사막·염호의 먼지 띠 | 기존 강풍 출력과 공유, 별도 내구도 소모 없음 |
| 오로라 | 눈밭·염호의 맑은 밤 | 생산 효과 없이 드물게 만나는 야간 풍경 |
| 반딧불이 | 숲의 밤, 공장 조명과 대비 | 생산 효과 없는 환경 연출 |
| 유성·별이 많은 밤 | 조용한 야간 공장 전경 | 파편·자원 보상 없이 관찰 요소 |
| 꽃가루·낙엽 | 숲의 낮, 계절감을 더하고 싶을 때 | 기계 오염·청소 노동 없이 연출만 |
| 화산재의 밝기 변화 | 화산의 황혼·붉은 하늘 | 상시 환경 연출. 태양광 0을 제외한 추가 질식·온도 계산 없음 |

처음부터 전부 구현하기보다 가랑비·지면 안개·오로라처럼 서로 다른 분위기 3종 정도를 먼저 비교하는 안이 적합하다. 위 후보는 제안이며 확정된 추가 콘텐츠 목록이 아니다.

## 2. 하루 12분 확정과 이전 비교 기록

기준은 1배속 게임 시간이다. 같은 하루 길이도 2배속에서는 절반의 실제 시간이므로 함께 보기의 속도 설정까지 생각해야 한다. 표의 완전한 밤은 현재 위상 비율 20%를 유지했을 때이며 저녁·아침 전환은 별도다.

| 검토한 하루 길이 | 완전한 밤 | 느낌 | 결정 상태 |
| --- | --- | --- | --- |
| 12분 | 2분 24초 | 낮밤이 자주 바뀌고 짧은 플레이에서도 변화가 보임 | 사용자 채택, 확정 |
| 20분 | 4분 | 풍경이 천천히 바뀜 | 미채택, 비교 기록 |
| 30분 | 6분 | 긴 낮과 긴 밤 | 미채택, 비교 기록 |

하루 길이에 대한 비교는 종료하고 12분을 적용 기준으로 삼는다. 한 날은 완전한 낮 7분 12초·저녁 1분 12초·완전한 밤 2분 24초·아침 1분 12초다. 남은 일은 이 시간에서의 가독성·날씨 체감·전력 밸런스 검증이며, 하루 길이를 다시 정해야 하는 상태는 아니다.

## 3. 주요 날씨와 짧은 연출의 구분

| 방식 | 장점 | 주의점 |
| --- | --- | --- |
| 고정 3분 | 과거 확장안과 비교하기 쉬움 | 최신 추천은 고정 구간 대신 경과 시간 확률 사용 |
| 가변 5~9분 | 과거에 검토한 비교안 | 큰 날씨 4~5일 주기·강수 약 1일 지속안으로 대체 |
| 주요 날씨 + 짧은 환경 연출 | 큰 흐름이 드물어도 평소 풍경이 다양함 | 실제 효과와 시각 연출을 구분해야 함 |

채택한 방식은 **주요 날씨 시작 간격 평균 약 4.3일, 일반 강수 약 1일 지속**이다. 날씨 시작 여부를 먼저 추첨하고 종류를 한 번 고른다. 흐림은 약 반나절, 안개·폭풍은 약 1/4일로 더 짧게 둔다. 정확한 고정 간격은 아니며 경과 시간에 따라 시작·종료 확률을 높인다. 희귀 현상이나 특정 시각 납품을 메인 목표에 넣지 않는다.

짧은 환경 연출은 옅은 구름 그림자·낙엽·물안개·반딧불이처럼 공장의 실제 성능을 바꾸지 않는 후보를 사용한다. 별도 시작 추첨이 가능하지만 주요 날씨를 밀어내거나 그 시계를 초기화하지 않는다. 이 세부 빈도는 미정이다.

확률 검사 순번·현재 상태·시작 시각은 게임 상태에 저장한다. 현실 날짜·접속 시간·프레임 수를 사용하지 않고 함께 하는 사람들의 결과가 같아야 한다. 현재 코드의 180초 구간 설계를 바꾸는 작업이므로 구현 완료로 보지 않는다.

## 4. 계절을 넣는다면

봄·여름·가을·겨울을 자원 잠금보다 색·식생·기상 가중치의 변화로 사용할 수 있다. 봄에는 가랑비·꽃가루, 여름에는 소나기·밝은 밤, 가을에는 낙엽·안개, 겨울에는 눈·맑은 별빛처럼 구성한다.

첫 범위에서는 계절 없이도 다양한 장면을 볼 수 있게 하는 편을 권한다. 계절을 넣더라도 ‘겨울이라 주석을 못 캔다’, ‘여름에만 특정 부품을 만든다’ 같은 생산 제한은 두지 않는다. 계절마다 설비·물류를 다시 짓는 노동을 요구하지 않는다. 계절 길이도 전체 목표 플레이 시간과 함께 정해야 한다.

## 5. 화면과 생활감

- 낮에는 움직이는 재료와 기계, 저녁에는 창문·작업등·차량 조명이 눈에 띄게 한다.
- 밤에도 선택 테두리·도로·벨트·경고의 가독성을 유지한다. 어두운 밤 자체를 난이도로 사용하지 않는다.
- 풍향은 나무·연기·입자 방향에 우선 사용하고, 풍력 발전기의 설치 방향을 다시 맞추는 과제로 만들지 않는다.
- 비는 빗소리·물결, 눈은 소리의 잔잔함, 모래 바람은 낮은 먼지 소리처럼 구분한다. 음향·입자는 따로 줄일 수 있다.
- ‘7일 저녁 · 가랑비’ 정도의 현재 정보로 충분하다. 다음 날씨·끝나는 시각을 표시하지 않는다.

## 6. 시간에 관한 별도 결정

낮밤 길이, 기상 지속 시간, 첫 트럭까지의 시간, 최종 납품까지의 플레이 시간은 서로 다른 값이다. 하루를 길게 한다고 연구·기계·트럭의 실제 게임 시간까지 같은 비율로 느리게 만들지 않는다.

현재 모듈 50개는 기준 2개/분에서 순수 조립 25분이고, 공장 건설·연구·운송 준비를 포함한 엔딩 시간은 아니다. 후속 [진행 시간·경제 기획](진행시간-경제-상세기획.md)에 첫 기어 자동화 5~8분·첫 배송 25~35분·첫 지역 조합 40~55분·엔딩 240~300분의 기준안과 연구·설비 비용을 정리했다. 이 구간은 하루 길이와 별개로 실제 플레이를 검증한다. 특정 시각 출석, 일일 초기화, 접속하지 않은 동안 손실, 시간제한 납품은 추가하지 않는다.
