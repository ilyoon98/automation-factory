# 날씨 시작과 종료 확률 규칙

2026-10-27 · [날씨·지도 보기](날씨-지도레이어-상세기획.md) · [시간 아이디어](날씨-시간-아이디어.md)

**평온한 시간이 길어지면 날씨가 시작할 확률을 높이고, 날씨가 오래 이어지면 끝날 확률을 높인다. 시작이 당첨됐을 때만 종류를 한 번 고른다.** 평균 4~5일은 비만이 아니라 주요 날씨 전체의 시작 간격이다. 일반 강수는 평균 약 1일, 안개·폭풍은 더 짧게 둔다. 사용자가 하루 12분과 이 방식을 채택했으므로 새 확장 지도의 기획 기준으로 확정한다. 실제 게임에 구현됐다는 뜻은 아니며, 효과 배율 등 밸런스 수치는 시제품에서 검증한다.

## 1. 시작과 종류를 두 단계로 분리

평온 → 시작 확률 검사 → 종류 선택 → 진행 → 종료 확률 검사 → 평온 순서다. 주요 날씨는 세계에 한 종류만 진행한다. 지역별 비·눈·모래 바람 표현과 상시 화산재는 별도로 적용한다. 시작될 때마다 날씨를 다시 고르며 진행 중에는 종류를 매 검사마다 교체하지 않는다.

| 방식 | 장점 | 문제와 적합한 용도 |
| --- | --- | --- |
| 전체 시작 판정 후 종류 선택 | 주기와 종류 비율을 따로 조정. 새 종류를 추가해도 전체 시작 빈도를 유지하기 쉬움 | 채택한 방식 |
| 종류별로 따로 판정해 먼저 당첨된 종류 적용 | 지역마다 별도 기상을 움직이거나 겹치는 효과에 확장 가능 | 종류 수에 따라 전체 빈도가 바뀌며 동시 당첨·우선순위 규칙이 필요 |

예를 들어 네 종류가 같은 시점에 각각 20%로 독립 판정하면 적어도 하나가 당첨될 확률은 `1 - 0.8⁴ = 59.04%`다. 전체 20%가 아니다. 순서대로 검사해 첫 당첨을 고르면 같은 20%라도 뒤쪽 종류가 불리하다. 두 번째 방식도 총 발생률을 다시 보정하면 사용할 수 있지만 첫 구현에 그 복잡함을 추가할 이유는 적다.

## 2. 평균 주기의 의미

확정한 기획의 시작 간격은 평균 약 **4.3게임일**이다. 정확히 4일이나 5일이 되면 켜지는 예약제가 아니다. 이전 주요 날씨가 끝난 뒤 평균 약 3.6일의 평온을 거친다. 종류별 지속 시간이 달라 전체 평균 지속 시간은 약 0.68일이고, 일반 강수만 평균 약 1.01일이다.

| 기준 | 채택한 값 |
| --- | --- |
| 주요 날씨 시작 → 다음 주요 날씨 시작 | 평균 약 4.29일 |
| 이전 종료 판정 → 다음 시작 | 평균 약 3.61일 |
| 전체 시작 간격의 가운데 80% | 약 3.25~5.5일 |
| 한 번의 일반 강수 | 0.5~1.5일, 평균 약 1.01일 |
| 한 번의 흐림 | 0.25~0.75일, 평균 약 0.51일 |
| 한 번의 안개·폭풍 | 0.125~0.375일, 평균 약 0.25일 |

**하루는 720초, 1배속 실제 12분으로 확정했다.** 주요 날씨 시작 간격은 평균 약 51.5분, 일반 강수는 평균 약 12.2분이다. 2배속에서는 실제 시간이 절반이다. 날짜 기반 확률과 종류별 기준 지속 시간은 아래 값을 그대로 사용한다.

| 항목 | 1배속 실제 시간 |
| --- | --- |
| 첫 평온 보호 2일 | 24분 |
| 시작 확률 검사 간격 0.25일 | 3분 |
| 첫 시작 검사 2.25일 | 27분 시점 |
| 평온 최대 6일 | 72분 |
| 일반 강수 0.5~1.5일 | 6~18분 |
| 흐림 0.25~0.75일 | 3~9분 |
| 안개·폭풍 0.125~0.375일 | 1분 30초~4분 30초 |

비만 4~5일마다 오길 원한다면 이 수치를 그대로 쓰면 안 된다. 다른 종류가 선택되는 만큼 같은 종류의 간격은 길어진다. 이번 비율과 반복 완화에서는 강수 계열 시작 간격이 평균 약 8.74일이다. 비·눈·모래 바람은 같은 강수 사건의 지역별 모습이므로 이 계열 간격을 공유한다.

## 3. 시작 확률

경과 시간은 이전 주요 날씨의 종료 판정부터 센다. 새 게임도 같은 평온 시계에서 시작한다. 첫 2일은 주요 날씨를 발생시키지 않으므로 첫 공장을 준비할 수 있다.

이후 **0.25일마다 한 번** 검사한다. 첫 검사는 평온 2.25일 시점이다. 검사할 때 아직 평온하면 시작 확률을 4%포인트씩 늘린다.

| 평온 경과 | 그 검사에서 시작할 확률 |
| --- | --- |
| 2일 이하 | 0% |
| 2.25일 | 2% |
| 2.5일 | 6% |
| 2.75일 | 10% |
| 3일 | 14% |
| 4일 | 30% |
| 5일 | 46% |
| 5.75일 | 58% |
| 6일 | 100%, 장기간 무변화 방지 |

일반식은 검사 번호 n=1부터 `p = 0.02 + 0.04 × (n-1)`이고, n=16인 6일에는 1로 한다. 표의 확률은 **아직 시작하지 않은 상태에서 이번 검사에 당첨될 확률**이다. 누적 발생 확률이나 프레임마다 적용하는 확률이 아니다. 시작되면 평온 시계와 시작 검사를 멈추고 종료 쪽으로 전환한다.

## 4. 종류 선택과 반복 완화

| 기본 종류 | 기본 가중치 | 지속 시간 기준 S |
| --- | --- | --- |
| 일반 강수 | 55 | 1일 |
| 흐림 | 20 | 0.5일 |
| 안개 | 15 | 0.25일 |
| 폭풍 | 10 | 0.25일 |

처음에는 위 가중치로 한 번 선택한다. 두 번째 사건부터는 직전에 나온 종류의 가중치를 절반으로 줄이고 다시 정규화한다. 같은 종류의 연속 당첨을 완전히 금지하지 않되 종류가 바뀔 기회를 늘린다. 예를 들어 직전이 일반 강수이면 다음 선택 가중치는 `27.5 : 20 : 15 : 10`이다. 두 번 거듭 나왔다고 추가로 절반씩 계속 누적하지 않는다.

55·20·15·10은 기본 추첨 가중치이지 장기 실현 비율의 보장이 아니다. 이 반복 완화까지 적용한 장기 사건 비율은 강수 약 49.08%·흐림 22.15%·안개 17.08%·폭풍 11.69%다. 이 비율과 종류별 지속 시간을 합쳐 4.29일 평균을 계산했다.

### 지역별 변환

- 일반 강수: 초원·숲·화산은 비, 눈밭은 눈, 바위사막·모래사막·염호는 모래 바람.
- 흐림·안개·폭풍: 같은 기본 기상이 지역에 적용된다. 별도 지역 시계는 첫 범위에 없다.
- 화산재: 항상 존재하는 지역 환경이며 시작 확률을 경쟁하지 않는다.
- 오로라·반딧불이·옅은 구름 그림자 등: 환경 연출 후보다. 주요 날씨의 추첨 목록이나 날씨 업적 종류 수에 자동으로 추가하지 않는다.

날씨 종류를 더할 때는 기존 종류의 가중치를 어떻게 나눌지 정한다. 새 종류마다 별도 시작 확률을 붙여 전체 주기를 의도치 않게 줄이지 않는다. 지역 독립 기상을 도입하는 경우에만 지역별 시작 관리자를 검토한다.

## 5. 종료 확률

종류별 기준 지속 시간 S를 사용한다. 날씨가 시작된 뒤 아래 경과 시점마다, 아직 진행 중일 때 종료를 검사한다.

| 경과 시간 | 이번 검사에서 종료할 확률 |
| --- | --- |
| 0.5S 이전 | 0% |
| 0.5S | 10% |
| 0.75S | 25% |
| 1.0S | 45% |
| 1.25S | 70% |
| 1.5S | 100% |

일반 강수의 S는 1일이므로 절반쯤 지난 날에 그칠 수도, 하루 반까지 이어질 수도 있다. 폭풍의 S는 0.25일이므로 하루 내내 강한 폭풍이 계속되지는 않는다. 모든 종류를 정확히 하루에 멈추는 타이머로 만들지 않는다.

시작과 종료 연출은 현재 초안 20초 동안 부드럽게 연결한다. 시작 연출은 진행 시간에 포함한다. 종료가 당첨되면 주요 날씨 상태를 평온으로 바꾸고 그때부터 다음 평온 시간을 센다. 종료 연출 20초는 그 평온 시간의 앞부분과 겹치므로 주기 계산에 별도로 더하지 않는다. 실제 효과는 전환 배율로 서서히 줄인다. UI에는 현재 전환만 표시하고 종료 확률·종료 예정 시각·다음 종류는 알려 주지 않는다.

## 6. 비의 세기와 하루 단위 날씨의 부담

일반 강수는 약한 비와 보통 비가 주가 되게 한다. 시각 강도 후보는 약함 35%·보통 55%·강함 10%이며 주요 날씨가 시작될 때 한 번 선택한다. 이는 입자·소리·지면 표현을 위한 값이고 생산 배율을 다시 곱하지 않는다. 진행 중 자연스러운 잔물결·바람 변화도 고정 씨앗의 연출로 처리하며 종류·종료 추첨을 매 프레임 다시 하지 않는다.

하루짜리 일반 날씨에 기존 3분 초안의 큰 태양광·성장 페널티를 그대로 적용하면 부담이 커진다. 긴 보통 날씨는 아래처럼 완화하고 강한 폭풍은 짧게 두는 안을 권한다. 현재 날씨 표도 이 수치안으로 맞춘다.

| 날씨 | 태양광 날씨 배율 | 풍력 kW/대 | 트럭 속도 | 나무 성장 | 양수 처리량·가동 전력 |
| --- | --- | --- | --- | --- | --- |
| 맑음 | 1.00 | 60 | 1.00 | 1.00 | 1.00 |
| 흐림 | 0.75 | 100 | 1.00 | 1.00 | 1.00 |
| 안개 | 0.80 | 60 | 0.95 | 1.00 | 1.00 |
| 비 | 0.60 | 150 | 0.95 | 1.25 | 1.20 |
| 눈 | 0.55 | 150 | 0.90 | 0.75 | 1.00 |
| 모래 바람 | 0.50 | 150 | 0.90 | 1.00 | 1.00 |
| 폭풍 | 0.20 | 250 | 0.80 | 1.25 | 1.20 |

지형·낮밤·전력 부족과는 별개인 날씨 배율이다. 화산 태양광은 여전히 0, 고무 수액·지열 수율은 그대로다. 파괴·소실·추가 청소 노동은 없다. 긴 비를 버티려면 축전기를 수십 배 늘려야 하는 구조보다, 보조 발전·약한 날씨 효과로 흡수하는 방향이다.

## 7. 평온한 날에도 보이는 변화

확정한 하루 12분에서도 주요 날씨는 평균 약 51.5분 간격으로 드문 편이다. 그 사이에는 낮밤 조명·연기·옅은 구름 그림자·강가의 물안개·낙엽·반딧불이 같은 짧은 환경 연출을 후보로 둔다. 이 작은 연출은 실제 태양광·풍력·트럭 성능을 바꾸거나 주요 날씨 타이머를 초기화하지 않는다. ‘맑음’ 속에 약간의 구름이 보인다는 이유로 기능상 흐림과 혼동시키지 않는다.

평온 중의 구체적인 연출 빈도는 별도 미정이다. 큰 날씨의 주기를 줄이지 않고도 다양한 장면을 자주 볼 수 있게 하는 역할이다. 희귀 현상을 봐야 메인 목표가 열리거나 정해진 날에 접속해야 하는 구조는 넣지 않는다.

## 8. 저장과 함께 하기

세계 규칙 버전·하루 길이 D(720초)·현재 종류·직전 종류·날씨 시작 게임 시각·평온 시작 게임 시각·다음 검사 번호·이미 처리한 전환을 저장한다. 게임 시간으로 검사하며 일시정지에는 진행하지 않고 배속에서는 같은 게임 시간만큼 진행한다. 접속하지 않은 동안 현실 시간으로 날씨가 바뀌지 않는다.

추첨은 세계 씨앗·주요 사건 순번·검사 번호·시작/종류/종료 구분에서 결정한다. 프레임 수·카메라·날씨 UI·입자 표시 여부로 추첨 횟수가 바뀌지 않는다. 여러 검사 시점을 한 번에 지나면 게임 시각 순서로 처리하고 이미 처리한 검사를 로드 후 다시 실행하지 않는다. 하루 길이는 새 세계에서도 D=720초로 고정하고 첫 범위에 별도 하루 길이 선택 옵션은 넣지 않는다. 기존 세계의 D도 임의로 바꾸지 않는다.

UI는 현재 날씨와 현재 영향만 보여 준다. 다음 검사 시점·당첨 확률·기상 카운트다운·예보 연구는 없다. 기존 저장은 기존 기상 규칙을 보존하고 새 지도 규칙과 구분한다.

## 9. 계산과 플레이 검증

독립 시행의 생존 확률을 곱해 시작·종료 분포를 계산하고, 종류 반복 완화의 전이 비율을 합쳐 위 평균을 구했다. 주기 4.29일은 수학적 장기 평균이며 모든 플레이어가 매 4.29일마다 날씨를 보게 된다는 뜻이 아니다. 짧은 실제 플레이의 난이도·빈도 만족도는 별도다.

구현 시 평온 최소/최대 경계, 종료 최소/최대 경계, 시작한 직후 종류 재추첨 금지, 같은 종류 반복 가중치, 지역 변환, 저장 직전/직후 검사, 중간 참가·배속 일치, 입자 끔 동일 결과를 확인한다. 확정한 하루 12분에서 실제 날씨 빈도가 어떻게 느껴지는지와 긴 강수 동안 전력·운송이 과하게 흔들리지 않는지를 확인한다. 이 단계는 문서 기획이며 게임 코드는 변경하지 않는다.
