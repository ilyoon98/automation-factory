# 리서치: Steam 자동화 / 기지건설 게임

> 조사일: 2026-10-20
> 출처: Steam 자동화 카테고리, 기지 건설 태그, Steam 검색(태그 필터), 각 게임 상점 페이지와 사용자 리뷰
> 리뷰 수는 전체 언어 합계 (대략적인 판매 규모 지표)

## 1. 시장 지형

| 분류 | 대표작 (리뷰 수 / 긍정률) | 우리와의 관련 |
|---|---|---|
| 정통 자동화 2D | Factorio (236,042 / 98%), Mindustry (28,518 / 96%), shapez (16,049 / 96%) | 직접 레퍼런스 |
| 정통 자동화 3D | Satisfactory (281,498 / 97%), Dyson Sphere Program (92,025 / 97%), shapez 2 (15,502 / 97%), Captain of Industry (11,742 / 90%) | 시스템 참고 |
| 기지건설 + 콜로니 | RimWorld (248,463 / 98%), Oxygen Not Included (144,547 / 97%), Timberborn (42,227 / 96%) | ONI 전력망 참고 |
| 상점 경제 + 자동화 | Alchemy Factory (3,048 / 88%), Industry Idle (1,488 / 77%) | 경제 구조 참고 |
| 방치·증분형 자동화 | Rusty's Retirement (14,924 / 97%), 포춘 밀 (4,034 / 82%), 우리 집의 광산 (1,323 / 75%), 지심까지 파버려! (731 / 80%), 스타베스터 (830 / 70%) | 최근 신작이 가장 많은 분야 |
| 소형·캐주얼 자동화 | Beltmatic (2,285 / 95%), Astro Colony (2,757 / 80%), Mob Factory (478 / 73%) | 규모 비슷, 실패 사례 참고 |

관찰:

- 기지 건설 태그 상위권은 대부분 3D 생존 크래프트 (팰월드, Enshrouded, Core Keeper, Valheim).
- 2D 순수 자동화는 Factorio / Mindustry / shapez가 수년째 장악. 새로 나온 2D 중간 규모 히트작은 거의 없다.
- 2025~2026 신작은 방치/증분형 + 자동화 하이브리드에 몰려 있다.
- 장르 결합 패턴: 자동화 + 디펜스 (Mindustry), 자동화 + 상점 (Alchemy Factory), 자동화 + 생존 (Factorio).

## 2. 레퍼런스별 핵심 장치

| 게임 | 핵심 장치 | 가져올 것 |
|---|---|---|
| Factorio | 공장 → 오염 → 적 유인 → 방어에 자원 소모 | 시스템끼리 서로 압박하는 피드백 루프 |
| Mindustry | 생산 자원이 곧 탄약·유닛. 코어가 창고이자 건설 재료 공급원 | 허브 = 창고 + 건설 자재 방식 |
| shapez | 위협 없음, 허브 납품으로 레벨업 | 깔끔한 규칙, 낮은 진입 장벽 |
| Alchemy Factory | 생산품 판매 → 재료 구매·확장 | 경제 루프 (우리는 생산품 건설로 대체) |
| Oxygen Not Included | 전력 과부하, 배터리, 발전 부산물 | 전력에 부작용을 주면 고민이 깊어짐 |

## 3. 부정 리뷰에서 얻은 교훈

| 불만 유형 | 사례 | 대응 |
|---|---|---|
| 만들어도 보람이 없다 | shapez 2 (납품하면 끝, 다음 주문만 반복), Astro Colony (무한 자원·전력이라 고민이 없음) | 생산품으로 건물을 짓는다 |
| 금방 반복된다 | Beltmatic (기본 모듈 하나 만들면 복붙 반복) | 새 레시피/제약이 기존 설계를 흔들게 |
| 조작이 불편하다 | Astro Colony (L자 배선 불가), Mob Factory (핫바 교체 반복), shapez (복붙이 레벨 12에 잠김) | 드래그, 복붙, 단축키를 처음부터 |
| 철거·재배치가 고통스럽다 | Alchemy Factory (라인 갈아엎은 뒤 아이템 회수에 20분) | 철거 100% 환급, 벨트 위 아이템 자동 회수 |
| 설명이 없다 | Astro Colony (분배 방법), Industry Idle (튜토리얼 없음), shapez (마지막 메카닉) | 직관적 규칙, 상태 아이콘, 툴팁 |
| 중후반 경제 붕괴 | Alchemy Factory (중후반 수익 정체), Astro Colony (진행 속도 들쭉날쭉) | 비용·해금 곡선 사전 시뮬레이션 |
| 진행이 일자 코스 | Mindustry v8 (선형 캠페인으로 자유도 감소) | 정답이 하나가 아닌 문제 |
