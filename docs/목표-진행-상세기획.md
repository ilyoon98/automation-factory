# 지역 생산망의 목표와 진행

2026-10-27 · [생산 체인](생산체인-상세기획.md)·[지역 인프라](지형-운송-전력-상세기획.md)와 연결하는 목표 기획

**처음에는 한 공장을 연결하는 법을 배우고, 이후 여러 지역의 생산물을 조립 공장으로 모아 안정적으로 생산한다.** 메인 목표 36개는 새 개념을 배우는 순서, 선택형 도전은 원하는 운영 방식을 실험하는 과제, 업적은 실제 성취를 보존하는 기록으로 나눈다.

수량은 첫 밸런스안이다. **메인 목표에는 ‘몇 초 동안 몇 % 유지’를 요구하지 않는다. 생산·배송·사용 실적은 중단돼도 남는다.** 현재 코드의 29단계 안내와는 별도의 확장 설계이며, 게임을 구현하거나 완료 기록을 변경한 문서가 아니다. 대표 거점 A~H와 기준 노선은 설명용 이름이다. 플레이어가 자신의 공장 이름·위치·노선을 선택해도 같은 행동으로 달성할 수 있다.

## 1. 메인 목표 운영

[진행 시간·경제 기획](진행시간-경제-상세기획.md)의 1배속 첫 플레이 기준안은 첫 기어 자동화 5~8분·첫 배송 25~35분·구동부 20개 40~55분·최종 납품 240~300분이다. 이는 개발 중 밸런스 목표이며 실제 달성 조건에 시간제한·카운트다운·초과 불이익을 추가하지 않는다.

목표판은 9장으로 묶되 아래 선행 관계를 사용한다. 장 번호만으로 기능을 막지 않는다. 새 확장 세계의 지도 공개는 별도 [목표별 지역 공개](지도-목표별-공개-상세기획.md)의 완료 MG 조건을 적용한다. 철강·산림·물류, 석유·전해 금속, 황·리튬 가지는 병행할 수 있다. 화면에는 추적 중인 메인 목표 1개와 선택 도전 또는 공개 업적 1개만 고정한다.

연구가 필요하면 해당 연구와 부족 재료를 먼저 안내한다. 아래 목표의 ‘누적 생산’은 시작 재고·환급·창고 이동을 빼고 실제 제작 완료량으로 측정한다. 목표 수량은 이후 모든 건설·연구비를 합친 필요량이 아니다. UI에서 연구·건설 비용과 기계의 현지 투입 재료를 구분해 보여 준다.

연구 완료를 확인하는 메인 목표와 실제 연구 선행은 분리한다. T01~T08 연구는 생산 기획의 선행 연구·실제 비용으로 실행하며 해당 완료 목표를 먼저 달성해야 연구 버튼이 열리는 구조로 만들지 않는다. 예를 들어 T08은 T07+제지가 선행이지 MG32 완료가 선행이 아니다. 미리 완료한 연구는 해당 메인 목표의 선행이 충족되면 그대로 반영한다. 지도 공개는 별도의 MG 완료 조건을 계속 적용한다.

지도는 시작 초원 → MG03 초원 외곽 → MG07 눈밭 / MG08 숲 → MG14 모래사막·바위사막 → MG19 화산 / MG20 염호 → MG28 남은 전체 순으로 공개한다. MG07 배송은 공개된 초원 안에서 가능하고 MG08 목재는 시작 나무로 만들 수 있다. 공개 지역의 접근로·담수·부지를 함께 보장하며 연구/자원 채취 해금과 구분한다. 자세한 RV00~07·저장·지도 정보 제한은 링크 문서를 따른다.

MG28의 출발지는 해당 배송 품목을 자동 채취하거나 제작한 기록이 있는 거점이어야 한다. 원자원도 목적지 레시피에 쓰는 제작 재료이면 인정한다. 생산·출고 실적에 유효기간을 두지 않으며 잠시 멈춘 공장도 실적은 남는다. 창고만 여러 곳 설치해 출발지를 늘린 것은 포함하지 않는다. 특정 지형에 특정 레시피를 강제하지 않으며, 중앙 조립과 현지 중간재 생산을 함께 허용한다.

MG28의 도착지는 선택한 **공개 조립 부지의 정류장/창고**면 된다. T07 연구·대형 조립소 건설·첫 제작·도착지 자체 생산을 먼저 요구하지 않는다. 예를 들어 C의 모터·E의 프레임·G의 배터리를 각각 10개씩 H의 수동 설정 목표 재고 요청에 실제 배송한다. 이 품목은 후속 조립에 사용할 실물이며 같은 화물의 왕복은 추가 실적이 아니다. 도착지가 생산 거점이어야 한다는 전력 업적의 별도 조건을 이 목표에 적용하지 않는다. 이 목표 뒤 RV07 전체 공개가 이루어지므로 조립소를 먼저 지어야 지도/조립 부지가 열리는 순환을 만들지 않는다.

MG36은 여러 산업의 최고 단계 제품을 실제 허브로 모으는 최종 납품 목표다. 거점 수·생산 출처 수·분당 생산량·전력 비율·연속 가동 시간을 추가로 요구하지 않는다. 설계 예의 8거점·24대 차량을 그대로 요구하지 않는다. 서로 다른 지형 7종을 정해진 순서로 방문하거나 지열·축전을 반드시 사용하도록 요구하지 않는다. 완료 뒤 자유 건설·자원이 남아 있는 범위의 생산망 확장 연구와 심화 업적을 이어 간다. 광맥 독립 연구는 선택 경로로 남는다.

MG30·MG31·MG34의 실제 사용은 [설치·분리·트럭 생성 계약](모듈-장착-트럭생성-상세기획.md)을 따른다. 슬롯만 채우거나 조립품을 옮긴 것은 제작 완료/배송 실적이 아니다. 작업 중 첫 설치 전에 시작한 배치는 모듈 효과가 없으므로 그 완료만으로 MG34를 달성하지 않는다. 모듈을 사용한다고 기록한 다음 배치가 실제 완료돼야 한다. 고급 트럭 생성은 새 P22 제작량으로 세지 않으며 그 차량의 실제 배송으로 MG31을 판정한다.

### 허브 프로젝트의 납품 규칙

T08 이후 허브에 ‘공장망 완성 프로젝트’를 연다. 기존 자동화 설비 모듈은 여섯 산업 부품을 결합하는 최고 단계 제품이므로 새 아이템·새 레시피를 더하지 않고 최종 납품품으로 사용한다. 50개는 첫 밸런스안이며 기준 공장의 2개/분이면 순수 제작 25분에 해당하지만 어떤 속도로 만들든 완료할 수 있다. 실제 연구·설비 개선·준비 비용은 별도다.

플레이어가 ‘설비 모듈을 프로젝트에 납품’을 켜면 **실제 허브 투입구로 도착한** 모듈을 남은 목표만큼 프로젝트가 소비한다. 다른 지역의 공용 건설 재고에서 원격 차감하거나 모듈이 들어 있던 과거 허브 재고를 자동 소급하지 않는다. 이미 허브 일반 재고에 있는 모듈은 허브 상세에서 ‘프로젝트로 옮기기’를 선택해 현지 수량만 이전할 수 있다. 벨트 직접 반입 또는 허브에 인접한 정류장의 하역·연결로 최종 구간을 구성한다. 정류장을 멀리 놓았다는 이유로 순간 이동하지 않는다.

납품량은 영구 보존하며 장착 슬롯에 있거나 연구로 이미 소비된 실물을 납품 재고로 동시에 세지 않는다. 다만 사용 후 정상 분리·회수한 모듈은 실물로 반환되므로 허브로 실제 운송해 프로젝트에 납품할 수 있다. MG34의 과거 완료는 분리해도 보존한다. 장착 1개를 유지하며 납품하려면 총 51개, 회수 모듈을 납품에 쓰면 총 50개 제작으로도 가능하다. 이는 실물의 순차 사용이며 복제가 아니다. 목표 50개를 넘는 물량은 프로젝트가 소비하지 않으며 일반 허브 재고 공간이 없다면 기존 입출고 규칙으로 대기한다. 한 아이템이 같은 틱에 설치·연구·납품에 중복 소비되지 않게 처리 순서를 고정한다. T08 이후 미리 쌓은 프로젝트 납품은 선행 목표 완료 시 반영한다.

50개 납품과 MG36 선행이 충족되면 완성 연출·공장망 요약·계속 건설을 제공한다. 지도는 계속 운영하고 끝없는 연구·선택 도전·추가 거점 확장은 남는다. 종료 화면에서 새 세이브나 진행 초기화를 강제하지 않는다.

완료 표현은 [연출 상세](공장-가동-운송-완료-연출-상세기획.md) §9를 따른다. 작은 폭죽과 8초 카드, 완료 시점 경과 시간·실적 있는 생산 거점 수·납품량을 보여 준다. 즉시 닫을 수 있고 일시정지·카메라 이동·추가 대기 없이 계속 건설한다. 납품 50개만 먼저 채웠다면 선행 충족으로 MG36이 실제 완료됐을 때 한 번 축하한다. 불러오기·중간 참가는 과거 완료를 재연하지 않는다.

## 2. 생산과 배송의 판정

- 메인의 생산 거점은 자동 채취 또는 가공품 제작 누적 10개와 충전 외 실제 작업 소비 누적 1MJ를 기록한 구역이다. 원광·원유·수액·염수 채취 거점도 포함하므로 원료 운송 후 중앙 가공을 허용한다. 발전기·도로·창고만으로 세지 않는다. 중심의 맨해튼 거리가 20칸 미만인 구역들을 연결 성분으로 묶어 한 곳으로 세며 대표 ID는 최솟값이다. 위치 편집으로 기존 실적을 복제하지 않는다.
- 생산·배송·사용 실적은 목표를 추적하기 전부터 기록하며, 선행을 완료하면 확인 가능한 저장 실적을 반영한다. 재료 부족·날씨·정지·배속·노선 수정으로 쌓인 수량을 깎거나 초기화하지 않는다.
- MG15·MG28은 생산 출처와 실제 하역 기록을 대응한다. 다른 곳에서 가져온 화물을 창고만 거쳐 재출고해도 새 생산 출처가 되지 않는다. 유효 납품은 소비·건설·목표 재고의 실제 요청을 충족한 양이며, 같은 화물의 반복 왕복은 추가 실적으로 세지 않는다.
- MG35의 서로 다른 노선은 생산 출처와 목적지의 조합으로 센다. 같은 구간을 노선 여러 개로 나누어도 한 연결이다. MG36은 허브 전용 프로젝트의 실제 납품량으로 판정하며 재료의 생산 출처별 소비 조건을 추가하지 않는다.
- 출처별 생산·유효 출고·입고·소비 집계와 현재 재고의 출처별 잔량을 보관한다. 가공 완료 시 생산 출처를 해당 공장으로 바꾸고 기존 원료의 다단계 이력은 이어 붙이지 않는다. 출처·품목별 크레딧은 실물 수량을 넘지 않으며 창고·중계 정류장은 그대로 전달한다. 모든 아이템의 무한한 이동 이력을 저장하지 않는다. 완료 실적과 과거 공급 연결은 현재 운행 상태와 구분한다.
- Q60은 최근 게임 시간 60초 실제 완료량, 작업 전력 충족률은 최근 60초 실제 작업 공급/요청 에너지다. 충전·유휴를 제외하고 요청 0이면 ‘수요 없음’으로 표시한다. 둘은 운영 진단과 선택 심화 업적에만 쓰며 메인 완료를 막지 않는다.
- 정기편 기준 주기는 120초지만 플레이어가 바꿀 수 있다. 정시는 예정 도착 +15초 이내, 배송률은 실제 요청 대비 유효 하역량으로 최대 100%다. 노선 수정 후 단기 통계 창은 다시 모아도 메인 누적 실적은 보존한다. 요청 0인 빈 편은 성공·실패로 세지 않으며 설정 클릭·배치만으로 목표를 완료하지 않는다.

## 5. 목표 화면과 저장

왼쪽 목표 카드는 장 이름·현재 행동·최대 3개 확인 항목·하나의 다음 행동 버튼을 보여 준다. MG36은 ‘설비 모듈 허브 납품 12/50개’로 표시한다. ‘허브 위치’와 ‘부품·레시피’만 제공하고 목표판의 ‘전력 부족 확인’ 버튼은 제거한다. 전력은 지도 오버레이에서 원하는 때 확인한다. 펼치면 조립 공장 재고·운송 중·허브 납품 완료를 구분하고 완료량에는 마지막 값만 센다. O 목표판에서 메인 36개와 선택 도전을 펼쳐 볼 수 있다.

목표는 시뮬레이션에서 판정하고 고정 ID로 저장한다. 현재 코드가 안내 제목을 `guideDone`에 저장하는 방식을 새 목표에 복사하지 않는다. 기존 제목 기록은 보존하고 확인 가능한 기존 사건만 새 목표와 대응한다. 연구 완료는 연구 저장으로 소급할 수 있지만, 과거 생산·배송·지속 시간을 재고·배치만 보고 추정하지 않는다.

거점과 전력망은 [연결 망 개정](전력망-연결-독립시작-개정.md) §3에 따라 분리한다. 위 판정의 ‘구역’은 운영 거점(siteId), 20칸 연결 성분은 거리로 세는 거점 묶음이며 실제 전선 연결 성분과 무관하다. 같은 전력망으로 연결해도 MG15·MG28·D28의 생산/물류 거점 수와 누적 실적이 합쳐지거나 사라지지 않는다. CG03의 두 거점은 20칸 이상 떨어진 유효 생산 거점이며 실제 발전원 기여를 판정한다.

공장 목표·업적은 공동 기록, 개인의 추적·접힘·정렬은 개인 설정이다. 화면을 열지 않아도 같은 시뮬레이션 틱에 판정한다. 정지·배속·저장·중간 참가에서도 누적 실적·출처별 잔량·배송 개정과 일회성 알림을 일관되게 유지한다. 선택 심화의 조건 충족 시간도 저장하며 조건 미달에는 누적을 멈추고 이전 시간을 보존한다. 새 공장은 별도 기록으로 시작한다.

## 6. 검증 기준

메인 목표 36개와 선행 관계가 순환하지 않고 최종 목표에서 모든 메인 가지로 이어지는지 확인한다. 연구 T01~T08, 제품·설비 이름과 필요한 재료가 생산 상세 기획과 일치해야 한다. 지열·축전·고급 정제 같은 선택 도전은 메인 목표의 숨은 선행이 되지 않아야 한다.

이번 정적 검토에서 MG01~MG36의 중복·없는 선행·순환을 발견하지 못했고, MG36의 선행 그래프에 나머지 35개가 모두 연결됐다. 업적 표의 최초 42·심화 28·숨은 16과 이전 기록 후보 30을 합친 116종, 획득 기록 290개도 확인했다. 실제 플레이 소요 시간이나 달성 판정 코드를 시험한 결과는 아니다.

구현 후에는 시작 재고·환급·빈 운행의 오달성, 동일 화물 왕복·중계 시 출처 보존, 노선 수정과 일시 중단 후 실적 보존, 허브 납품 49/50개 저장 후 마지막 1개 완료, 출처별 소비 중복 방지, 동시 달성 알림, 예전 저장과 손님의 중간 참가를 확인한다. 이 문서의 미출시 조건은 누적형으로 완화하며 기존에 획득한 완료 기록은 취소하지 않는다. 비용과 목표 시간의 초기값은 경제 기획을 적용하고 실제 소요 시간·알림 밀도·첫 외곽 연결의 학습 부담은 플레이 테스트로 조정한다.
