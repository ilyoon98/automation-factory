# 사용성·운송·동기화 개선 (2026-11-01)

기준은 배포된 0.6.3 (`703c1d8`)이며, 아래 변경은 로컬 main에 반영했다. 게임 이용자용 목록은 `바뀐점.md`의 ‘다음 버전’에 있다.

## 지도와 조작

- 빈 땅의 상시 화면 이동 툴팁을 숨겼다. 설비·자원·건설 실패 정보는 유지한다.
- 화면 가장자리·좁은 창·글자 배율에 맞춰 툴팁 위치와 폭을 조절하고, 모달이 열리면 숨긴다.
- 청사진 꺼내기·세계 교체·되돌리기 때 이전 드래그를 정리한다. 새 게임·파일 불러오기·백업 복구는 이전 선택과 이동 키도 정리한다.
- 미니맵은 그 위에서 시작한 왼쪽 드래그에만 반응하며 지도 경계까지만 움직인다.
- 배율을 켰을 때 건설 카드 노출과 왼쪽 스크롤바의 클릭 범위를 수정했다. 스크롤 드래그 취소·포커스 상실을 처리한다.
- Shift+숫자 자동 반복과 숫자 조합키의 건설 선택을 분리했다. 모달·버튼의 Enter를 채팅이 가로채지 않고, 한글 조합 Enter로 청사진을 저장하지 않는다.
- 지연된 회수 명령은 실제 옮긴 품목과 수량을 표시하며 화면 배율을 적용한다.

## 운송과 저장

- 목표 재고 초안·초점은 재고 갱신 때 유지한다. 빈 값·0·음수·소수·안전 정수 범위를 벗어난 값으로 기존 목표를 변경하지 않는다.
- 목표 삭제 버튼과 아이템 도감 링크의 속성을 분리해 삭제 때 도감이 함께 열리지 않는다. 최종 화면 캡처에서 발견한 문제를 회귀 검사로 고정했다.
- 목표나 연결 창고를 바꾸면 미적재 예약을 다시 계산한다. 실은 화물은 보존한다.
- 같은 품목의 입고 예약이 여러 행으로 나뉘어 있어도, 일시정지 후 예약 합계는 실제 화물과 일치한다.
- 차량 복제와 기본 차량 추가·철거의 undo/redo는 운송 계획·주기·조기 출발·일시정지를 보존한다. 화물과 배터리는 복제하지 않는다.
- 계획을 끈 차량의 내부 상태도 저장해 중간 참가의 해시가 일치한다.
- 적재된 계획 운송의 새 끝점은 현재 배송·반송이 끝난 뒤 적용한다. 화면에는 다음 노선과 대기 이유를 표시한다. 저장·중간 참가·되돌리기·복제도 다음 노선을 보존한다.
- 출발지가 없어져도 이미 출발한 화물은 남은 목적지에 배송한다. 반송 중 계획을 꺼도 출발지에 실제 반환한다.

## 같이 하기

- 스냅샷 전환은 진행 중인 편집을 마감한다. 방을 떠난 참가자의 미완료 편집도 호스트가 마감해 재입장 후 undo가 합쳐지지 않는다.
- 호스트는 읽기 확인 전의 명령 결과를 보관하고 스냅샷에 포함한다. 손님은 콜백을 한 번만 완료하며, 명령을 재실행하지 않는다. 확인·퇴장 후 결과 보관을 정리한다.
- 결과 객체는 호스트가 처리한 시점의 데이터로 복원한다. 같은 id의 오래된 로컬 건물·차량이 응답을 대체하지 않는다.
- 장시간 검사에서 중간 참가 후 D02 가동률 업적의 누적 시간이 달라지는 문제를 재현했다. 업적 판정에 쓰이는 기계 가동률 표본을 스냅샷에 포함해 해결했다.
