# 상단 UI의 줄 배치와 고정 위치

2026-10-27 · [운영 UI](지역-운영-UI-상세기획.md) · [AI 변경 명세](AI-구현-변경명세.md)

**하단과 같은 종이색·갈색 잉크·픽셀 테두리를 사용하고, 되돌리기·다시 실행은 이름이 보이는 상단 버튼으로 유지한다.** 이 문서는 실제 줄 배치·좌우 정렬·화면 폭별 이동·팝업의 앵커를 구현 전에 정하는 기준이다. 게임 코드 변경은 별도다.

## 1. 기능별 묶음과 유지할 버튼

| 묶음 | 내용 | 표시·동작 |
| --- | --- | --- |
| 시간 | 현재 날씨 아이콘·몇 일차·낮/저녁/밤/아침 | 경과 시간·현재 지역 날씨는 상세/툴팁. 예보 없음 |
| 진행 | 정지/계속, 1×·2×·4× | 실제 현재 상태에만 선택 표시. Space 유지 |
| 편집 | `↶ 되돌리기`, `↷ 다시 실행` | 이름 항상 표시. Ctrl+Z/Ctrl+Y 보조 안내. 불가능하면 비활성 상태로 같은 자리에 유지 |
| 공장 창 | 운영 P·목표 O·업적 J·도감 G·연구 T | 실제 창 열기. 열린 창과 새 연구 가능 표식을 구분 |
| 지도·표시 | 지도 M, 기본·전력·운송·자원·날씨, 생산량 I | M은 현재 지도 열기 기능 유지. 5개 레이어는 실제 공장 지도에 적용. I는 기계 생산량 표시 토글 |
| 저장 | 저장됨·저장 필요·저장 중·저장 실패 | 항상 같은 폭의 버튼. 누르면 기존 수동 저장, 자동 저장은 기존 주기 유지 |
| 함께 하기 | 함께 하기, 채팅 | 함께 하기 진입 버튼 유지. 혼자 할 때도 채팅 버튼을 남기고 비활성 사유 표시 |
| 메뉴 | 새 게임·도움말 H·소리 설정 | 이름이 보이는 메뉴 버튼에서 열기. 기존 기능·단축키와 확인 절차 유지 |

되돌리기/다시 실행의 범위는 기존 편집과 [완제품 사용 계약](모듈-장착-트럭생성-상세기획.md)을 따른다. 버튼 표시를 이유로 생산·배송·연구를 과거로 되돌리거나 모듈·고급 차량 원가를 복제하지 않는다. 연구는 재료 지불 즉시 완료하는 기존 기획을 유지하며 연출 시간을 연구 대기 시간으로 만들지 않는다.

## 2. 좌표와 기본 치수

현재 UI는 `body > :not(#game)`에 `zoom: var(--uiz)`를 적용한다. 아래 치수는 **확대 전 UI 논리 픽셀**이다. 배율을 s, 화면 CSS 폭/높이를 Vw/Vh라 하면 사용 가능한 논리 폭 W=Vw/s, 높이 H=Vh/s로 계산한다. 지도 캔버스의 화면 좌표와 UI 논리 좌표를 섞지 않는다.

| 항목 | 기준 |
| --- | --- |
| 상단바 바깥 앵커 | 화면 위 0, 왼쪽 0, 오른쪽 0 |
| 상단바 테두리 | 위·아래 2px, 종이색 불투명 배경 |
| 한 줄 | 최소 높이 40px. 버튼 30px, 위아래 여백 각 4px, 줄 사이 얇은 선은 줄 높이에 포함 |
| 줄의 좌우 여백 | 바깥 테두리부터 각각 8px. 테두리 2px이면 내부 padding은 6px |
| 같은 묶음 버튼 간격 | 4px |
| 다른 묶음 간격 | 기본 8px. 필요하면 묶음 사이에 1px·높이 22px 세로 구분선 |
| 줄 사이 구분선 | 1px의 옅은 갈색. 탭 선택을 나타내는 선으로 사용하지 않음 |
| 글자·단축키 | 이름 12px, 키 배지 11px. 이름을 아이콘만으로 바꾸지 않음 |
| 편집 버튼 | 각각 최소 88px. ‘되돌리기’·‘다시 실행’ 전체 이름 유지 |
| 저장 버튼 | 최소 88px. 상태가 달라져도 다른 버튼 위치가 움직이지 않음 |

숫자·시간은 고정 자릿수 정렬을 사용한다. 터치 입력에서는 실효 터치 영역을 약 44px로 늘리고 실제 줄 높이를 다시 측정한다. 글자가 커지거나 번역/배율로 높이가 늘면 실제 높이를 기준으로 아래 앵커를 갱신한다.

## 3. 화면 폭별 줄과 좌우 정렬

### W가 900px 이상: 기본 2줄

```text
1줄 왼쪽  [날짜·날씨] [정지·1×·2×·4×] | [↶ 되돌리기] [↷ 다시 실행]
1줄 오른쪽                                      [저장 상태] [함께 하기] [채팅] [메뉴]
────────────────────────────────────────────────────────────────────────────────
2줄 왼쪽  [운영 P] [목표 O] [업적 J] [도감 G] [연구 T]
2줄 오른쪽                          [지도 M] | [기본 전력 운송 자원 날씨] [생산량 I]
```

1줄의 오른쪽 묶음은 화면 오른쪽 8px에, 2줄의 지도·보기 묶음도 오른쪽 8px에 맞춘다. 가운데 여유는 두 묶음 사이에서만 늘어난다. 편집 두 버튼은 붙어 이동하며 오른쪽 메뉴로 넘어가지 않는다. 기본 줄 높이대로면 상단바 높이는 84px다.

### 640px 이상 900px 미만: 3줄

```text
1줄 왼쪽  [날짜·날씨] [정지·배속]      오른쪽 [저장 상태] [함께 하기] [채팅] [메뉴]
2줄 왼쪽  [↶ 되돌리기] [↷ 다시 실행]  오른쪽 [운영 P] [목표 O] [업적 J] [도감 G] [연구 T]
3줄 왼쪽  [지도 M] | [기본 전력 운송 자원 날씨] [생산량 I]
```

3줄은 왼쪽 8px에서 시작한다. 기본 높이는 124px다. 편집 버튼을 누락하거나 가로 스크롤 뒤에 숨겨 2줄로 억지로 압축하지 않는다.

### W가 640px 미만: 묶음을 유지해 세로 배치

| 논리 줄 | 왼쪽 | 오른쪽 |
| --- | --- | --- |
| 1 | 날짜·날씨 | 저장 상태·메뉴 |
| 2 | 정지·배속 | 함께 하기 |
| 3 | 되돌리기·다시 실행 | 채팅 |
| 4 | 운영·목표·업적·도감·연구 | 없음. 이름을 유지하며 필요하면 같은 묶음 안에서 다음 줄로 넘김 |
| 5 | 지도 M | 생산량 I |
| 6 | 기본·전력·운송·자원·날씨 | 없음. 필요하면 다음 줄로 넘김 |

이 폭은 최소 지원 해상도 확정 전의 안전한 축소 배치다. 글자를 더 줄이거나 아이콘으로 이름을 대체하지 않는다. 내부 이름/버튼이 줄바꿈돼 물리 줄이 늘면 높이도 늘어난다. 단축키·작동 조건은 배치 전환으로 바뀌지 않는다. 접속 인원·저장 상태 변화만으로 묶음 순서를 바꾸지 않는다.

## 4. 상태 표현

- 선택한 배속·지도 레이어·켜진 생산량 표시는 금빛 배경과 눌림 상태로 표현한다. 열린 정보 창 버튼도 같은 그룹 안에서만 활성 표시한다.
- 정지 중이면 버튼 이름을 ‘계속’으로 바꾸고 정지 상태를 표시한다. 직전 배속은 기억하되 현재 실행 중인 것처럼 표시하지 않는다. 계속을 누르면 직전 선택 배속으로 재개한다.
- 편집 이력이 없으면 회색 버튼·비활성 상태와 ‘되돌릴 작업 없음/다시 실행할 작업 없음’을 보조 표시한다. 상태가 바뀌어도 너비·위치는 고정한다.
- 저장 실패는 경고 아이콘과 문구로 표시한다. 버튼을 누르기 전 성공으로 바꾸지 않으며 실제 저장 결과를 반영한다.
- 혼자 플레이 중에는 채팅을 회색 비활성 상태로 남기고 함께 하기 접속 후 사용 가능하다고 안내한다. 함께 하기 버튼의 진입은 항상 제공한다.
- 연구 가능 표식은 작은 점으로 두고 열린 창/선택 배속의 금빛 전체 강조와 구분한다. 다음 연구를 자동 선택하지 않는다.
- 날짜는 `floor(게임 경과 초/하루 길이)+1`로 표시한다. 날씨는 카메라 중앙의 실제 지형에 적용되는 현재 날씨를 표시하고 상세에서 지역명을 알려 준다. 기존 세계의 기존 날씨 규칙은 유지한다.
- 단계 공개 세계의 카메라 중앙이 미공개 셀이면 현지 이름/기상은 ‘미공개 지역’으로 표시하고 날짜/낮밤만 유지한다. [목표별 지도 공개](지도-목표별-공개-상세기획.md)의 정보 제한을 따르며 상단 시계로 미공개 지형을 미리 노출하지 않는다.

## 5. 높이 측정과 앵커

`H_top`은 상단바의 실제 논리 높이, `H_bottom`은 기존 하단바의 실제 논리 높이다. 둘 다 테두리를 포함한다. 기본 2/3줄의 예상 높이를 다른 창의 고정 top 값으로 복사하지 않는다.

| ID | 대상 | 고정 위치·계산 |
| --- | --- | --- |
| A | 상단바 왼쪽 기준선 | x=8, 바깥 top=0. 각 줄의 첫 묶음이 같은 선에서 시작 |
| B | 상단바 오른쪽 기준선 | x=W−8. 저장/세션/메뉴 묶음의 마지막 버튼 오른쪽을 맞춤 |
| C | 메뉴·시간·함께 하기·채팅 팝오버 | y=H_top+8. 메뉴/세션/채팅은 트리거 오른쪽 맞춤, 시간은 트리거 왼쪽 맞춤. x는 화면 여백 안으로 보정 |
| D | 연구 완료·일반 완료 알림 카드 | x=W/2 중앙, y=H_top+8, 너비=min(360,W−16). 알림 전용 자리에서 한 장씩 표시 |
| E | 왼쪽 목표/재고 판 | x=8, y=H_top+8. 넓은 화면의 기존 좌측 정보 묶음 유지 |
| F | 오른쪽 선택 상세 | right=8, y=H_top+8. 기본 너비 280 이하, 화면 안에서 제한 |
| G | 지도 범례 | right=8, y=H_top+8. 선택 상세가 열려 있으면 별도 겹친 창 대신 그 상세 위쪽에 결합 |
| H | 연구·운영·목표·업적·도감 큰 창 | x=W/2 중앙, y=H_top+8. 너비는 기존 창별 제한과 W−16 중 작은 값 |
| I | 기존 하단 건설 도구 | 화면 bottom=0, left=0, right=0. 기존 H_bottom 측정 유지 |

팝오버 폭은 기본 240~280px에서 W−16을 넘지 않게 한다. 보정식은 `x=max(8,min(희망 x,W−팝오버 폭−8))`이다. 상단 1줄 버튼에서 연 팝오버도 그 버튼 바로 아래의 다음 줄을 가리지 않고 **전체 상단바 아래**에서 시작한다. 메뉴 버튼이 오른쪽에 있으므로 메뉴는 특히 right 정렬을 유지한다.

본문 판/큰 창의 최대 높이는 `max(0,H−H_top−H_bottom−16)`을 기준으로 제한한다. 내용이 길면 해당 판 내부에서 스크롤한다. W가 900px 미만이면 좌우 판을 동시에 넓게 펼치지 않고 선택 상세를 우선하는 한 판 보기로 전환해 목표판과 겹치지 않게 한다. 기존 판으로 돌아가는 위치와 선택은 보존한다.

이 실제 구분선과 달리, 시안에서 보이는 A/B/C/D 앵커 안내선은 확인용이다. 배포 게임에 좌표 안내선을 상시 그리지 않는다.

## 6. 구현 시 좌표 변환

1. 기존 `#topbar`를 `ResizeObserver`로 관찰해 확대 전 `offsetHeight`를 `--top-h`에 넣는다. 기존 `--bottom-h`와 같은 논리 좌표 공간을 사용한다.
2. 상단 메뉴·플레이어 목록의 기존 `top:46px`, 정보창 `top:52px` 같은 상수는 `calc(var(--top-h) + 8px)` 기준으로 교체한다. 큰 창·알림·높이 제한의 상수도 이 계약을 적용한다.
3. 버튼의 `getBoundingClientRect()`로 앵커를 구하면 물리 CSS 좌표를 `--uiz`로 나눈 뒤 UI 논리 좌표에 적용한다. s를 두 번 곱하거나 서로 다른 좌표 공간의 right/width를 섞지 않는다.
4. 화면 폭·UI 배율·접속 상태·텍스트 변경 때 위치와 실제 높이를 다시 계산한다. 배율 125%·150%에서도 실제 화면상의 간격은 논리 8px에 해당해야 한다.
5. 표시 위치 변경은 DOM/로컬 UI 상태에서 처리하며 생산·연구·목표 실적을 바꾸지 않는다. 노드 이동은 실제 DOM 순서도 줄의 읽는 순서와 같게 해 키보드 이동이 화면 순서와 어긋나지 않게 한다.
6. 지도 캔버스는 기존 화면→세계 좌표 변환을 유지한다. UI 위 포인터 입력은 지도 건설/선택으로 새지 않게 한다. 팝오버를 감추려고 전체 상단바에 `overflow:hidden`을 적용하지 않는다.

## 7. 겹침과 닫기

| 레이어 | 기준 z-index |
| --- | --- |
| 지도/월드 | 0 |
| 지도 정보 오버레이 | 10 |
| 일반 HUD·좌우 판 | 20 |
| 상단바 | 30 |
| 상단 팝오버·메뉴·플레이어/채팅 목록 | 50 |
| 큰 모달 창 | 80 |
| 연구 완료 등 알림 카드 | 90 |
| 툴팁 | 100 |

연구 창을 연 상태에서 완료해도 축하 카드가 위에 보이게 한다. 동시에 여러 연구가 완료되면 카드의 실제 적용은 즉시 진행하고 연출은 모아 보여 준다. 카드·팝오버가 상단 버튼을 덮지 않는다.

팝오버는 동시에 한 개만 열며 다른 상단 기능을 누르면 해당 팝오버로 바꾼다. 바깥 클릭·X·Esc로 닫고 기능 버튼에 키보드 포커스를 돌린다. Esc는 알림 카드 → 열린 팝오버/모달 → 선택 상세 → 오버레이 기본 복귀/건설 도구 순서의 기존 우선 관계를 유지한다. 입력칸에서 글을 쓰는 동안 Space·I·M·T 등 게임 단축키를 실행하지 않는다. 기존 함께 하기의 조작 권한과 버튼 비활성 조건을 보존한다.

## 8. 검증할 배치와 동작

- 논리 폭 1280·980·900은 2줄, 899·736·640은 3줄, 639·480·320은 작은 묶음 배치인지 확인한다. 최소 지원 게임 해상도 확정과 별도로 시안은 320px 폭까지 검토한다.
- 모든 폭에서 되돌리기·다시 실행의 이름과 버튼이 보이고, 이력이 없어도 사라지지 않는다. undo 후 redo 활성화, redo 후 반대 상태와 버튼 위치를 확인한다.
- 상단바의 좌우 첫/마지막 끝이 8px 기준선을 지키고 줄 사이 1px 선·버튼 간격이 일치하는지 확인한다. 글자·버튼·키 배지의 겹침과 잘림이 없어야 한다.
- 메뉴·시간·함께 하기 팝오버가 전체 상단바 아래 8px에서 시작하고 화면 양 끝 8px 안에 들어가는지 확인한다.
- 연구 완료 카드가 상단바 아래 중앙에 놓이고, 연구 창이 열려 있어도 읽히며 X·Esc로 닫히는지 확인한다. 연출을 연구 실행으로 중복 집계하지 않는다.
- 창 크기와 UI 배율을 바꾸는 동안 열린 팝오버·좌우 판·알림의 앵커가 갱신되는지 확인한다. 예전 고정 top 값으로 2/3줄째를 덮지 않아야 한다.
- 저장됨/저장 중/실패, 혼자/함께 하기, 정지/재개, 지도 레이어 전환에서 버튼 폭·핵심 순서가 흔들리지 않는지 확인한다.
- O/J/G/T/P/M/I/Space/Ctrl+Z/Ctrl+Y와 텍스트 입력·초점 복귀, 기존 저장을 확인한다. 상태 표시는 실제 실행 결과를 사용한다.

이 문서는 UI 배치·상태 계약이다. 함께 보여주는 독립 시안의 샘플 이력·저장·연구는 상호작용을 확인하기 위한 값이며 실제 세계를 변경하거나 게임 기능의 통과를 증명하지 않는다.
