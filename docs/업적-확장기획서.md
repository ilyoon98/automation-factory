# 업적 확장 기획서

2026-10-27 · [확장 기획서 버전 3](기획서-버전3.md)의 업적 상세 설계

**설계 문서이며 게임 구현 완료 목록이 아니다.** 특히 아래 숨은 업적 표에는 이름·정답·판정 조건이 모두 있다. 플레이어용 도움말이나 배포 설명에 이 표를 그대로 노출하지 않는다.

## 1. 구성과 목표

기존 업적은 생산량과 공장 규모의 기록으로 남긴다. 신규 업적은 처음 배운 행동, 운영 숙련도, 우연히 발견하는 재미를 채운다.

| 구분 | 계열 수 | 계열당 단계 | 획득 기록 수 |
| --- | --- | --- | --- |
| 기존 누적·속도·공장 기록 | 30 | 4 | 120 |
| 신규 최초 달성 | 30 | 1 | 30 |
| 신규 심화 | 24 | 4 | 96 |
| 신규 숨은 업적 | 16 | 1 | 16 |
| 합계 | **100** | — | **262** |

이번에 새로 설계한 것은 **70종**이다. 기존 30종을 신규 70종에 중복해서 세지 않는다. 심화의 네 기준은 동·은·금·다이아 순서이며, 위 단계를 한 번에 만족하면 아래 단계도 함께 달성한다. 모든 조건은 플레이 테스트 전의 명확한 판정 초안이다.

### 기능 의존 표기

| 표기 | 의미 |
| --- | --- |
| K | 기존 생산·물류·숲·3종 지형·날씨 기능을 기반으로 설계 가능 |
| B | 7종 지형과 특화 자원 분포 필요 |
| R | 원유·고무·황·리튬과 신규 생산 체인 필요 |
| P | 지역 전력 구역·송전·축전·지열 등 전력 확장 필요 |
| E | 조사 보고서·탐사 시스템 필요 |

`K`도 **업적 자체가 구현돼 있다는 뜻이 아니다**. 현재 기능에서 판정 사건과 집계를 보강하면 만들 수 있다는 의미다. 여러 표기가 있으면 모두 필요하다. 해당 기능이 없는 버전에서는 업적을 비활성화하고 완료율의 분모에서도 제외한다.

## 2. 공통 판정 규칙

### 2.1 시간·수량·실제 행동

1. 모든 시간은 게임 시뮬레이션 시간이다. 일시정지는 진행 시간에 들어가지 않고, 2배·4배속에서는 게임 시간만큼 진행한다. PC 시각·프레임 수·창을 연 시간은 쓰지 않는다.
2. 생산량은 제작 완료·실제 채굴·실제 벌목 사건으로 센다. 시작 재고·파일 불러오기·철거 환급·나무 위 건설 환급·창고 이동은 새 생산이 아니다.
3. 기본 단위는 아이템 개수, 거리 칸, 전력 kW, 에너지 MJ다. 에너지는 실제 kW × 경과 초를 적분해 환산한다. 발전기 명목 출력이나 유휴 설비의 표시 용량은 공급 실적이 아니다.
4. 실제 공급은 기계 가동·유효 차량 충전 등 수요에 전달된 전력이다. 송전 에너지 조건은 별도 언급이 없으면 **수신 구역의 기계·차량이 최종 소비한 양**을 센다. 충전만 반복하거나 중간 송전 구간을 여러 번 지난 것을 중복 합산하지 않는다.
5. 유효 배송은 트럭이 출발지와 다른 정류장에 실제로 화물을 내린 사건이다. 빈 운행·배터리 충전·정류장 배치·노선 설정만으로 배송 업적을 주지 않는다. 동일 배송 사건을 재접속·재동기화로 다시 세지 않는다.
6. 업적은 한 번 완료하면 조건이 낮아져도 취소되지 않는다. 건물 수·지역 수처럼 현재 상태를 재는 조건은 계속 지었다 철거하는 누적 횟수로 대체하지 않는다.

### 2.2 생산 속도와 지속 가동

- `Q60`은 최근 게임 시간 60초의 **실제 완료 생산량**이다. 충분한 60초 기록이 없으면 속도 조건을 판정하지 않는다.
- 기존 속도 업적은 Q60 한 번 충족으로 유지한다. "1분 내내 일정 속도"를 요구하는 것으로 설명을 바꾸지 않는다.
- 신규 심화 표에 `180초 유지`라고 적으면, 매초 Q60 등 해당 조건을 확인해 180초 동안 연속으로 만족해야 한다. 중간에 실패하면 해당 연속 시간만 0으로 돌아가며 누적 실적과 달성 메달은 유지된다.
- 표의 `가동률`은 그 기계가 온전히 존재한 최근 60초 중 실제 작업한 시간 비율이다. 재료 부족·출력 막힘·전력 부족 시간도 분모에 포함한다. 레시피 변경·건물 교체로 불리한 구간을 지우지 못하게 새 60초 기록을 다시 모은다.
- `가동 구역`은 최근 60초에 실제 제작 완료가 있는 생산 기계를 포함하고, 기계·차량의 배터리 충전 외 소비 수요가 최소 100kW인 구역이다. 축전기를 충방전만 하는 빈 구역은 포함하지 않는다.
- `전력 충족 95%`는 실제 공급/작업 수요가 0.95 이상이라는 뜻이다. 수요 0인 순간은 지속 가동 시간으로 인정하지 않는다.

### 2.3 지역·날씨·전기 출처

- 건물의 지형은 중심 칸으로 정한다. 도로·컨베이어·창고·빈 정류장으로 생산 거점의 수를 채우지 않는다.
- 전력 구역은 변전소·허브 등 구역 기준점의 지형으로 분류한다. 개별 건물의 발전 배율과 현지 날씨는 각 건물의 중심 칸을 따른다.
- 날씨 조건은 **20초 전환이 끝난 현지 날씨**에서 센다. 별도 조건이 없다면 한 날씨 구간 안에서 실제 가동 60초를 확인한다. 3분 날씨의 안정 구간에 3분 이상 유지하도록 요구하지 않는다.
- 한밤은 기존 하루 720초 중 위상 0.7 이상·0.9 미만인 구간이다. 게임 날짜는 `floor(게임 시간 / 720)`로 구분한다.
- 폭풍·안개 등 확률형 현상은 후속 날씨에서 반복 도전할 수 있다. 특정 첫날·첫 폭풍·세이브 생성 직후만 가능한 업적은 만들지 않는다.
- 태양광·풍력·수력·지열·연료·허브·축전기 방전의 기여를 구분한다. 축전기는 에너지를 만드는 설비가 아니며, 친환경 조건에는 충전 당시의 발전원 비율도 반영한다.
- 전력 구역 분리·병합·기준점 이동·송전 방향 변경은 연속 가동 업적의 관련 구간을 다시 측정한다. 누적 소비와 이미 완료한 업적은 유지한다.

## 7. UI와 알림

- 업적 창은 `최초 / 기록 / 심화 / 숨은` 탭으로 나눈다. 각 탭에 생산·물류·전력·지역·숲·탐사 필터를 제공한다.
- 이름 검색, 미달성만 보기, 다음 단계가 가까운 순 정렬을 제공한다. 검색 결과나 정렬 정보로 숨은 이름·조건을 미리 노출하지 않는다.
- 최초는 완료 표시, 기록·심화는 네 메달과 다음 기준, 숨은 업적은 달성 전 힌트·달성 후 이름과 설명을 표시한다.
- 신규 최초·심화는 한 개를 추적할 수 있다. 숨은 업적은 달성 전 정확한 진행도 추적을 제공하지 않는다.
- 연속 가동은 현재 연속 시간과 필요한 시간을 표시한다. 조건이 끊기면 재료 부족·출력 막힘·전력 부족 등 이유를 보여 준다.
- 한꺼번에 여러 업적을 달성하면 한 알림으로 묶고 상세 내역을 업적 창에서 확인한다. 저장 로드·중간 참가의 일괄 소급은 소리를 반복하지 않는다.
- 공개 완료율은 활성화된 최초·기존 기록·심화의 획득 기록 수 기준이다. 비활성 계열과 숨은 업적은 공개 완료율의 분모에서 제외한다. 숨은 업적은 별도의 발견 수로 보여 준다. 표의 262개는 모든 기능을 활성화했을 때 숨은 기록까지 합친 설계 총수다.
- UI 배율·키보드 포커스·목록 스크롤·애니메이션 줄이기를 기존 창과 동일하게 지원한다.

### 보상

첫 구현의 보상은 업적 기록·알림·완료 도장이다. 후속 보상은 칭호·허브 장식 등 외형으로 한정한다. 생산 속도·전력·자원 보상을 업적에 붙여 숨은 조건을 공략해야 효율이 좋아지는 구조를 만들지 않는다.

| UI | 개인별 필터·추적 선택. 공장 업적의 판정 상태와 분리 |

- 업적은 시뮬레이션에서 판정한다. UI는 결과를 읽고 알린다. 화면을 열지 않았거나 탭이 가려져도 같은 틱에 같은 결과가 나와야 한다.
- 최초·숨은 완료 기록, 심화 메달, 누적값, 연속 타이머와 이를 판단하는 데 필요한 최근 창·출처 집계를 저장과 네트워크 스냅샷에 포함한다. 불러오기나 중간 참가가 진척을 임의로 초기화하지 않게 한다.
- 기존 속도 업적의 디스크 불러오기 후 1분 재측정은 기존 동작으로 남길 수 있으나, 신규 심화의 저장된 연속 조건을 보존하려면 대응하는 최근 창도 함께 저장해야 한다. UI에서 두 규칙을 구분한다.
- 완료 후 재접속·재동기화·되돌리기로 누적값과 알림을 중복 생성하지 않는다. 설비 되돌리기는 이미 실제 발생한 생산·소비 사건을 재발생시키지 않는다.
- 업적은 공장 저장 단위의 공동 기록이다. 혼자 새 공장을 만들면 별도 기록으로 시작한다. PC 계정 단위 최고 기록 통합은 후속 범위다.
- 원래 존재하던 공장의 사건을 확인할 수 없으면 추정 달성하지 않는다. 과거 기록이 없어도 이후 플레이로 모든 신규 업적에 다시 도전할 수 있게 한다.
- 오래된 저장의 원래 메달 ID를 삭제하거나 다른 조건으로 재사용하지 않는다. 표시 제목은 바꿀 수 있어도 저장 ID는 고정한다.
- 필요한 사건·집계를 보존하되 모든 아이템의 무한한 이동 이력을 쌓지 않는다. 출처가 필요한 전력·물 반입 등은 한정된 집계로 설계하고 저장 크기·틱 비용을 측정한다.

## 9. 구현 순서

1. 기존 기록 보존과 업적 탭·숨김·알림 규칙을 구현한다.
2. 현재 기능 기반 최초·심화·숨은 업적부터 연결한다. `K`만 있는 계열이 첫 대상이다.
3. 7종 지형·신규 자원·지역 전력망을 만들 때 관련 계열을 함께 활성화한다.
4. 전력 출처·유효 배송·숲 세대·지속 가동의 사건 집계를 검증한 뒤 복합 숨은 업적을 활성화한다.
5. 탐사 기능과 D24를 연결하고 실제 플레이에서 메달별 소요 시간·알림 밀도를 조정한다.

## 10. 구현 완료 확인 기준

- 모든 기준값의 직전·정확한 도달·여러 단계 동시 도달을 확인한다.
- 시작 재고·철거·복사·창고 이동·빈 트럭·유휴 발전으로 생산/공급 업적을 얻지 못한다.
- 180초 지속 조건은 179초에서 멈추면 완료되지 않고 다시 측정한다. 일시정지·배속·저장·중간 참가에서도 같은 게임 시간 규칙을 따른다.
- 날씨 전환 중·전환 완료 후·날씨 끝 경계의 판정이 일치한다. 눈·모래 바람은 건물의 현지 지형을 사용한다.
- 송전 다중 경유·방향 변경·축전기의 혼합 발전원에서 최종 소비를 중복 집계하지 않는다.
- 같은 원료·트럭·나무·자원지를 다시 읽어 동일 사건을 여러 번 세지 않는다.
- 기존 메달은 유지되고 활성 기능이 없는 미래 업적은 완료율에서 빠진다.
- 미달성 숨은 이름·수치·진행도가 검색·툴팁·정렬·알림·공유 화면에 유출되지 않는다.
- 새 지도마다 모든 활성 지형·자원지와 업적에 필요한 최소 공간을 보장한다. 자원지 25곳 미만인 특수 지도에서는 D24의 불가능한 단계를 활성화하지 않거나 별도 목표를 정한다.
- 두 참여자가 같은 명령을 실행하고 한 명이 도중에 들어와도 같은 시각·메달·최초·숨은 완료 결과를 얻는다.
- 네 단계 수치와 70개 신규 ID는 플레이 테스트 후 조정할 수 있지만, 저장 호환 규칙과 이미 얻은 기록은 유지한다.
