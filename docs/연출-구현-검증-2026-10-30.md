# 공장·운송·완료 연출 구현 기록

2026-10-30 · 작업 기준: `feat/2026-10-27-regional-d09`, 시작 HEAD `27d14d7`, 버전 `0.6.0`.

루트의 `docs/공장-가동-운송-완료-연출-상세기획.md`를 기준으로 기존 표현을 보완했다. 새 버전 배포는 실행하지 않았다.

## 적용

- 실제 작업량/제작 시간의 누적 위상으로 작업 프레임을 결정한다. 전력 부족 일괄 반속도와 시각×현재 배율 계산을 제거했다. 발전기 작업부는 출력에 비례해 위상을 누적하고, 풍력은 실제 현지 바람을 읽는다. 기존 설비 그림을 유지하면서 정유소 유체 눈금과 대형 조립소의 여섯 투입부를 보완했다.
- 차량별 현재 적재 용량으로 빈 차/부분/가득 그림을 고른다. 바퀴는 실제 이동 거리, 배터리 눈금은 실제 받은 충전량을 따른다. 성공한 기본/계획/반송 상하차에서만 화물 이동을 만들고 정류장당 실제 시간 0.3초로 묶는다. 차량 상세 kW도 실제 받은 충전량을 사용한다.
- 설치·철거의 기존 효과를 재사용한다. 작은 도로·벨트 먼지는 2개, 파편은 4개로 줄이고 편집 소리의 공통 간격을 0.12초로 제한했다. 설치 실패는 대상과 실제 이유만 잠깐 강조한다.
- 실제 전력 간선 전체를 읽어 안정적인 대표 신장 숲을 그린다. 선택 시 모든 실제 인접 간선과 철거 영향을 표시하고, 전력 보기에서는 보조 간선을 옅게 표시한다. 같은 망의 공급 면은 한 경로로 한 번 채워 겹침이 진해지지 않는다. 배치 미리보기는 실제 배치 중심과 새 범위를 사용한다.
- 현지 날씨는 공개된 해당 지형에서만 표시한다. 밤의 어둠을 낮춰 판독성을 높였다. 정보 보기의 날씨 입자는 기본의 40%, 축소 시 0개이며 날씨 입자 상한은 256개다. 접근 마스크와 지형별 경로는 화면/공개 상태가 바뀔 때만 다시 만든다.
- 공용 상단 카드에 연구 4초·작은 폭죽 0.8초·금빛 1.5초 회전과 최종 완료 8초·두 번의 작은 폭죽을 연결했다. 우선순위는 최종 완료 → 연구 → 일반 목표/업적이며 반복 알림은 묶는다. X/Esc/계속 건설은 즉시 닫는다. 해금 보기와 완료 기록 보기를 제공한다.
- MG36 실제 첫 판정에서만 완료 시점 경과 시간·기존 정의의 생산 거점 수·프로젝트 납품량을 저장한다. 예전 완료 저장의 누락 통계는 현재 값으로 채우지 않는다. 불러오기·새 참가/재동기화는 기존 완료 카드를 재생하지 않는다.
- 효과 줄이기는 OS 설정을 기본으로 하고 개인 변경은 별도 로컬 설정에 보존한다. 동작/폭죽/화물 비행을 줄여도 정적 정보는 유지한다. 일시 연출은 저장/스냅샷/체크섬에서 제외한다. 탭을 숨겼다가 돌아와도 밀린 연출을 재생하지 않는다. 화면 장식 예산은 먼지·파편 88 + 카드 20 + 허브 8 + 화물 4 + 산출 강조 8 = 128이다.

레시피·비용·운송 시간/규칙·난수·날씨 판정·전력 반경/연결 거리·지역 과제에 따른 지도 공개 판정은 변경하지 않았다.

## 검증 한계

화면 시험은 개발용 상태를 제어하고 실제 렌더러/DOM을 실행하는 방식이다. 별도 PC 두 대의 실제 LAN 참가/재접속과 장시간 플레이, 사람의 실제 음향 청취는 수행하지 않았다. 네트워크 스냅샷·락스텝·저장 회귀는 자동 테스트로 확인했다.

기계 1,000대의 별도 렌더링 계측은 GPU를 끈 숨김 창에서 수행했다. 효과 켬의 중앙값은 약 6ms, 효과 줄이기는 약 4ms였으며 간헐적인 느린 프레임도 있었다. 실제 GPU·해상도·운영체제에서의 프레임 보장은 아니다.
