# 도로로 갈 수 있는 정류장 선택과 운송 정보 정리

2026-10-30 · regional-d09의 미커밋 연출 개선 위에 추가 적용.

## 후속 사용자 요청 반영

- MG01은 `첫 생산물을 허브로`로 바꾸고 철광석/철판 합계 10개 반입을 인정한다. 철광석 채굴 또는 철판 제작의 실제 실적 하나도 10개 이상이어야 한다. 시작 재고 재순환만으로는 완료하지 않으며 기존 ID/완료와 MG02 조건은 유지한다.
- 노선의 모든 정류장 행에 `지도에서 보기`를 넣었다. 정류장 중심으로 개인 화면만 이동하며 차량 선택·노선은 유지한다. 단절된 정류장은 이동 가능하고 미지정/삭제/미공개 대상은 비활성/무동작 처리한다.
- 일반 운송의 품목은 해당 정류장 적재함, 계획 운송은 연결 창고를 포함한 공급 풀의 보관 품목을 먼저 묶는다. 나머지 품목도 전부 남기며 재고 없는 기존 선택과 물도 유지한다. 출고 예약 등으로 지금 바로 실을 수 있다는 뜻은 아니므로 묶음 이름은 `출발지에 있음`이다.
- 목록에 초점을 맞추거나 열 때 그 선택 목록만 갱신한다. 같은 클릭의 중복 갱신은 생략하고 아직 적용하지 않은 상한·주기·다른 행은 다시 쓰지 않는다.

후속 검증은 컴퓨터 유즈 없이 코드로 수행했다. 빌드와 단위 테스트 325개가 통과했고, 회전/반전 8종의 새 지도·준비된 운송 6상황·원광 반입 없는 철판 직접 자동화도 통과했다. 지도 이동 콜백·삭제/미공개 대상·품목 분류·선택/계획/저장 보존을 단위 테스트로 확인했다. 아래의 숨김 Electron 10개는 최초 개선 당시 결과이며 후속 지도 보기/품목 그룹의 실제 화면 검증으로 간주하지 않는다.

## 바뀐 화면

- 노선의 정류장 목록은 현재 트럭 칸에서 실제 도로로 갈 수 있는 정류장만 보여 준다. 단순히 정류장 옆에 도로가 있는지는 충분한 조건이 아니다.
- 기존 목적지의 도로가 끊기면 선택을 지우거나 다른 곳으로 바꾸지 않고 `정류장 N · 도로 끊김`을 선택된 비활성 항목으로 유지한다. 철거된 정류장도 `삭제된 정류장`으로 남긴다. 도로를 다시 연결하거나 되돌리면 즉시 선택 가능해진다.
- 트럭 창은 상태·화물·배터리와 노선을 먼저 보여 준다. 품목별 운송 설정·운행 정보·도움말·차량 관리는 이름이 보이는 접기 항목으로 제공한다. 계획 사용 중이면 접힌 제목에도 사용 품목 수를 표시한다.
- 정류장 창은 종류·실물 화물·차량을 먼저 보여 준다. 고급 트럭 조립·충전/전력 상세·목표 재고·설명은 접는다. 연결 창고 선택은 유지한다.
- 도로 단절·미지정 정류장·배터리 거리 부족·충전 전력 없음/부족 같은 문제는 기본 화면에서 확인할 수 있다. 실제 충전 차량/전력은 받은 에너지를 기준으로 표시한다.
- 같은 대상을 편집하는 동안 펼친 설정은 재렌더링해도 유지한다. 창 배치·기존 자원 아이콘과 비용·픽셀 테마를 유지한다.

## 판정과 범위

도로 연결 표시는 도로/정류장 변경 개정 번호로 캐시한다. 정류장이 서로 끊긴 두 도로에 닿아 있어도 정류장을 통해 그 도로망을 합치지 않는다. 차량 밑의 도로가 철거된 경우 인접 도로로 출발할 수 있는 기존 경로 탐색 규칙을 따른다. 표시 캐시는 저장·체크섬에 포함하지 않는다.

기존 2~8개 정류장·싣기/내리기·혼합 운송·목표 재고·예약·출발 주기·차량 비용과 주행 판단은 유지한다. 도달 불가능한 정류장은 지도에서 사라지는 것이 아니라 차량의 선택 목록에서 제외된다. 자동 배차·새 노선 시스템·일괄 재설정은 추가하지 않았다.

구현 위치는 `src/ui/transport.ts`, `src/ui/ui.ts`, `src/style.css`이며 `World.roadRevision`은 읽기 전용 캐시 키다. 기존 연출 개선의 다른 변경과 파일을 보존한다.

## 검증

- `npm run build` 통과. 타입 검사 포함.
- `npm test` 319개 통과, 기존 성능 시험 1개 기본 건너뜀. 새 테스트 4개는 실제 findPath와의 일치, 분리된 도로망, 철거/되돌리기/저장 복원, 차 밑 도로 철거를 확인한다. 선택 목록 조회 전후 저장·체크섬도 동일하다.
- `scripts/verify-transport.cjs`의 숨김 Electron 검증 10개 통과. 실제 DOM에서 연결 목록·편집 명령·단절/삭제된 선택 유지·접기 유지·정류장 요약·320px 기본/펼친 설정을 확인했다. 임시 프로필을 사용하며 결과와 캡처는 `artifacts/transport/`에 생성된다.
- `git diff --check` 통과. 배포와 설치 파일 재생성은 실행하지 않았다. 실제 두 PC LAN과 장시간 운송은 이번 화면 검증에 포함하지 않는다.
