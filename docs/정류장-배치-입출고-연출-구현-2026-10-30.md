# 정류장 도로 미리보기와 입출고 연출

2026-10-30 · 기존 regional-d09의 미커밋 개선 위에 추가 적용.

## 배치 미리보기

정류장을 들면 실제 접도 칸을 초록 테두리와 연결선으로 강조한다. 가까운 화면에서는 정차할 수 있는 도로 칸에 `P`, 위쪽에는 `도로 연결 · 정차 N칸`을 표시한다. 대각선이나 한 칸 떨어진 도로는 접도로 세지 않는다. `P`는 예약 주차 공간이나 새 충돌 규칙이 아니라 기존 트럭이 정차할 수 있는 칸의 표시다.

도로가 없으면 정류장 테두리와 `도로 미연결` 안내를 보여 주되 정류장 먼저 건설하기는 유지한다. 다른 건물과 겹치거나 설치할 수 없는 곳은 `설치 불가`와 회색 접도 표시를 사용한다. 미공개 도로는 표시하지 않는다. 허브/창고 인접 자동 회전·내리기 설정 이후에도 정차 칸 판정은 실제 배치와 같다.

`World.stationStops`가 위치/크기만 받도록 타입 범위를 정리해 가상의 미리보기 몸체와 실제 정류장이 같은 판정을 사용한다. 복사 묶음의 아직 설치하지 않은 도로를 실제 접도로 오인하지 않도록 이 안내는 일반 정류장 도구에 적용한다.

## 상차와 하차 및 벨트 입출고

- 트럭 상차는 정류장 적재 구역 → 트럭, 하차는 트럭 → 정류장 안쪽으로 아이템 아이콘이 이동한다. 줄 서기 때문에 트럭을 옮겨 그렸다면 그 화면 위치를 사용한다.
- 벨트/기계 → 정류장의 실제 입고와 정류장 → 벨트/기계의 실제 출고도 표시한다. 지하 벨트는 먼 입구가 아니라 실제 출구를 시작점으로 사용한다.
- 아이템에는 밝은 받침, 짧은 색 궤적과 도착 적재 구역 테두리를 붙인다. 날씨·정보 레이어 위에 그리되 미공개 지도 마스크를 유지한다.
- 이전 게임 시간 0.25초 대신 실제 시간 0.55초에 걸쳐 성공한 이동의 잔상을 마무리한다. 4배속에서 약 0.06초 만에 지나가던 문제를 줄인다. 실제 화물 이동·적재 속도·출발은 연출을 기다리지 않는다. 완료 사건의 잔상은 정지 후에도 짧게 마무리할 수 있다.
- 정류장 기존 표지에는 최근 실제 이동에 맞춰 `상차`·`하차`·`입고`·`출고`를 약 0.65초 표시하고 이후 원래 역할로 돌아온다. 효과 줄이기에서는 아이콘 비행을 생략하고 이 정적인 상태 표시를 유지한다.
- 재고·공간이 없어 이동하지 못했거나 예약/충전/대기만 한 경우에는 이동 효과를 만들지 않는다. 같은 정류장/종류/방향의 진행 중 효과는 묶고 전체 아이콘은 기존 4개 상한을 유지한다. 새 사건 때문에 진행 중인 아이콘을 중간에 잘라내지 않는다.

이동 사실은 읽기 전용 `station-port` 알림으로 전달한다. 저장·네트워크 명령·체크섬에는 넣지 않으며 불러오기/탭 복귀 때 과거 효과를 재생하지 않는다. 기존 생산·주행·하역 규칙은 유지한다.

## 구현과 검증

`src/render/station-feedback.ts`에 접도 모델·이동 끝점/시간·효과 묶기를 두고 실제 렌더러에 연결했다. `src/sim/world.ts`는 기존 정차 칸 판정을 재사용하며 실제 성공한 정류장 입출고 뒤에만 관찰 알림을 낸다.

- 타입 검사를 포함한 빌드 통과, 단위 테스트 335개 통과. 기존 성능 시험 1개는 기본 실행에서 건너뜀.
- 새 테스트 10개는 8방 접도 후보 중 실제 네 면/대각선/간격·설치 불가/안개·자동 회전, 입고/출고 성공과 실패, 지하 벨트 출구, 줄 선 차량 끝점, 1/2/4배속 가독성 시간, 효과 상한, 저장/체크섬 동일성을 확인한다.
- 새 지도 8종·준비된 운송 6상황·원광 없이 철판 반입하는 자동 진행도 통과했다.
- 컴퓨터 유즈나 숨김 브라우저/앱 조작은 실행하지 않았다. 실제 화면에서의 재생·가독성 확인과 배포는 이번 검증에 포함하지 않는다.
