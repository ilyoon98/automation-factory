# 생산 목표에 따른 지도 공개

2026-10-27 · 요청 반영 첫 기획안 · [메인 목표 36개](목표-진행-상세기획.md) · [자원·지도 배치](지형-운송-전력-상세기획.md)

**시작 지역만 공개하고 실제 생산·배송 목표를 달성할 때 다음 산업 지역을 공개한다.** 새 확장 맵은 처음부터 256×256 전체를 생성하지만 볼 수 있고 건설할 수 있는 범위를 단계적으로 늘린다. 이전의 ‘첫 시제품 전체 지도 공개’안을 이 문서로 대체한다. 연구비·레시피·목표 수량·최종 납품 50개는 바꾸지 않는다. 게임 코드 적용은 별도다.

## 1. 플레이 흐름

첫 공장에 집중 → 초원 외곽으로 배송 → 눈밭의 주석과 숲의 고무 → 석유/전해 금속 두 갈래 → 화산/염호 두 갈래 → 후반 전체 맵에서 조립망 확장이다. 공개 보상은 이미 달성한 행동의 다음 사용처를 보여 준다. 새 지역에 있는 자원을 먼저 써야 그 지역이 열리는 조건은 만들지 않는다.

지역 공개는 무료·즉시이며 연구나 조사 버튼을 다시 요구하지 않는다. 일수·날씨·대기 시간·가동률 유지로 열지 않는다. 아래 시각은 경제 기획에 맞춘 관찰 목표이고 실제 시간 잠금이 아니다. 업적 메달을 지도 공개 조건으로 삼지 않는다.

## 2. 목표별 공개 표

RV 식별자는 공개 묶음의 고정 ID다. MG는 기존 메인 목표 ID를 그대로 사용한다. RV02/03, RV05/06은 순서를 강제하지 않는 병행 가지다.

| 공개 ID | 공개 조건 | 새로 보이는 곳과 보장 내용 | 이어지는 생산/목표 | 참고 시각 |
| --- | --- | --- | --- | --- |
| RV00 | 새 게임 시작 | A 시작 초원. 허브 주변 약 24칸, 철·구리·석탄·돌·담수·일반 나무·초기 부지 | MG01~06, MG08의 목재 생산까지 시작 지역만으로 가능 | 0분 |
| RV01 | MG03 기어 자동화 완료 | 초원 외곽. 첫 추가 철·구리·석탄 광맥, 왕복 운송용 부지·진입로, 확장 건설 공간 | MG07 첫 트럭 배송의 목적지/출발지. 기본 산업과 연료 공급 확장 | 5~8분 |
| RV02 | MG07 첫 트럭 배송 완료 | B 첫 눈밭. 주석광석·24×24 공장 부지·충전/연료 창고 자리·연결 가능한 도로 띠 | MG09 합금 연구 → MG10 주석 → MG11 구동부 | 25~35분 |
| RV03 | MG08 숲의 건설 재료 완료 | C 첫 숲. 일반 나무·고무 수액 군락·담수·제지/화학 부지·접근로 | MG12 산업 전동기 → MG13 고무/전선 → MG14 모터 | 약 20~40분. 고무/모터 생산은 60~80분 목표 |
| RV04 | MG14 첫 절연 모터 완료 | D 모래사막과 E 바위사막을 **동시에** 공개. 원유·보크사이트·각 지역 담수/공장 부지·두 접근로 | MG18 플라스틱/19 제어기와 MG20 프레임을 병행. MG17 정제는 먼저 진행 가능 | 60~80분 |
| RV05 | MG19 산업 제어기 완료 | F 첫 화산. 황·지열 분출구 3곳·공장 부지·반입/전봇대 연결 경로 | MG21 황 → MG22 타이어/23 케이블, 선택 지열 | 90~125분 |
| RV06 | MG20 경량 프레임 완료 | G 첫 염호. 염수·**별도 담수**·전해/배터리 부지·접근로 | MG25 리튬 → MG26 배터리/27 윤활제 | 90~125분 |
| RV07 | MG28 재료가 모이는 조립 거점 완료 | 아직 가려진 전체 지도. 두 번째 이후 자원지·추가 분출구·확장 부지·남은 경계 지역 | 대형 조립·추가 차량·생산 증설·최종 납품을 자율 배치 | 약 145~175분 |

MG19가 먼저면 화산, MG20이 먼저면 염호가 먼저 보인다. 두 지역이 보여도 채취·레시피는 기존 T05/T06 해금을 따른다. 보이는 것과 가공 기술 습득을 구분한다. MG19/20의 실제 순서가 바뀌어도 후속 생산이 막히지 않는다.

RV03 숲 공개가 RV02 눈밭보다 먼저일 수 있다. 숲을 공개했다고 T02 전에 수액을 바로 채취할 수 있는 것은 아니다. 목재·제지 부지를 미리 준비할 수 있고, 주석+구동부를 거쳐 고무/모터로 합류한다.

H는 별도 지형이나 잠긴 조립 전용 지역이 아니다. RV01 이후 초원 외곽의 공개 부지나 이후 원하는 공개 부지를 조립 거점으로 쓸 수 있다. 예시 H 부지는 늦어도 RV04에 공개한다. MG28을 해야 조립 부지가 열리는 순환 조건을 만들지 않는다.

## 3. 첫 지역의 보장과 막힘 방지

### 시작 초원

- 초기 철판 120·기어 40·돌 40, 철/구리 시작 광맥 각 8,000·석탄 6,000·돌/담수·일반 나무 최소 60그루를 공개 범위에 둔다. 숨겨진 첫 숲의 자원에 의존하지 않는다.
- 시작 나무만으로 벌목·제재를 할 수 있고, 나무 25그루에서 통나무 50 → 목재 100을 만들어 MG08을 달성할 수 있다. 산림 연구·제재소 비용은 기존 기본 금속으로 만든다. 식목·후속 숲은 그 뒤 확장 경로다.
- MG03 뒤 초원 외곽 공개 묶음에 첫 추가 기본 광맥(기존 허브 중심 25~36칸 보장)과 진입로를 함께 넣는다. 원광 고갈이나 큰 트럭 준비 비용 때문에 눈밭 공개 전에 기본 자원이 막히지 않게 한다.

### 첫 트럭 배송

MG07은 주석·수액·석유 배송을 요구하지 않는다. 예를 들어 시작 공장에서 실제 채굴한 석탄 20개를 공개된 초원 외곽의 현지 발전용 연료 창고로 배송하면 된다. 두 정류장·유효 수요·실제 하역을 사용한다. 창고·정류장만 두고 빈 운행하거나 같은 화물을 반복 왕복해 실적을 늘리지는 않는다. 도착지의 실제 연료 수요를 충족하고 현지 발전으로 이어지는 사례다.

초기 연료 반입과 무전력 화물 하역은 [독립 시동](전력망-연결-독립시작-개정.md) §5를 따른다. 눈밭이 가려져 있다는 이유로 외곽 충전에 리튬·지열·태양광을 강제하지 않는다. 기본 트럭 25~35분 목표와 기본 구매 비용도 유지한다.

### 이후 산업

- RV04는 MG18/20 완료가 아닌 **모터 MG14**에서 연다. 플라스틱을 만들어야 유전이 열리거나 프레임을 만들어야 보크사이트가 열리는 모순을 막는다.
- RV05는 황 채굴 MG21이 아닌 **제어기 MG19**, RV06은 리튬 MG25가 아닌 **프레임 MG20**에서 연다. T05/T06의 교차 연구 선행은 기존대로 유지한다.
- 첫 특화 자원지·담수·부지는 각각 해당 산업을 시작하기 전에 같은 공개 묶음으로 확보한다. 염수만 보이고 전해용 담수가 가려진 상태를 만들지 않는다.
- 첫 자원지 보장량은 기존 경제 예산을 감당한다. RV07 이전에 두 번째 특화 광맥을 반드시 써야 MG28을 완료하는 배치를 내보내지 않는다. 이 조건은 지도 생성 검증에 포함한다.
- MG28은 선택한 조립 부지에 세 생산 거점에서 제작 재료를 배송하는 목표다. 모듈·고급 트럭 완성이나 최종 납품을 먼저 요구하지 않으므로 전체 지도는 최종 조립 전에 열린다.
- MG28 수신지는 공개 부지의 정류장/창고로 준비할 수 있다. C 모터·E 프레임·G 배터리 각 10개의 수동 목표 재고 요청/실제 입고가 한 달성 예다. T07·대형 조립소·수신지 자체 생산을 선행 조건으로 추가하지 않는다. MG29는 그 다음 T07의 P22 첫 제작으로 진행할 수 있다.

## 4. 지역 공개의 공간 단위

동심원 반경만 늘리지 않고 **산업 지역+필수 부지+그곳까지 갈 수 있는 접근 구간**을 한 묶음으로 연다. 목표는 맵의 특정 방향을 강제하지 않는다. 같은 시드의 회전/반사 배치에도 해당 자원 역할의 지역이 공개된다. A~H 좌표는 기존 문서의 검산용 예다.

지도 생성 때 전체 지형·자원량을 고정하고, 셀별 기본 공개 묶음 ID와 각 RV의 공개 셀 집합을 함께 만든다. 실제 공개 마스크는 달성한 RV 집합의 합집합이다. 공개할 때 새 자원을 생성하거나 기존 광맥 양을 다시 주지 않는다. 작업 부지는 기존 24×24·확장 방향 보장, 도로 띠는 폭 3칸을 유지한다.

묶음 생성은 RV00 → RV01 → RV02/03 → RV04 → RV05/06 → RV07의 의존 순서로 검사한다. 각 묶음의 필수 도로/벨트/전봇대 설치 경로가 이미 공개된 곳과 그 묶음 안에서 이어져야 한다. 먼저 열리는 도로 띠에 미래 단계 전용 자원·분출구를 배치해 정보나 채취를 앞당기지 않는다. 한 부지가 여러 묶음과 겹치면 먼저 공개된 셀은 유지하되 미래 전용 자원 셀은 해당 묶음에서만 열리게 배치한다.

기존 후보 전력선/화물 경로가 가려진 곳을 가로지르면 우회 공개 경로를 보장한다. 기존 F/E/G/C 전력 배선 예시는 해당 거점·경유 셀이 공개된 뒤 쓸 수 있는 기하 예다. 시드의 실제 공개/설치 가능 경로를 검증한 결과와 구분한다. RV07은 남은 셀을 모두 공개한다.

## 5. 공개 전후의 조작과 표시

미공개 지역은 동일한 안개/종이 음영으로 표시한다. 지형·정확한 자원 위치/잔량·호수·분출구·현지 날씨 수치는 노출하지 않는다. 지도 바깥 테두리와 앞으로 열릴 지역에 대한 일반적인 목표/도감 설명은 볼 수 있어도 좌표를 먼저 알 수는 없다. 안개는 기상 ‘안개’와 다른 영구 공개 상태이며 날씨가 바뀌어도 이미 공개한 곳을 가리지 않는다.

- 기본 지도·미니맵 M·전력/운송/자원/날씨 레이어·목표 위치 이동·검색·툴팁·부족 재료의 공급지 링크는 같은 공개 마스크를 사용한다. 숨겨진 자원으로 카메라를 바로 이동시키지 않는다.
- 카메라를 미공개 영역으로 옮겨도 상단에 현지 지형명·기상 아이콘·지형별 입자 효과를 노출하지 않는다. 날짜/낮밤은 공통 정보로 유지하고 현지 정보는 ‘미공개 지역’으로 표시한다. 공개 후 현재 날씨를 정상 표시한다.
- 미공개 셀은 건설·철거·채취·복사 대상·트럭 경로로 사용할 수 없다. 도로/벨트 미리보기와 청사진 일부가 걸치면 건설 전에 해당 칸이 미공개라고 표시한다. 원래 가능한 공개 부분의 도구 사용을 숨기지는 않는다.
- 도로·벨트·건물을 공개 경계에 설치해도 주변 미공개 셀을 자동으로 열지 않는다. RV 묶음 공개로만 범위를 늘린다. 건설을 반복해 다음 목표의 지역 공개를 앞당기는 별도 탐사 규칙은 넣지 않는다.
- 전선 자동 연결도 양 끝과 선이 지나는 셀의 공개 조건을 만족해야 한다. 선의 셀 판정은 기준 칸 사이 직선의 supercover(모서리 접촉 포함)를 사용한다. 선이 서로 교차한다고 전력망을 합치지는 않는다. 이 공개 조건은 12칸 연결·무손실 공유 규칙에 추가되는 지도 접근 조건이다.
- 월드 명령 처리에서 접근 가능 여부를 다시 검사한다. UI만 회색으로 만들고 숫자키/다른 참여자의 명령은 미공개 칸에 들어가는 상태를 만들지 않는다.
- 목표를 달성하면 짧은 ‘새 지역 공개’ 알림·자원 종류·목적을 보여 준다. 미니맵의 새 공개 영역만 잠깐 강조하고 강제 카메라 이동·게임 일시정지·추가 확인 버튼은 없다. ‘위치 보기’를 누르면 이동한다.
- 다음에 열릴 묶음은 ‘첫 트럭 배송을 완료하면 새 지역 공개’처럼 **직접 선행 목표 하나**를 표시한다. 공개가 빠르다는 이유로 다음 연구나 생산 배치를 자동 선택하지 않는다.

## 6. 목표·업적·저장·함께 하기

목표 완료 플래그와 지도 공개를 공용 시뮬레이션에서 한 번 처리한다. 선행 완료 전에 이미 쌓인 연구/생산 실적은 기존 목표 규칙대로 반영한다. 해당 목표가 완료되는 틱에 공개 묶음을 열고, 필요하면 노드 연결/경로 캐시를 갱신한다. 같은 틱의 여러 공개는 합집합으로 적용한다.

공개 상태는 되돌리기·전력망 분리·메달 조건 하락으로 취소되지 않는다. 이미 연 자원과 도로를 다시 가리지 않는다. 공개 애니메이션을 재생해 자원을 다시 주거나 목표를 중복 완료하지 않는다.

새 세계에 `mapRevealProfile=goal-frontier-v1`, 지도 생성/공개 버전, 달성 RV ID를 저장·스냅샷·체크섬에 포함한다. 셀별 공개 집합은 같은 시드/버전에서 결정하며 지원 버전 없이 임의 재생성하지 않는다. 함께 하기에서는 한 사람이 목표를 완료하면 공장 전체에 공개한다. 새 참가자도 같은 범위를 즉시 받는다. 개인 카메라·레이어 선택만 개인 설정이다.

유효한 단계 공개 저장에서 완료 MG가 있는데 해당 RV 비트가 누락된 경우 완료 플래그로 공개를 보충한다. 이미 저장된 RV는 목표 추적/안내 상태가 달라져도 지우지 않는다. 재고에서 완료 MG를 추정하지 않으며 저장 복구 알림·공개 애니메이션을 반복 재생하지 않는다.

기존 legacy-v042 공장과 전체 공개로 만들어진 기존 시제품 저장은 **전체 공개를 유지**한다. 현재 건설된 곳을 갑자기 가리거나 지도 접근을 축소하지 않는다. 새 목표 공개 규칙은 새 확장 세계에 적용한다. 개발용 전체 공개는 별도 디버그 기능이며 일반 저장의 업적/공개 목표를 임의 달성시키지 않는다.

지도 공개는 탐사 드론·자원지 조사 보고서 시스템이 아니다. E 의존 업적 D24의 조사 완료로 세지 않으며 아직 미지원으로 남긴다. 업적 획득이 지도 공개를 대신하지 않고, 공개만으로 생산/배송/지역 운영 업적을 지급하지 않는다.

## 7. 구현 전 검토와 구현 후 검증

문서 단계에서 RV00~07의 선행 MG가 존재하고, 각 공개 조건을 그 지역의 자원 없이 달성할 수 있는지 검사한다. MG07의 초원 배송·MG08의 시작 나무·MG14 이전 두 자원군의 필요 여부·MG28 이전 조립 부지/특화 광맥을 특히 확인한다.

구현 후에는 여러 시드의 각 단계마다 도달 가능한 부지·실제 도로 길이·담수·연료 시동·전봇대 선의 공개 조건을 검사한다. 목표 직전/직후·동시 달성·저장/중간 참가·청사진/지도 레이어의 정보 노출·RV07 전체 공개를 실제로 확인한다. 현재 문서의 기획·정적 검산을 지도 생성/플레이 통과로 보고하지 않는다.
