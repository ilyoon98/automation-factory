# 진행 시간과 연구 설비 비용

2026-10-27 · 새 확장 지도용 경제 프로필 regional-v1 · [전체 기획](기획-통합정리-검토.md) · [생산 체인](생산체인-상세기획.md)

**첫 자동화 5~8분, 첫 배송 25~35분, 첫 지역 조합 40~55분, 최종 허브 납품 4~5시간을 첫 플레이 목표로 잡는다.** 초반 기본 재료 연구비를 낮추고, 중후반에는 직전 산업의 부품과 새로운 지역 연결을 요구한다. 아래 regional-v1 비용안은 2026-10-27 사용자 채택 기준이다. 실제 플레이 시간이 검증된 결과나 게임 코드 적용 완료를 뜻하지 않는다. 설비 크기·정확한 연결 칸·조립 셀은 [설비 배치 상세](설비-입출구-배치-상세기획.md)를 따른다.

## 1. 시간의 기준과 목표

1인·1배속·새 확장 지도·첫 플레이 기준이다. 제작·설계·배치·설명 읽기를 포함하되 게임을 멈춘 휴식은 제외한다. 보통은 배치 중에도 시뮬레이션을 진행한다고 가정한다. 별도로 정지해 설계하는 시간과 2배속·함께 하기의 단축 효과는 플레이 기록에서 구분한다.

목표 시각은 개발 중 안내와 밸런스를 위한 값이다. 시간제한·마감·늦었을 때의 불이익이 아니며, 빠른 플레이어를 정해진 시각까지 기다리게 하지 않는다. 게임 목표 카드에 실패 카운트다운을 추가하지 않는다.

| 이정표 | 시작 후 목표 시간 | 실제 달성 기준 |
| --- | --- | --- |
| 첫 철판 자동화 | 2~4분 | 채굴·제련·허브 입고 연결 |
| 첫 기어 자동화 | 5~8분 | 기어 실제 누적 20개 생산 |
| 기본 산업 | 12~20분 | 구리선·강철·회로 라인이 돌아감 |
| 첫 트럭 | 25~35분 | 기본 트럭으로 다른 정류장에 화물 20개 실제 배송 |
| 첫 지역 조합 | 40~55분 | 주석 물류를 연결하고 청동 구동부 누적 20개 생산 |
| 숲 전기부품 | 60~80분 | 고무·절연 전선·절연 모터 10개 생산 |
| 제어·경량 금속 | 90~125분 | 플라스틱·제어기·알루미늄·프레임 생산, 두 연구 가지 병행 |
| 황·리튬 산업 | 125~165분 | 강화 소재·배터리·고급 윤활제를 조립망에 연결 |
| 만든 고급 트럭 사용 | 165~195분 | 조립품을 사용 위치로 보내 차량을 만들고 실제 배송 |
| 첫 설비 모듈 | 190~220분 | 여섯 재료를 모아 첫 제작, 한 기계에 설치·사용 |
| 최종 납품 | 240~300분 | 허브 프로젝트에 설비 모듈 누적 50개 납품 |

첫 지역 조합은 단순 주석판 생산이 아니라 다른 산지의 재료를 합친 구동부까지다. 최종 모듈 50개를 2개/분으로 만드는 순수 제작 25분은 전체 엔딩 시간이 아니다. 첫 모듈 뒤에도 공급 보강·재고 채우기·현지 사용·허브 귀환이 필요하다.

권장 초반 생산 규모는 구동부 5개/분, 모터 2개/분이다. T05~T06 단계에는 제어기·프레임·배터리 2개/분 정도, T08 준비에는 제어기·프레임을 4개/분까지 확장하는 것을 기준으로 비용을 정했다. 생산 속도는 달성 조건이 아니다.

하루 12분이므로 엔딩 목표는 약 20~25게임일에 해당한다. 날씨는 확정한 확률을 그대로 사용하며 특정 날씨가 와야 연구가 열리지는 않는다.

## 2. 비용을 낮추는 원칙

- 기존 레시피·기계 속도·전력·트럭 성능·시작 재고는 바꾸지 않는다. 비용과 권장 확장 순서를 조정한다.
- 초반은 첫 기능을 배우기 전에 기본 재료를 수백 개 더 기다리는 일을 줄인다.
- 중후반 연구는 직전 중간재를 보통 3~5분 더 생산하면서 도로·부지·보조 공정을 준비할 양으로 잡는다. 새 부품을 다음 설비 건설에도 써야 하므로 연구비와 건설비를 동시에 보여 준다.
- 연구 완료는 재료를 실제 허브에 반입해 지불하면 즉시 처리한다. 별도 연구 타이머·연구소 연료는 추가하지 않는다.
- 건설 원가는 기존 공용 허브 재고에서 지불하고, 기계 투입물·고급 트럭 조립품 사용·최종 납품은 현지 실물을 사용한다.
- 선택형 발전·고급 채굴·고속 벨트·축전·끝없는 연구를 전부 해야 최종 납품이 가능하게 만들지 않는다.

예를 들어 모터 2개/분이면 T03의 모터 8개는 4분, 구동부 5개/분이면 T02의 구동부 20개도 4분이다. T03과 T04는 함께 모터 16개를 쓰므로 한 번에 두 연구를 누르기보다 두 현장을 준비하는 동안 생산을 이어 간다.

T08의 제어기·프레임 각 16개는 4개/분으로 확장하면 4분이다. 이 단계에서 기존 공장을 한 번 더 확장할 이유를 만든다. 고급 회로·제어기를 새로 만들기 전에 그 결과물을 연구비로 요구하지 않는 기존 선행 원칙은 유지한다.

## 5. 기본 건물 비용은 유지

첫 채굴·제련·운송 설비는 현행 비용을 유지한다. 같은 기능을 다시 배우면서 건설 단가까지 모두 바뀌는 부담은 줄인다. 연구비를 낮춰 필요한 기능을 빨리 열고, 실제 확장에 쓸 재료는 계속 생산하게 한다.

## 6. 새 생산 설비 비용

작업 전력과 면적은 생산 기획의 기존 수치를 유지한다. 첫 산업에 들어갈 때의 중복 금속 비용을 낮췄다.

| 설비 | 작업 전력 kW | 비용 |
| --- | --- | --- |
| 수액 채취기 | 60 | 철판×12 + 기어×6 + 목재×12 |
| 화학 반응기 | 180 | 강철×8 + 기어×6 + 회로×4 |
| 시추기 | 120 | 강철×12 + 절연 모터×2 + 회로×6 |
| 정유소 | 240 | 강철×20 + 절연 모터×4 + 회로×12 |
| 전해로 | 500 | 강철×16 + 청동×8 + 절연 모터×2 + 벽돌×12 |
| 대형 조립소 | 300 | 강철×30 + 경량 프레임×8 + 절연 모터×4 + 산업 제어기×4 |

첫 시추기·정유소·전해로는 모터를 요구하지만 해당 산업이 처음 만들 플라스틱·알루미늄·배터리를 요구하지 않는다. 대형 조립소에는 이미 만들 수 있는 프레임·모터·제어기를 사용한다.

## 7. 새 전력 설비 비용

| 설비 | 비용 |
| --- | --- |
| 기본 전봇대 | 목재×2 + 구리선×4 |
| 변전소 | 강철×8 + 목재×8 + 절연 전선×8 + 절연 모터×1 |
| 축전기 | 배터리 팩×4 + 강철×4 + 산업 제어기×1 |
| 연료 발전기 | 강철×16 + 절연 모터×2 + 산업 제어기×1 + 벽돌×12 |
| 지열 발전소 | 강철×30 + 청동×12 + 절연 모터×4 + 산업 제어기×4 + 콘크리트×24 |

[전력망 개정](전력망-연결-독립시작-개정.md)에 따라 송전 터미널·양 끝 건설비·선로 케이블 비용을 삭제했다. 전봇대 건설비에 전선을 포함하며 12칸 이하 자동 연결은 추가 재료를 차감하지 않는다. 기준 F/E/G/C 연결용 중간 전봇대 24대를 현지 50대에 더해 74대로 계산한다. 신규 설비 비용은 생산 6종+전력 5종이다.

축전기 한 대는 10MJ·200kW를 유지하면서 배터리 팩 비용을 8개에서 4개로 낮췄다. 첫 야간 완충을 시험할 수 있게 하되 한 대가 전체 공장의 밤을 버티는 것으로 안내하지 않는다. 하한 10%에서 쓸 수 있는 양은 9MJ다. 완전한 밤 144초에 1MW 부족을 저장만으로 메우려면 최소 16대·배터리 팩 64개가 필요하고, 저녁·아침과 여유분은 별도다. 이 정도 축전을 필수 목표로 요구하지 않는다.

지열은 비용을 낮춰도 콘크리트 공정 시간이 있으므로 중후반에 병행 준비하는 선택지다. 강철·회로·기존 발전으로 먼저 해당 산업을 돌릴 수 있다.

## 8. 첫 자동화와 첫 트럭의 검산

### 첫 자동화

시작 재고 철판 120·기어 40·돌 40을 그대로 준다. 자동화 연구와 채굴기 1·제련로 2·조립기 1·벨트 35칸·분배기 2·병합기 1은 철판 95·기어 10·돌 20으로 시작 재고 안이다. 이 세트가 반드시 정답 배치라는 뜻은 아니다.

이후 실제로 새 기어 20개를 만들려면 철판 40개, 안내용 허브 철광석 10개까지 포함하면 신규 철광석 50개가 필요하다. 시작 기어를 생산 실적으로 세지 않는다. 채굴기 90 + 제련로 180 + 조립기 75 = 345kW로 허브 400kW 안에서 돌아간다. 이론 제작은 약 1~2분이지만 배치·설명·방향 수정 시간을 포함해 5~8분을 목표로 한다.

### 첫 트럭 준비 세트

권장 연구 8종과 다음 누적 시설을 포함한다. 첫 기어 세트와 중복되는 건물을 다시 더하지 않는다.

- 채굴기 6·제련로 8·조립기 3
- 석탄 발전기 3·정류장 2·기본 트럭 1
- 창고 2·하역기 2·도로 64칸·벨트 80칸
- 분배기 4·병합기 2·지하 컨베이어 4칸

첫 배송은 외곽 발전용 석탄 20개 같은 실제 필요한 화물로 한다. 초기 운영 석탄 300개 안에 이 배송분도 포함한다. 새로운 광물 목표를 열기 위한 빈 형식의 노선을 강제하지 않는다.

| --- | --- | --- |
| 철광석 | 1,144 | 2,734 |

시작 재고는 한 번만 차감했다. 철광석 1,144개에는 안내용 허브 광석 10개가 포함된다. 석탄 450개는 연구 50·강철용 100·운영 예산 300이다. 모두 플레이어가 한 번에 지불해야 하는 금액이 아니라 이 세트를 거쳐 확보할 총량이다.

이때 철판 1,134개를 120개/분으로 만들면 9.45분, 새 기어 208개를 20개/분으로 만들면 10.4분, 강철 100개를 24개/분으로 만들면 약 4.2분이다. 생산은 병행하므로 이 시간을 합산하지 않는다. 앞에서부터 시설을 늘리는 준비·연구·도로·최초 하역을 포함한 목표가 25~35분이다.

기준 배치는 주 공장에 철판 120·구리판 60·기어 20·회로 15개/분의 명목 용량을 두는 안이다. 첫 외곽 채굴기까지 합친 작업 부하는 1,485kW다. 주 공장 작업 1,395kW는 허브+석탄 2대의 2,200kW, 외곽 채굴기 90kW는 현지 석탄 1대의 900kW로 감당하며 지역별 충전 예산도 별도 확보한다. 처음부터 모든 기계가 계속 100%로 돌아간다는 가정은 아니다.

## 9. 최종 납품까지의 전체 예산 사례

### 무엇을 포함했는가

최종 납품 50개 외에 설치 상태로 남길 모듈 1개까지 총 51개를 제작하고, 고급 트럭 조립품은 5개를 제작하는 예다. 기존 모듈을 회수해 납품한다면 51개가 절대 최소는 아니다. 참고 생산량은 모듈 2개/분 + 트럭 조립품 0.2개/분을 유지한다. 이 예산의 완제품 수량은 지정한 배치 수다. 추가로 계속 켜 둔 조립 라인의 초과 완제품·진행 중 재료와 승리 뒤 생산은 별도이며, 게임이 자동으로 해당 배치 수에서 정지한다는 뜻은 아니다.

선택 발전을 포함한 기준 일반 연구는 기존 14종 + 산업 연구 8종, 총 22종이다. 고속 벨트·고급 채굴·배터리 연구·전기 제강·숲 가꾸기·광맥 독립과 끝없는 연구는 이 예산에서 제외한다. 선택하지 않은 발전·연구를 생략한 실제 공장은 이보다 적게 쓸 수 있다.

콘크리트 공정의 추가 철 정광·구리 정광은 원래 금속 라인으로 재활용할 수 있지만 이 원료 상한 예산에서 기본 광석 절감으로 차감하지 않았다. 따라서 이 표는 최적화한 최소 원료량이 아니다. 추가 제련로 2대와 분류기를 포함해 부산물 출구가 막히지 않게 한다. 남는 진흙도 후속 벽돌·보관 경로를 둔다.

### 매장량과 전력 확인

철광석 13,884개는 시작 8,000개를 넘으므로 첫 추가 철광맥을 연결해야 한다. 석탄도 총 9,643개라 시작 6,000개만으로는 부족하다. 첫 추가 광맥은 기존 지도 보장대로 허브 중심 25~36칸 범위에서 연결할 수 있다. 미리 경고하고 허브 배전 확장을 안내한다.

새 지도 최소 매장량은 철·구리 각 56,000개, 석탄 42,000개, 주석 24,000개, 보크사이트·원유·염수 각 36,000개, 황 6,000개다. 위 전체 예산은 모두 그 안이다. 특화 자원 첫 자원지의 양은 위 생산·연구·설비 예산을 감당한다. 희소 자원을 더 자주 옮기는 방식으로 플레이 시간을 늘리지 않는다.

기존 인프라 표의 A 부하는 기초 생산만의 1,635kW다. 이번 전체 예산은 돌·흙 채굴, 분쇄기 2, 세척·양수·벽돌·분리·콘크리트·정광 제련 2대를 추가해 작업 1,275kW를 더한다. 충전 400kW까지 합친 A의 보수적 합계는 **3,310kW**, 비의 양수 보너스까지 3,322kW다. 허브+석탄 4대의 실제 가용 4,000kW로 공급한다. 변전소 처리 한도는 없다. 기준 인프라의 석탄 3대에 한 대를 더한 이유다.

모듈 속도 보너스·끝없는 연구·추가 산업은 이 기본 부하에서 제외한다. 첫 설치 모듈을 C의 모터 조립기처럼 여유 있는 라인에 두는 배치 예를 제공한다. 모듈을 어디에 설치해도 무조건 같은 전력 여유를 보장한다는 뜻은 아니다.

## 10. 콘크리트와 지열의 시간 확인

분리기 1대는 광물 가루 15개/분 → 슬래그 1.5개/분이다. 콘크리트에 슬래그 2개가 필요하므로 지속 공급량은 0.75개/분이다. 지열 1대의 콘크리트 24개는 약 32분, 3대 72개는 약 96분의 분리 가동이 필요하다.

따라서 분리·콘크리트는 다른 산업을 짓는 동안 미리 병행한다. 지열을 125분 시점에 처음 생각한 뒤 완성까지 기다리도록 메인 목표를 막지 않는다. 모듈과 배터리는 기존 석탄 발전으로 먼저 가동할 수 있고 지열은 후반 연료 절약 선택지다. 지열이 너무 늦게 쓰인다는 플레이 결과가 나오면 발전소 자체 비용보다 콘크리트 공정의 전체 수율·비용·재료 대체를 함께 재검토한다.

## 11. 저장 호환과 후반 연구

새 확장 세계에 regional-v1 비용 프로필을 저장하고 모든 참가자가 같은 프로필을 사용한다. 기존 저장의 legacy-v042 연구·설비 비용과 이미 완료한 연구·달성 기록은 보존한다. 가격표만 전역에서 덮어써 옛 공장의 규칙을 바꾸지 않는다. 건설 시 지불한 원가는 기록하고 환급은 현재 가격표가 아니라 그 원가에 맞춘다.

기존 끝없는 연구 5종은 광맥 독립 이후의 선택 경로로 두고 현행 첫 비용·1.5배 증가 규칙을 유지한다. 새 생산망 확장 반복 연구도 기존 기획의 모듈 5·종이 50·콘크리트 50, 다음 단계 1.5배 올림, 하역 속도 단계당 +5%를 유지한다. 둘 다 최종 납품의 필수 조건이 아니고 위 기준 비용에 넣지 않았다.

이 프로필은 연구·설비 비용을 바꾸는 새 지도 설계다. 기존 레시피 27아이템·신규 28아이템의 제작 재료와 시간, 하루 12분·날씨 확률·최종 모듈 50개 목표는 바꾸지 않는다.

## 12. 시제품에서 기록할 것

첫 철판·기어·발전·트럭 제작·첫 배송·구동부·모터·제어기·프레임·배터리·첫 모듈·최종 납품의 게임 시간을 각각 기록한다. 제작 가능하지만 다음 작업이 없어서 재료만 기다린 시간, 배치와 설명에 쓴 시간, 생산·전력·물류 막힘도 구분한다.

첫 목표는 연속 재료 대기 3~5분 이내에서 다른 의미 있는 작업이 가능하도록 만드는 것이다. 다음 연구를 위해 10분 넘게 기본 재료만 반복 대기한다면 비용·안내·권장 설비 규모를 함께 조정한다. 복잡한 조립을 설계하는 시간이 길었다는 이유로 모든 레시피를 빨리 만들지는 않는다.

수학 검산은 재료 수지·최초 설비 비용·선행 관계·전력 예산까지다. 실제 연구 시간·경로·창고 포화·동시 생산·날씨·저장·함께 하기를 시험한 결과와 구분한다. 이 문서 작성으로 게임 코드는 변경하지 않는다.
