# 하단 발전·전력 분리와 건설 진행 순서

2026-10-30 · 사용자 요청 · regional-d09 작업본 · 배포 전

전봇대·변전소·축전기를 발전 설비와 분리하고, 목표·연구 단계에 맞춰 하단 목록을 고정 순서로 정렬했다. 종전의 전력 C 통합·기존 발전 번호 보존 규칙을 대체한다.

| 탭 | 1번부터 순서 |
| --- | --- |
| 물류 Z | 컨베이어, 지하 컨베이어, 분배기, 합류기, 우선 분배기, 스마트 분류기, 고속 컨베이어 |
| 생산 X | 채굴기, 제련로, 조립기, 고급 채굴기, 양수기, 분쇄기, 세척기, 분리기, 전기로 |
| 발전 C | 풍력 발전기, 석탄 발전기, 태양광 패널, 수력 발전기, 연료 발전기, 지열 발전소 |
| 전력 U | 전봇대, 변전소, 축전기 |
| 보관 V | 창고, 하역기 |
| 운송 B | 도로, 정류장, 충전기 |
| 숲 N | 벌목기, 제재소, 식목기 |
| 산업 L | 수액 채취기, 화학 반응기, 시추기, 정유소, 전해로, 대형 조립소 |

청사진 K는 마지막이다. U는 이동·기존 창·건설 단축키와 겹치지 않는 키다. 풍력과 석탄은 같은 연구 단계에서 선택할 수 있으며 풍력을 C1로 우선 표시했다. 같은 단계의 물류·가공 설비는 기본 기능과 생산 흐름을 기준으로 배치했다.

연구 완료 여부로 동적 정렬하지 않는다. 분기 연구를 다른 순서로 진행해도 번호가 유지되고 잠금·부족 상태와 클릭 시 연구 안내는 기존 처리를 따른다. 모든 카드·숫자키·도감은 `CATEGORIES`/`categoryItems`를 공유하며 건물 타입·저장·연구 선행·비용·발전 성능은 변경하지 않았다.

기존 세계는 확장 전용 설비를 빼고 발전 4종만 표시하며, 빈 전력 U·산업 L은 탭·Tab 순회·도감에서 제외한다. 세계 프로필이 바뀌면 현재 팔레트도 다시 그려 확장 카드가 남지 않게 했다. 좁은 화면에서는 탭을 다음 줄로 내려 기존 하단 높이 측정에 반영한다.

변경: `src/data/buildings.ts`, `src/ui/toolbar.ts`, `src/ui/codex.ts`, `src/ui/ui.ts`의 입력 안내 주석, `src/style.css`, `index.html`. 루트의 운영 UI·AI 변경 명세·전력 개정·계획서도 동기화했다.

검증: `npm run build` 성공. `npm test` 341개 통과, 기존 성능 테스트 1개 제외. 추가 6개 검증은 설비 누락/중복·키 충돌·연구 단계 역전·두 세계 프로필의 표시 대상·실제 탭/숫자키/Tab 선택·풍력 C1/전력 U 분리를 확인한다. 아이콘 생성과 DOM 그리기만 대체한 코드 테스트이며 컴퓨터 유즈·화면 재생 검증은 실행하지 않았다. `git diff --check` 통과.
