# 흙에서 금속을 만드는 공정 개정

2026-11-06 · 현행 구현 기준. 이전 생산 체인·경제 기획의 흙 정제 수치보다 이 문서와 `src/data/recipes.ts`를 우선한다. 설비별 투입·산출과 다른 생산라인으로 보내는 양은 [전체 수지와 분기 비율](흙-공정-전체수지-검토안.md)에 정리했다.

## 바꾼 이유

기존에는 흙 채굴기 1대의 흙 60개/분을 모두 정제해도 철 정광이 14개/분에 그쳤다. 흙·자갈 분쇄와 세척·분리의 처리량이 달라 비율을 맞출수록 설비가 늘어났다. 여기에 진흙과 슬래그를 처리하는 설비까지 붙이면 물·자갈 공급도 따로 계산해야 했다.

이번에는 **설비 한 대의 전력은 유지하면서 공정 처리량과 부산물 소비 비율을 조정했다.** 분리기는 한 번 완료할 때 철 정광·구리 정광·슬래그를 함께 만든다. 세척과 콘크리트는 양수·벽돌·자갈 분기까지 연결하기 쉬운 비율로 바꿨다. 기존 설비·연구·아이템과 건설비·연구비는 유지한다.

## 변경한 값

아래의 이전 값은 개정 전 출시본 기준이다. 도중에 사용한 세척 `모래2 + 물1 → 가루2 + 진흙1 / 2초`도 현재 값으로 교체했다.

| 항목 | 개정 전 | 현재 적용값 |
|---|---|---|
| 자갈 분쇄 | 자갈1 → 모래1 / 1.5초 | 자갈1 → 모래1 / **2초** |
| 모래 세척 | 모래3 + 물2 → 광물 가루1 + 진흙1 / 3초 | **모래5 + 물2 → 광물 가루5 + 진흙2 / 5초** |
| 광물 분리 | 가루1 / 4초, 10회에 철7·구리2·슬래그1 순차 생산 | **가루10 / 10초, 매회 철7·구리2·슬래그1 동시 생산** |
| 고효율 모래 세척 | 모래3 + 물2 + 황산1 → 가루2 + 진흙1 / 4초 | **모래4 + 물2 + 황산1 → 가루8 + 진흙2 / 4초** |
| 콘크리트 | 슬래그2 + 자갈1 → 콘크리트1 / 3초 | **슬래그1 + 자갈2 → 콘크리트1 / 2초** |

흙 분쇄, 정광 제련, 벽돌 레시피는 그대로다. 분쇄기 120kW·세척기 150kW·분리기 300kW를 포함해 모든 설비의 정격 전력을 유지한다. 분리기 산출물은 동시에 출력 버퍼에 들어간 뒤 기존 출구를 통해 차례로 빠져나간다.

## 전체 공장을 맞추는 예시

평시 양수량, 전력 100%, 속도 연구·설비 모듈 없음, 완제품을 계속 내보내는 조건이다. 모든 생산 설비가 정격으로 가동하고 자갈·진흙·슬래그까지 내부에서 소비하는 가장 작은 정수 조합은 다음과 같다.

| 공정 | 대수 | 합계 소비/분 | 합계 생산/분 |
|---|---:|---|---|
| 흙 채굴 | 6 | — | 흙360 |
| 흙 분쇄 | 6 | 흙360 | 자갈180 + 모래180 |
| 자갈 분쇄 | 4 | 자갈120 | 모래120 |
| 양수 | 1 | — | 물120 |
| 세척 | 5 | 모래300 + 물120 | 광물 가루300 + 진흙120 |
| 광물 분리 | 5 | 광물 가루300 | 철 정광210 + 구리 정광60 + 슬래그30 |
| 철판 제련 | 7 | 철 정광210 | 철판210 |
| 구리판 제련 | 2 | 구리 정광60 | 구리판60 |
| 벽돌 제련 | 3 | 진흙120 | 벽돌60 |
| 콘크리트 조립 | 1 | 슬래그30 + 자갈60 | 콘크리트30 |
| **합계** | **40** | 중간재 생산·소비 일치 | **철판210 + 구리판60 + 벽돌60 + 콘크리트30** |

정격 전력은 **5,205kW**다. 발전 설비와 외부 생산라인의 전력은 별도다. 위 40대는 수지를 확인하는 예시이며, 건설 대수나 배치를 제한하지 않는다. 작은 공장부터 시작해 일부 설비가 쉬게 두거나, 다른 공장과 재료를 공유해도 된다.

금속만 먼저 만들면 **흙 채굴기1 → 분쇄기2 → 세척기1 → 분리기1**에 양수와 제련을 붙여 철판42·구리판12개/분을 얻을 수 있다. 이때 물24개/분을 쓰고 진흙24·슬래그6개/분도 나온다. 자갈을 모두 모래로 쓰는 조합이므로 콘크리트까지 만들려면 추가 자갈이 필요하다. 위 전체 조합은 처음부터 자갈180 가운데 120을 모래로, 60을 콘크리트로 배분한 예시다.

## 부산물과 확장

- 구리 정광·진흙·슬래그의 출구가 막히면 관련 생산도 멈춘다. 완제품 창고가 가득 차는 경우도 같으므로 계속 쓸 곳이나 허브 납품을 연결한다.
- 전체 조합의 물120개/분은 세척이 모두 사용한다. 종이·플라스틱·알루미늄·황산·리튬·수력 발전에 필요한 물은 추가로 공급한다.
- 모래·자갈·진흙·슬래그를 다른 라인으로 보내면 그만큼 본선 공급이 줄어든다. 완제품 철판210·구리판60·벽돌60·콘크리트30도 여러 공정에 중복 배분하지 않는다.
- 고효율 세척 1대는 모래60·물30·황산15개/분으로 가루120·진흙30개/분을 만든다. 같은 모래에서 가루는 일반 세척의 2배지만, 물·황산과 부산물 처리도 더 필요하다. 황산 자체 생산에 드는 물까지 합치면 세척 1대당 물45개/분이다.

## 기존 저장과 검증

기존 저장에서 바뀐 레시피가 제작 중이었다면 그 작업이 실제로 소비한 옛 재료만 입고 칸으로 반환하고 새 레시피를 준비한다. 이미 생산한 물건, 남은 입고 재고, 설치한 설비는 보존한다. 새 저장을 다시 불러올 때 재료를 중복 반환하지 않는다.

`node scripts/audit-soil-chain.mjs`는 현재 게임 레시피를 읽어 40대 조합, 중간재 9종의 수지, 완제품 산출량, 전력과 다른 생산라인의 물 소비를 검사한다. 전체 레시피의 분당 처리량은 `node scripts/audit-production.mjs docs/생산비율-계산.md`로 재생성한다.

실제 제작 틱·입출고 버퍼·부산물 정체·저장 재개는 시뮬레이션 테스트로 확인한다. 이 계산과 테스트는 화면에서 벨트를 배치한 플레이 검증을 대신하지 않으며, 초기 재료 준비와 운송 시간에는 순간 처리량이 달라질 수 있다.
